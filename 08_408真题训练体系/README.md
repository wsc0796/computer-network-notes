## 二、错题归因四类法

每题错了不只看答案，要归类原因：

### 第1类：概念错

```
特征：知识盲区，完全不知道这个知识点
归因标记：❌ 概念错
处理：回看笔记 → 在知识点旁标记"408真题X年" → 睡前再背一次

例：不知道IGMP是组管理协议 → 概念错
```

### 第2类：公式错

```
特征：知道考什么，但公式记错了 / 算错了
归因标记：❌ 公式错
处理：整理到公式速查表 → 找同类题计算3道

例：2^4=16算成8 → 幂次不熟悉 → 练幂次
例：子网块大小256-248=8 → 算对了但主机数2^3-2=6 → 漏减2
```

### 第3类：协议过程错

```
特征：知道协议，但过程中的细节搞混了
归因标记：❌ 过程错
处理：画出协议过程图 → 一步不差口述一次 → 重新做题

例：TCP三次握手第三步可以带数据吗？→ 可以(SYN=0)
例：DHCP的Discover是广播，Offer是单播还是广播？→ 可选
```

### 第4类：选项陷阱错

```
特征：明明会，看到陷阱选项改了答案
归因标记：❌ 陷阱错
处理：收入"个人陷阱清单" → 考前30分钟扫一遍

例：看到"UDP首部长度20B"知道不对 → 20B是TCP → 改错
     但自己做的笔记里没强调过这个口
```

## 三、个人陷阱清单模板

```
个人陷阱清单（持续更新）
─────────────────────────────────
# 协议类
[ ] TCP是面向字节流，不是面向报文
[ ] UDP是面向报文，不是面向字节流
[ ] RIP是应用层，不是网络层（UDP 520）
[ ] OSPF直接用IP（协议号89），不是UDP/TCP

# 数字类
[ ] MAC地址48bit，IPv4 32bit，IPv6 128bit
[ ] TCP首部20-60B，UDP首部8B
[ ] 以太网最短帧64B，数据字段最小46B

# 计算类
[ ] 可用主机数 = 2^h - 2（不是2^h）
[ ] 子网数 = 2^n（不算全0全1减法）

# 概念类
[ ] 交换机隔离冲突域但不隔离广播域
[ ] CRC只能检错不能纠错
[ ] 海明码能纠错1位
```

## 四、真题二刷方法

### 第一遍（第8周）

```
做题 → 对答案 → 标记错题 → 归因分类
         ↓
只做错题收集，不深入分析
```

### 第二遍（第9周）

```
遮住答案重做错题 → 过3关：
  第1关: 这道题的正确答案是什么？（√就过）
  第2关: 这四个选项分别错在哪里？（√就过）
  第3关: 跟另外哪一年的哪题是同类题？（完成）
```

## 五、跨层综合分析题模板

### Web页访问完整流程（常考大题格式）

```
用户打开浏览器输入 www.example.com

① 应用层(DNS):
   查询www.example.com的IP
   → 本地DNS缓存? → 递归/迭代查询 → 获得IP: 93.184.216.34

② 应用层(HTTP):
   浏览器发起HTTP GET请求
   准备建立TCP连接

③ 运输层(TCP三次握手):
   C→S: SYN=1, seq=x
   S→C: SYN=1, ACK=1, seq=y, ack=x+1
   C→S: ACK=1, seq=x+1, ack=y+1

④ 网络层(IP+ARP):
   判断93.184.216.34是否在本子网? → 不在
   ARP查默认网关的MAC → 帧发送给网关
   路由器查路由表 → 逐跳转发

⑤ 数据链路层:
   逐跳的帧封装/解封装
   每跳MAC地址改变

⑥ 物理层:
   比特流传输

⑦ 服务器收到HTTP请求, 返回HTML

⑧ 浏览器渲染页面
```

### 自主训练法

```
每学完一层，对自己做：
  "如果A向B发一个ping包, 经过3台路由器,
  经过各层时分别发生了什么？"
  
完整口述一遍能讲清楚 → 这层及格了
讲不清楚 → 回看这层笔记
```

```

  王道计网每章选择题 → 正确率≥70%进下章

  2009-2012 计网选择+综合 → 归因 →
  2013-2016 计网选择+综合 → 归因 →
  2017-2020 计网选择+综合 → 归因 →
  2021-2024 计网选择+综合 → 归因

第三阶段（错题歼灭）：
  全部错题二刷 → 正确率≥90%

  目标是选择题错≤2题, 综合大题基本正确
```
