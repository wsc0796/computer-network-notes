## 考点1：UDP首部十六进制解析 ⭐ S级 大题

**2025B卷真题：** 首部十六进制 `07 21 00 45 00 2C E8 27`，求源端口、目的端口、总长度、数据长度、客户端还是服务器、服务程序

**UDP首部结构（8字节）：**

| 字节 | 1-2 | 3-4 | 5-6 | 7-8 |
|------|-----|-----|-----|-----|
| 含义 | 源端口 | 目的端口 | 总长度 | 校验和 |

**固定解题步骤：**
1. 每2个十六进制字节 = 1个字段
2. 十六进制 → 十进制
3. 总长度 - 8 = 数据部分长度
4. 根据端口号判断服务程序

**真题演练：**
```
首部: 07 21 00 45 00 2C E8 27

Step 1: 源端口 = 0x0721 = 7×256 + 2×16 + 1 = 1792 + 32 + 1 = 1825
Step 2: 目的端口 = 0x0045 = 4×16 + 5 = 69
Step 3: 总长度 = 0x002C = 2×16 + 12 = 44 字节
Step 4: 数据长度 = 44 - 8 = 36 字节
Step 5: 目的端口69 = TFTP → 客户端→服务器，服务程序TFTP
```

**变式练习1：**
> UDP首部: `06 33 00 35 00 20 11 A2`，求同上各项。

```
源端口 = 0x0633 = 1587
目的端口 = 0x0035 = 53 (DNS)
总长度 = 0x0020 = 32 字节
数据长度 = 32 - 8 = 24 字节
目的端口53 = DNS，客户端→服务器
```

**变式练习2：**
> UDP首部: `00 44 00 43 00 1A 5F 08`，求同上各项。

```
源端口 = 0x0044 = 68 (DHCP客户端)
目的端口 = 0x0043 = 67 (DHCP服务器)
总长度 = 0x001A = 26 字节
数据长度 = 26 - 8 = 18 字节
DHCP Discover报文，客户端→服务器
```

**常见错误：** 十六进制转换算错、总长度忘减8、源端口和目的端口顺序写反

**保分步骤：** 画出4行2列的UDP首部表 → 标注各字段 → 逐个转换

## 考点2：RIP计时器 ⭐ S级 简答

**2025B卷真题：** 请讲述RIP协议更新几种计时器及作用

**标准答案（4个评分点）：**

1. **更新计时器（Update Timer）= 30秒**：路由器每隔约30秒向邻居发送完整路由更新报文。
2. **失效计时器（Invalid Timer）= 180秒**：若路由器在180秒内未收到某条路由的更新，则将该路由度量设为16，标记为不可达。路由表项暂时保留（用于通告不可达和等待垃圾回收），但**不再用于正常转发**。
3. **删除计时器（Flush/Garbage Collection Timer）= 240秒**：路由标记为不可达后又过了60秒（总共240秒），若仍未收到更新，将该路由从路由表中彻底删除。
4. **抑制定时器（Hold-Down Timer）**：部分教材提到，当收到某路由不可达的消息后，在一段时间内不接受同一路由的更优更新，防止路由振荡。

**30秒口述版：** 30秒更新一次，180秒没消息就标记"死了"(跳数16)，再过60秒（总共240秒）彻底删除。

**易丢分点：**
- 180秒是"失效"(跳数16)不是删除
- 240秒才是删除，总差值60秒

## 考点3：NAT作用 ⭐ S级 简答

**2025B卷真题：** 请简要阐明NAT可以解决什么问题

**标准答案（4个评分点）：**

1. **解决IPv4地址枯竭问题**：允许多个内网主机通过少量公网IP（甚至1个）访问Internet，大大节省公网IP地址。
2. **实现私有地址网络与公网互联**：内部使用私有地址（192.168.x.x / 10.x.x.x / 172.16-31.x.x）的主机，通过NAT转换为公网地址后可以访问Internet。
3. **提高内网安全性**：外部主机无法直接访问内网私有地址的主机（除非主动配置端口映射），NAT起到一定的防火墙作用。
4. **网络改造中避免地址变更**：更换ISP或网络改造时，只需修改NAT设备的公网地址，内部主机配置无需改变。

**30秒口述版：** NAT把一个公网IP分给多个内网主机用，省IP地址，还能保护内网不被外部直接访问。

## 考点4：IPv6分片行为 ⭐ S级 选择/简答

**2025B卷真题（选择题3）：** 如果一台路由器接收到的IPv6数据报因太大而不能转发，则路由器将把该数据报（ 丢弃 ）。

**核心规则（必背）：**

1. **IPv6路由器永远不对数据报分片。** 分片功能从IPv6路由器中被移除，由源主机负责。
2. 若数据报超过出链路MTU → 路由器**丢弃**该数据报。
3. 丢弃后路由器向**源主机**发送**ICMPv6 Packet Too Big**报文，告知源主机MTU值。
4. 源主机收到后重新分片或使用更小的数据报。

**对比IPv4：** IPv4路由器可以对数据报分片（当DF=0时）。这是IPv4和IPv6的关键区别。

**常见陷阱：** "IPv6路由器分片更高效"——错误。IPv6路由器根本不分片。

## 考点5：10Base命名含义 ⭐ S级 大题/名词解释

**2025B卷真题：** 试说明10Base5、10Base2、10Base-T、1Base5和10BROAD36所代表的意思。

**标准答案（按10Base命名规则拆解）：**

| 名称 | 速率 | 信号类型 | 段最大长度/介质 |
|------|:---:|------|------|
| 10Base5 | 10 Mbps | 基带(Baseband) | 500m（粗同轴电缆） |
| 10Base2 | 10 Mbps | 基带 | 185m（细同轴电缆，实际≈200m） |
| 10Base-T | 10 Mbps | 基带 | T=Twisted Pair（双绞线） |
| 1Base5 | 1 Mbps | 基带 | 500m（双绞线） |
| 10BROAD36 | 10 Mbps | 宽带(Broadband) | 3600m（同轴电缆） |

**命名规则速记：**
```
数字 = 数据传输速率(Mbps)
Base = 基带信号 / BROAD = 宽带信号
后缀 = 5=500m粗缆 / 2=~200m细缆 / T=双绞线 / 36=3600m
```

**2025B卷原卷答案摘要：** Base表示基带曼彻斯特编码，BROAD代表宽带。数字表示速率，后缀表示最大段长或介质。

## 考点6：编码识图（NRZ/NRZ-I/曼彻斯特/差分曼彻斯特）⭐ S级 选择/判断

**2025B卷真题（选择题8）：** 给两幅波形图，判断编码1和编码2分别是什么。

**2022大数据B卷真题答案：** 编码1=NRZ，编码2=曼彻斯特编码。

**识图口诀：**

| 编码 | 必看特征 | 一句话 |
|------|---------|--------|
| NRZ | 正电压=1，负电压=0（或相反），**位中间无跳变** | "平线代表1或0" |
| NRZ-I | 1=电压翻转，0=不翻转，位中间无跳变 | "看边界是否跳" |
| 曼彻斯特 | 每比特**中间必有跳变**，方向固定（↓=1或↑=1） | "中间必须跳" |
| 差分曼彻斯特 | 每比特**中间必有跳变**，但0/1看**位开始处**是否翻转 | "中间必跳+开始处看数据" |

**快速区分法：**
```
1. 先看bit中间是否必有跳变？
   否 → NRZ 或 NRZ-I
   是 → 曼彻斯特 或 差分曼彻斯特
2. 对于中间必跳的：
   看bit边界：方向固定 → 曼彻斯特
   看bit边界：是否翻转 → 差分曼彻斯特
```

**自测题：**
1. 位串 `101100`，NRZ-I（1翻转0不翻转），初始低电平。画出波形。
2. 判断：曼彻斯特编码每个bit中间必有跳变。（✅ 正确）
3. 给定长串`000000`，NRZ和曼彻斯特哪个更容易丢失同步？（NRZ，因为长时间电压不变）

## 考点7：停止等待协议超时 ⭐ S级 选择/简答

**2025B卷真题（选择题6）：** 在简单的停止-等待协议中，当帧出现丢失时，发送端会永远等待下去，解决这种死锁现象的办法是（ 超时机制 ）。

**标准答案：**

1. 停止等待协议：发送方每发送一帧后**停止**，等待接收方**确认(ACK)**后再发下一帧。
2. **死锁场景**：如果数据帧丢失或确认帧(ACK)丢失，发送方会**永久等待**，导致死锁。
3. **解决**：设置**超时计时器**。发送方发送帧后启动计时器，若在超时时间内未收到ACK，则**自动重传**该帧。
4. **注意**：超时后需要重传且保留帧的副本。接收方需要有**帧序号**来区分新帧和重传帧。

**常见考查方式：** 选择题（4选1选"超时"），或简答题问"如何解决停止等待死锁"。

## 考点8：直接交付与间接交付 ⭐ S级 简答

**2025B卷真题（简答38）：** 在广域网中，直接交付和间接交付有何不同？

**标准答案（4个评分点）：**

1. **直接交付（Direct Delivery）**：目的主机与源主机通过交换机/网桥**直接连接在同一物理网络**中。分组不需要经过路由器，直接在数据链路层通过MAC地址交付。发送方通过ARP直接解析目的主机的MAC地址。
2. **间接交付（Indirect Delivery）**：目的主机与源主机**不在同一网络**。分组需要经过一台或多台**路由器**逐跳转发。发送方将帧发送给**默认网关**（ARP解析网关MAC地址），由路由器根据路由表转发。
3. **判断标准**：源主机用目的IP与自己的子网掩码做AND运算，若与自己的网络地址相同 → 直接交付；否则 → 间接交付。
4. **举例**：同一局域网内A访问B = 直接交付；A访问百度服务器 = 间接交付。

**30秒口述版：** 同一子网不经过路由器=直接交付（ARP查目标MAC），跨子网经过路由器=间接交付（ARP查网关MAC）。

## 考点9：帧定界——标志字节 ⭐ A级 简答

**2025B卷真题（综合应用43）：** 一帧的开始和结束各用一个标志字节是否浪费？为什么不能用同一个标志字节？

**标准答案（3个评分点）：**

1. 如果数据链路层是**连续不断**传输的，用一个标志字节可以区分帧边界（上一个帧的结束标志 = 下一个帧的开始标志）。
2. 但如果一个帧结束后，**长时间没有新帧**（如静默15分钟），接收方无法区分下一个到来的字节是新帧的开始还是链路上的**噪声**干扰。
3. 采用**开始和结束各一个标志字节**，可以大大简化数据链路层协议设计，提高可靠性。
