## 四、简答题（5题，共30分）

### 26. TCP与UDP的主要区别（6分）

**标准答案(6个评分点，每个1分)：**
1. TCP面向连接；UDP无连接。
2. TCP提供可靠传输(确认+重传+序号)；UDP不可靠，尽最大努力交付。
3. TCP面向字节流(不保留报文边界)；UDP面向报文(保留报文边界)。
4. TCP有流量控制和拥塞控制；UDP没有。
5. TCP首部开销大(至少20B)；UDP首部固定8B。
6. TCP适用于Web/文件/邮件；UDP适用于DNS/视频/语音。

**部分正确给分：** 答出4点得4分，答出>4点按比例给分。

**常见错误：**
- TCP/UDP首部字节数写反(各扣1分)
- 面向字节流vs面向报文说反(扣1分)
- 漏写流量控制和拥塞控制(扣1分)

---

### 27. 数据链路层三个基本问题（6分）

**标准答案(3个评分点，每个2分)：**
1. **封装成帧**(2分)：在IP数据报前后添加首部和尾部，构成完整的帧，确定帧边界。
2. **透明传输**(2分)：采取字节填充或零比特填充等措施，使数据中的特殊比特组合(如帧定界符)不会被误判为控制信息。
3. **差错检测**(2分)：通过CRC等检错码检测传输过程中可能出现的比特错误，通常只检错不纠错。

**常见错误：** 透明传输说成加密(扣2分)、把差错检测说成自动纠错(扣1分)

---

### 28. CSMA/CD工作过程（6分）

**标准答案(6个评分点，每个1分)：**
1. **先听后发**(1分)：发送前监听信道，空闲则发送。
2. **边发边听**(1分)：发送过程中持续监听，检测冲突。
3. **冲突停止**(1分)：检测到冲突立即停止发送。
4. **强化碰撞**(1分)：发送人为干扰信号(jam signal)。
5. **随机重发**(1分)：采用截断二进制指数退避算法等待随机时间后重发。
6. **适用范围**(1分)：适用于半双工共享式以太网，现代全双工交换式以太网不使用。

---

### 29. 交换机自学习和转发过程（6分）

**标准答案(6个评分点，每个1分)：**
1. **收到帧**(1分)：记录帧进入的端口。
2. **自学习**(1分)：提取源MAC地址，将"源MAC→入端口"存入MAC地址表。
3. **查表转发**(1分)：查目的MAC在表中的端口，若存在则定向转发。
4. **泛洪**(1分)：若目的MAC未知(不在表中)，向除入端口外的所有端口泛洪。
5. **过滤**(1分)：若目的端口等于入端口，丢弃该帧。
6. **广播**(1分)：若目的MAC为全F(广播地址)，向同VLAN内所有端口转发。

---

### 30. 慢开始与拥塞避免（6分）

**标准答案(每个要点1-2分)：**
1. **慢开始**(2分)：cwnd从1 MSS开始，每经过一个RTT翻倍(指数增长)。名称"慢"是指起点低而非增长率慢。当cwnd≥ssthresh时，转入拥塞避免。
2. **拥塞避免**(2分)：每经过一个RTT，cwnd增加1 MSS(线性增长)，而不是翻倍。
3. **增长方式对比**(2分)：慢开始是指数增长(1→2→4→8...)，拥塞避免是线性增长(+1/RTT)。慢开始快速探测可用带宽，拥塞避免缓慢逼近网络容量上限。

**常见错误：** 说慢开始的增长率"慢"(扣分)、混淆两种增长方式(扣2分)

### 32. CRC（8分）

**标准答案：**
```
(1) G(x)=x⁴+x+1 → 二进制除数 = 10011            [1分]
    r = 4

(2) 数据M=1101011011, 补4个0 → 11010110110000    [1分]
    模2除法:
    11010110110000 ÷ 10011
    ...计算过程...
    余数 = 1110                                  [3分]

(3) 发送串 = 1101011011 + 1110 = 11010110111110  [2分]

(4) 余数=0表示: 未检测出错误(数据大概率正确)     [1分]
```

**评分点：**
- 二进制除数正确：1分
- 补0正确：1分
- 模2除法过程(至少画出前几步)：3分(步骤对但结果错得2分)
- 发送串正确：2分
- 含义表述正确：1分

**常见错误：** 二进制除数遗漏x²(0) → 写成1011(应为10011)、模2除法进位用普通减法而非XOR

### 33. TCP三次握手+数据传序号（8分）

**标准答案：**
```
三次握手:
(1) A→B: SYN=1, seq=100                        [1.5分]
(2) B→A: SYN=1, ACK=1, seq=300, ack=101        [1.5分]
(3) A→B: ACK=1, seq=101, ack=301                [1分]

数据传输:
(4) A→B: 数据400B, seq=101, ack=301             [2分]
(5) B→A: ACK, seq=301, ack=501                  [2分]
```

**评分点：**
- SYN消耗序号→ack=100+1=101 (1.5分)
- 服务器初始序号300 (0.5分)，ack=101(1分)
- 第三次：seq=101, ack=301 (1分)
- 数据段：seq=101, ack=301(1分), 数据400B(1分)
- 确认：seq=301, ack=101+400=501 (2分)

**常见错误：** SYN不消耗序号(ack=100)、ack=300+400写错方向、数据段seq写错

### 34. 最长前缀匹配（8分）

**标准答案：**
```
(1) 192.168.1.60:
    /24匹配: 192.168.1.0/24 → 网络192.168.1.0 ✓
    /26匹配: 192.168.1.0/26 → 192.168.1.0-63 ✓ (60在0-63)
    /27匹配: 192.168.1.64/27 → 64-95 ✗ (60不在)
    选最长前缀 → /26 → 下一跳 R2                  [2.5分]

(2) 192.168.1.80:
    /24 ✓, /26: 0-63 ✗(80>63),
    /27: 64-95 ✓(80在64-95)
    选最长前缀 → /27 → 下一跳 R3                  [2分]

(3) 192.168.1.128:
    /24 ✓, /26 ✗(128>63), /27 ✗(128>95)
    选 /24 → 下一跳 R1                            [1.5分]

(4) 192.168.2.50:
    无匹配
    使用默认路由0.0.0.0/0 → 下一跳 R4            [2分]
```

**评分点：** 每题2分。(1)2.5分因需排除/27。每条路由给出AND结果和是否匹配的判断给部分分。

**常见错误：** 选前缀最短的(应用/24而非/27)、忘记默认路由

### 35. 拥塞控制cwnd（8分）

**标准答案：**
```
RTT1: cwnd=1  (慢开始)          [1分]
RTT2: cwnd=2  (慢开始)          [1分]
RTT3: cwnd=4  (慢开始)          [1分]
RTT4: cwnd=8  (慢开始)          [1分]
RTT5: cwnd=16 (达ssthresh=16)   [1分]
RTT6: cwnd=17 (切换拥塞避免)     [1分]
RTT7: cwnd=18 (拥塞避免)        [1分]
RTT8: cwnd=19 (拥塞避免)        [1分]

在第5个RTT当cwnd达到16时，第6个RTT切换为拥塞避免。
```

**评分点：** 每个RTT的cwnd值各1分，共8分。

**常见错误：** RTT5写16后RTT6写32(忘记切换)、RTT1从0开始
