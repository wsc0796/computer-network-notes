## 四、简答题（共30分）

### 1. TCP 与 UDP 的区别（6分）

评分点：

1. TCP 面向连接，UDP 无连接。  
2. TCP 可靠，UDP 尽力交付。  
3. TCP 保证按序到达，UDP 不保证。  
4. TCP 面向字节流，UDP 面向报文。  
5. TCP 有流量控制和拥塞控制。  
6. UDP 首部固定 8 字节。  

### 2. 流量控制与拥塞控制的区别（6分）

评分点：

1. 流量控制保护接收方。  
2. 拥塞控制保护网络。  
3. 流量控制主要依据 `rwnd`。  
4. 拥塞控制主要依据 `cwnd`。  
5. 二者解决的问题不同。  
6. 发送窗口通常取 `min(rwnd, cwnd)`。  

### 3. 停止等待、GBN、SR 的区别（6分）

评分点：

1. 停止等待一次只能有 1 个未确认帧。  
2. GBN 是多帧窗口协议。  
3. GBN 采用累计确认。  
4. GBN 出错后从出错帧开始回退重传。  
5. SR 允许缓存乱序帧。  
6. SR 只重传丢失或出错帧，窗口通常不超过序号空间一半。  

### 4. RIP 工作原理（6分）

评分点：

1. RIP 是距离向量协议。  
2. 用跳数作为度量。  
3. 周期性交换路由表。  
4. 收到邻居通告后先加 1。  
5. 同一下一跳变差也要更新。  
6. 16 表示不可达。  

### 5. CSMA/CD 工作过程（6分）

评分点：

1. 发送前先监听。  
2. 空闲才发送。  
3. 发送时继续监听。  
4. 检测到冲突立即停止。  
5. 发送干扰信号。  
6. 按二进制指数退避后重传。  

## 五、大题（共40分）

### 1. 物理层题（10分）

1. 奈奎斯特：  
`最高比特率 = 2W log2V = 2 × 3000 × log2 8 = 18000 bit/s`。  
答案：`18 kb/s`。（4分）

2. 发送时延：  
`1 MB = 8 Mb`，  
`发送时延 = 8 Mb / 10 Mb/s = 0.8 s`。（3分）

3. 传播时延：  
`1000 km = 10^6 m`，  
`传播时延 = 10^6 / (2 × 10^8) = 0.005 s = 5 ms`。（3分）

评分点：

- 奈奎斯特公式和代入 2分，结果 2分。  
- 发送时延公式 1分，单位换算 1分，结果 1分。  
- 传播时延公式 1分，单位换算 1分，结果 1分。  

### 2. 数据链路层题（10分）

#### 第(1)问 CRC（5分）

`G(x)=x^3+1`，除数为 `1001`。  
原数据 `1011110` 后补 3 个 0，得 `1011110000`。  
模2除余数为 `100`。  
发送比特串为 `1011110100`。

评分点：

- 写出除数 `1001`，1分。  
- 补 3 个 0，1分。  
- 模2除过程正确，2分。  
- 写出发送比特串，1分。  

#### 第(2)问 交换机 MAC 表（5分）

第一帧：从端口 3 进入，源 `D1`，目的 `B1`。  

- 交换机先学习 `D1 -> 3`。  
- 查到 `B1 -> 2`，因此只从端口 2 转发。  

第二帧：从端口 2 进入，源 `B1`，目的 `E1`。  

- 表中已有 `B1 -> 2`，保持或刷新该项。  
- 查不到 `E1`，因此除入端口 2 外，对其余端口泛洪。  

最终交换表新增 `D1 -> 3`，其余原表项保留。

评分点：

- 第一帧学习 `D1 -> 3`，1分。  
- 第一帧只发端口 2，1分。  
- 第二帧保留/刷新 `B1 -> 2`，1分。  
- 第二帧对未知目的泛洪，1分。  
- 写出最终表变化，1分。  

### 3. 网络层题（10分）

1. 目的 IP `192.168.10.130` 同时匹配 `/16`、`/24`、`/25`，最长前缀为 `192.168.10.128/25`，所以下一跳为 `R3`。（2分）

2. `192.168.20.0/24` 等长划分为 4 个子网，需要借 2 位，前缀变为 `/26`。  

- `192.168.20.0/26`
- `192.168.20.64/26`
- `192.168.20.128/26`
- `192.168.20.192/26`

（3分）

3. 邻居 X 通告到网络 N 的距离为 4，本路由器记入的新距离应为 `5`，因为 RIP 收到邻居通告后要先加 1。（2分）

4. 原数据长度：`3820 - 20 = 3800B`。  
每片最大数据：`1500 - 20 = 1480B`。  
除最后一片外，每片数据长度必须为 8 字节整数倍，1480 满足要求。  
分片结果：

- 第1片：数据 1480B，片偏移 `0`，`MF=1`
- 第2片：数据 1480B，片偏移 `1480/8 = 185`，`MF=1`
- 第3片：数据 `3800 - 1480 - 1480 = 840B`，片偏移 `(1480 + 1480)/8 = 370`，`MF=0`

（3分）

评分点：

- 最长前缀选 `R3`，2分。  
- 四个 `/26` 子网写对一个给 0.75 分，共 3 分。  
- RIP 加 1 写对 1分，说明原因 1分。  
- 分片数据长度 1分，偏移 1分，`MF` 1分。  

### 4. 运输层题（10分）

1. 三次握手：  

- A 发 SYN：`seq=1000`
- B 发 SYN+ACK：`seq=5000, ack=1001`
- A 发 ACK：`seq=1001, ack=5001`

（3分）

2. A 发送 300B 数据时：  

- 数据段 `seq=1001`
- B 返回确认号 `ack=1301`

（2分）

3. A 发送 FIN：  

- `FIN` 报文段 `seq=1301`
- B 返回确认号 `ack=1302`

（2分）

4. 拥塞控制按课程简化模型：  

- 当前 `cwnd=20 MSS`，收到 3 个重复 ACK：  
  `ssthresh = 20 / 2 = 10 MSS`  
  `cwnd = ssthresh = 10 MSS`
- 之后若又发生超时：  
  `ssthresh = 10 / 2 = 5 MSS`  
  `cwnd = 1 MSS`

（3分）

评分点：

- 握手三报文 3分。  
- 300B 数据的 `seq/ack` 2分。  
- `FIN` 的 `seq/ack` 2分。  
- 3 重复 ACK 的新值 1.5分，超时后的新值 1.5分。  

## 判定标准

- 90分及以上：通过本轮闭卷训练。
- 80-89分：还不算稳定90分，必须按错题类型回模板重做。
- 任何红线错误出现：即使总分达到90，也不能直接判定为稳定90分。
