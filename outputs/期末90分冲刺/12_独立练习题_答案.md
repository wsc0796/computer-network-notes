### 40. CRC

```

补4个0: 10100011010000
模2除法: 10100011010000 ÷ 10011

```

### 43. TCP数据传输

```

(1) A→B: 数据200B, seq=500, ack=800
(2) B→A: 纯ACK, seq=800, ack=700 (=500+200)
(3) B→A: 数据150B, seq=800, ack=700
(4) A→B: ACK, seq=700, ack=950 (=800+150)
```

### 46. RIP更新

```
R1发来的每条+1跳: N1=4, N2=3, N4=4

N1: 自己表N1=2(R1), 收到4(同下一跳R1) → 替换为4(R1)
N2: 自己表N2=1(直连), 收到3(下一跳R1) → 1<3且下一跳不同 → 不更新
N3: 自己表N3=5(R2), 收到表无N3 → 保持不变
N4: 自己表无N4 → 添加 N4=4(R1)

更新后表:
N1=4(R1), N2=1(直连), N3=5(R2), N4=4(R1)
```

### 47. CSMA/CD

```
(1) 2τ = 2×2000/(2×10^8) = 20 μs
    Lmin = 100×10^6 × 20×10^-6 = 2000 bit = 250 Byte

(2) 64B = 512 bit
    2τ = 512/(100×10^6) = 5.12 μs
    d = 5.12×10^-6 × 2×10^8 / 2 = 512 m
    本题距离2000m > 512m → 64B帧不够，无法正常检测冲突
```

### 48. 交换机MAC表

```
初始: 空

(1) A→B: 学习A→1, 查B→未知→泛洪(端口2,3)
    MAC表: A→1

(2) B→A: 学习B→2, 查A→端口1→定向转发到端口1
    MAC表: A→1, B→2

(3) A→C: 查A(已知,同端口→跳过学习), 查C→未知→泛洪(端口2,3)
    MAC表: A→1, B→2 (A已存在不更新)

(4) C→A: 学习C→3, 查A→端口1→定向转发到端口1
    MAC表: A→1, B→2, C→3
```
