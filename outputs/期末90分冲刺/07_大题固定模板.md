# 07 大题固定模板

使用规则：每类题都按“识别 -> 基础题 -> 变式题 -> 完整答案 -> 评分点 -> 保分步骤”来套。不会完整做时，先拿保分步骤保底。

## 1. 物理层公式题

识别：题干给带宽、码元状态数、信噪比、数据长度、发送速率、传播距离。

基础题：带宽 `3kHz`，每码元 `8` 种状态，求最高比特率。  
变式题：带宽 `3kHz`，信噪比 `30dB`，发送 `1MB` 数据，经 `10Mb/s`、`1000km` 链路，求香农容量、发送时延、传播时延。

完整答案：

- 奈奎斯特：`2Wlog2V = 2 × 3000 × 3 = 18000bit/s`
- 香农：`S/N = 10^(30/10) = 1000`，`C = 3000log2(1001)`，约 `30000bit/s`
- 发送时延：`8Mb / 10Mb/s = 0.8s`
- 传播时延：`10^6 / (2 × 10^8) = 0.005s`

评分点：

1. 看出用奈奎斯特还是香农，2分。
2. 公式写对，2分。
3. 单位换算正确，2分。
4. 结果正确，4分。

不会完整做时的保分步骤：

1. 先把公式写出来。
2. 把 `dB` 转普通比值。
3. 即使算不完，也把 `L/R`、`d/v` 写出来保公式分。

## 2. CRC题

识别：给数据比特串和生成多项式，要求求余数或发送串。

基础题：`1011110`，`G(x)=x^3+1`。  
变式题：`1101011`，`G(x)=x^3+x+1`。

完整答案：

- 基础题：除数 `1001`，补 3 个 0 得 `1011110000`，余数 `100`，发送串 `1011110100`
- 变式题：除数 `1011`，补 3 个 0 得 `1101011000`，余数 `110`，发送串 `1101011110`

评分点：

1. 多项式转除数，2分。
2. 后补 `r` 个 0，2分。
3. 模2除过程，4分。
4. 写出余数和发送串，2分。

不会完整做时的保分步骤：

1. 先写除数。
2. 写出补0后的串。
3. 明确“模2除法，不借位不进位”，先保前 4 分。

## 3. CSMA/CD题

识别：给距离、传播速率、数据率，求最短帧长；或要求叙述工作过程。

基础题：距离 `2km`，传播速率 `2×10^8m/s`，数据率 `100Mb/s`，求最短帧长。  
变式题：解释为什么最短帧长必须不小于 `2τ × 数据率`。

完整答案：

- `τ = 2000 / (2 × 10^8) = 10us`
- `2τ = 20us`
- 最短帧长 `= 100 × 10^6 × 20 × 10^-6 = 2000bit = 250B`
- 原因：如果帧太短，站点在最远冲突信号返回前就发完了，检测不到冲突

评分点：

1. 传播时延算对，3分。
2. 写出 `2τ`，2分。
3. 帧长计算对，3分。
4. 解释最短帧长意义，2分。

不会完整做时的保分步骤：

1. 先写 `τ = 距离/传播速率`。
2. 再写 `最短帧长 = 2τ × 数据率`。
3. 记不住结果也要写“为保证冲突能被检测到”。

## 4. 交换机 MAC 地址表题

识别：给若干帧的入端口、源 MAC、目的 MAC，要求写学习和转发结果。

基础题：表中有 `A1->1, B1->2, C1->4`，有一帧从端口 3 进入，源 `D1`，目的 `B1`。  
变式题：再加一帧从端口 2 进入，源 `B1`，目的 `E1`。

完整答案：

- 第一帧先学习 `D1 -> 3`
- 查到 `B1 -> 2`，只从端口 2 转发
- 第二帧保留或刷新 `B1 -> 2`
- `E1` 未知，除入端口 2 外泛洪
- 最终表新增 `D1 -> 3`

评分点：

1. 先学源 MAC，2分。
2. 已知目的定向转发，2分。
3. 未知目的泛洪，2分。
4. 最终表项变化写对，4分。

不会完整做时的保分步骤：

1. 先写“交换机根据源 MAC 学习”。
2. 再分“已知目的”和“未知目的”两种情况。
3. 即使端口算不全，也先写“未知目的泛洪”。

## 5. GBN/SR题

识别：题干给序号位数、窗口、累计确认或乱序缓存。

基础题：序号字段 `3` 位，GBN 中发送方已经发出 `0-5`，收到 `ACK3` 后还能发送哪些序号。  
变式题：同样 `3` 位序号，问 SR 的最大发送窗口是多少，并说明为什么。

完整答案：

- GBN 中 `ACK3` 的统一语义：`0、1、2` 已按序收到，下一步期待 `3`
- 若原发送窗口为 `0-6`，收到 `ACK3` 后窗口基序号滑到 `3`，新窗口覆盖 `3、4、5、6、7、0、1`
- 因此仍可继续发送 `6、7、0、1`
- SR 的最大发送窗口为 `2^(3-1)=4`

评分点：

1. 写出 `ACK3` 的语义，3分。
2. 写出滑窗后可继续发送 `6、7、0、1`，4分。
3. 写出 SR 窗口不超过序号空间一半，3分。

不会完整做时的保分步骤：

1. 先把 `ACK3` 写成“期待3”。
2. 先画一个 0-7 的环。
3. 即使不会全推，也先把 `6、7` 写出来，再检查是否还能回绕写 `0、1`。

## 6. 子网与 CIDR 题

识别：给一个网段，要求等长划分或求网络地址、广播地址。

基础题：`192.168.20.0/24` 划成 4 个等长子网。  
变式题：给 `172.16.33.75/20`，求网络地址和广播地址。

完整答案：

- `/24` 划 4 个子网，需要借 2 位，变为 `/26`
- 四个子网：`192.168.20.0/26`、`192.168.20.64/26`、`192.168.20.128/26`、`192.168.20.192/26`
- `172.16.33.75/20` 的第三字节块大小为 16，`33` 落入 `32-47`
- 网络地址 `172.16.32.0`，广播地址 `172.16.47.255`

评分点：

1. 新前缀写对，2分。
2. 网络地址写对，4分。
3. 广播地址写对，2分。
4. 地址块边界解释清楚，2分。

不会完整做时的保分步骤：

1. 先算块大小。
2. 网络地址先写主机位全 0。
3. 广播地址先写主机位全 1。

## 7. 最长前缀匹配题

识别：给路由表和目的 IP，问下一跳。

基础题：目的 `192.168.10.130`，表有 `/16`、`/24`、`/25`、默认路由。  
变式题：在上题基础上加入一条不匹配的更长前缀，问是否能选。

完整答案：

- 匹配项为 `192.168.0.0/16`、`192.168.10.0/24`、`192.168.10.128/25`
- 其中 `/25` 最长，所以下一跳选 `R3`
- `0.0.0.0/0` 只有在无更具体匹配时才作为默认路由使用

评分点：

1. 找出全部匹配项，4分。
2. 选出前缀最长者，4分。
3. 说明默认路由是兜底项，2分。

不会完整做时的保分步骤：

1. 先把每条前缀长度写出来。
2. 即使不确定，也先圈出最具体的那条。
3. 明确 `0.0.0.0/0` 是默认路由，不是 `0.0.0.0`。

## 8. RIP 更新题

识别：给本地路由表和邻居通告，问是否更新。

基础题：原到网络 N 的距离为 `3`，下一跳 `R1`；收到 `R1` 通告到 N 的距离为 `8`。  
变式题：原到网络 N 的距离为 `3`，下一跳 `R1`；收到 `R2` 通告到 N 的距离为 `1`。

完整答案：

- 同一下一跳 `R1` 的通告要先加 1，得到新距离 `9`
- 虽然变差，但因为来自同一下一跳，仍然更新为 `9`
- 若来自 `R2` 的距离为 `1`，先加 1 得 `2`，比原来的 `3` 更短，则改为走 `R2`
- 距离 `16` 记为不可达

评分点：

1. 先加 1，3分。
2. 同一下一跳变差也更新，3分。
3. 不同下一跳更短时替换，2分。
4. 16 不可达，2分。

不会完整做时的保分步骤：

1. 每次先把收到的距离旁边写 `+1`。
2. 再判断“同一路由器发来的”还是“不同路由器发来的”。
3. 最后才比较大小。

## 9. IP 分片题

识别：给总长度、首部长度、MTU，要求写分片数据长度、偏移和 `MF`。

基础题：总长度 `3820B`，首部 `20B`，MTU `1500B`。  
变式题：总长度 `4000B`，首部 `20B`，MTU `1500B`。

完整答案：

- 原数据长度 `= 3820 - 20 = 3800B`
- 每片最大数据 `= 1500 - 20 = 1480B`
- 除最后一片外，每片数据长度必须为 8 字节整数倍
- 分片结果：`1480, 1480, 840`
- 片偏移：`0, 185, 370`
- `MF`：`1, 1, 0`

评分点：

1. 原数据长度算对，2分。
2. 每片最大数据算对，2分。
3. 分片数据长度写对，2分。
4. 片偏移写对，2分。
5. `MF` 写对，2分。

不会完整做时的保分步骤：

1. 先把“总长度减首部”写出来。
2. 再把“MTU减首部”写出来。
3. 即使后面不会分，也先写“除最后一片外，每片数据长度必须为 8 字节整数倍”。

## 10. TCP seq/ack 题

识别：题干给初始序号、数据字节数、SYN、FIN。

基础题：A 初始 `1000`，B 初始 `5000`，A 发送 `300B` 数据后再发 `FIN`。  
变式题：同题，但中间插入一次 B 向 A 发送 `200B` 数据。

完整答案：

- A 发 SYN：`seq=1000`
- B 发 SYN+ACK：`seq=5000, ack=1001`
- A 发 ACK：`seq=1001, ack=5001`
- A 发 `300B` 数据：`seq=1001`
- B 回 ACK：`ack=1301`
- A 发 FIN：`seq=1301`
- B 回 ACK：`ack=1302`

评分点：

1. 三次握手三个关键 `seq/ack`，4分。
2. 数据段起始 `seq` 与确认号，3分。
3. `FIN` 和其确认号，3分。

不会完整做时的保分步骤：

1. 先单独写：`SYN +1`，`FIN +1`，纯 ACK `+0`。
2. 再写“发送 N 字节就消耗 N 个序号”。
3. 最后按时间顺序列式子，不要心算。

## 11. TCP 流量控制与拥塞控制题

识别：题干给 `rwnd`、`cwnd`、`ssthresh`、超时、3 个重复 ACK。

基础题：`rwnd=12 MSS`，`cwnd=20 MSS`，发送窗口是多少；发生 3 个重复 ACK 后按课程简化模型写新值。  
变式题：题目明确写“按 TCP Reno”，当前 `cwnd=24 MSS`，收到 3 个重复 ACK，写快恢复入口和退出时的 `cwnd`。

完整答案：

- 实际发送窗口 `= min(rwnd, cwnd)`
- 课程简化模型：
  `ssthresh = 当前cwnd/2`
  `cwnd = ssthresh`
- 若随后超时：
  `ssthresh = 当前cwnd/2`
  `cwnd = 1 MSS`
- 若题目明确按 TCP Reno：
  `ssthresh = 当前cwnd/2`
  快恢复入口 `cwnd = ssthresh + 3 MSS`
  收到确认新数据的 ACK 后 `cwnd = ssthresh`

评分点：

1. `min(rwnd, cwnd)`，2分。
2. 区分课程简化模型和明确 Reno 口径，2分。
3. 3 个重复 ACK 后的新 `ssthresh`，2分。
4. 3 个重复 ACK 后的新 `cwnd`，2分。
5. 超时后的新 `ssthresh/cwnd`，2分。

不会完整做时的保分步骤：

1. 先写 `min(rwnd, cwnd)`。
2. 再判断题目是“课程简化模型”还是“明确 Reno”。
3. 即使记不全，也先写：超时 `cwnd=1`；3 重复 ACK 一定不是回到 1。
