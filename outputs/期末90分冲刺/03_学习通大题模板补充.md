# 03_学习通大题模板补充

> 重点补老师最爱用的“公式 + 步骤 + 口径”题。

## 数据链路层滑动窗口与信道利用率

识别题型：
停止等待、连续 ARQ、GBN、SR、窗口上限、信道利用率、满利用率窗口反求。

固定公式：
`Tf = L / R`

`Tack = Lack / Rack`

`T = Tf + RTT + Tack`

`U = min(1, Ws × Tf / (Tf + RTT + Tack))`

`Ws_min = ceil((Tf + RTT + Tack) / Tf)`

窗口上限：
GBN：`Ws ≤ 2^n - 1`，`Wr = 1`
SR：`Ws ≤ 2^(n-1)`，`Wr ≤ 2^(n-1)`
停止等待：`Ws = 1`

解题步骤：
1. 先统一单位，算 `Tf`。
2. 再算 `Tack`，题目若明确可忽略才可近似为 0。
3. 用题目给的 RTT，不要把 RTT 当单程时延。
4. 代入 `U`，结果不能超过 1。
5. 反求窗口时，用 `Ws_min`。

高频陷阱：
- 发送时延不是传播时延。
- RTT 不是单程传播时延。
- 链路层 GBN/SR 窗口不是 TCP 的 `rwnd/cwnd`。
- ACK 发送时间是否忽略必须看题干。

## 时延计算

识别题型：
发送时延、传播时延、总时延、RTT。

公式：
`发送时延 = L / R`
`传播时延 = D / V`
`总时延 = 发送 + 传播 + 处理 + 排队`

## CRC

步骤：
1. 生成多项式转二进制。
2. 补 `r` 个 0。
3. 模 2 除。
4. 余数接在原数据后。

## 子网/CIDR

步骤：
1. 找前缀。
2. 算块大小。
3. 写网络地址、广播地址、可用范围。
4. 路由匹配时选最长前缀。

## RIP

步骤：
1. 邻居通告跳数先 +1。
2. 同下一跳无条件替换。
3. 不同下一跳仅更小才替换。
4. 16 表示不可达。

## TCP 序号确认号

步骤：
1. seq 是本段首字节序号。
2. ack 是期望收到的下一字节序号。
3. SYN/FIN 各消耗 1 个序号。
4. 纯 ACK 不消耗序号。

## 慢开始和拥塞避免

步骤：
1. 慢开始：cwnd 翻倍。
2. 到 ssthresh 后转拥塞避免。
3. 拥塞避免：每 RTT 约 +1 MSS。
4. 超时后 `ssthresh = cwnd/2`，`cwnd = 1 MSS`。
