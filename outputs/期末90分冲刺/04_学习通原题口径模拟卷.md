# 04_学习通原题口径模拟卷

> 结构：选择10分、判断10分、填空10分、简答30分、大题40分。  
> 口径：优先贴近学习通老师原话，避免超出课程范围。

## A卷

### 一、选择题（10分）

1. 协议控制的是（ ）。A.对等实体 B.相邻层实体 C.主机硬件 D.传输介质
2. 物理层 PDU 是（ ）。A.帧 B.比特 C.段 D.报文
3. `Base` 在 10Base-T 中表示（ ）。A.宽带 B.基带 C.总线 D.广播
4. `PPP` 的特点是（ ）。A.提供可靠传输 B.点到点但不保证可靠 C.只用于广播信道 D.一定使用滑动窗口
5. 交换机自学习依据的是（ ）。A.目的 MAC B.源 MAC C.源 IP D.目的 IP
6. `ARP` 跨网段时解析的是（ ）。A.远端主机 MAC B.默认网关 MAC C.DNS MAC D.广播 MAC
7. TCP 确认号表示（ ）。A.最后收到的字节 B.期望收到的下一个字节 C.本段长度 D.窗口大小
8. `TIME-WAIT` 出现在（ ）。A.被动关闭方 B.主动关闭方 C.双方同时 D.服务器一定
9. `rwnd` 表示（ ）。A.网络拥塞程度 B.接收端能力 C.发送方带宽 D.路由器缓存
10. `IPv6` 路由器对过大数据报的处理是（ ）。A.分片 B.丢弃 C.暂存 D.广播

### 二、判断题（10分）

1. `PPP` 提供可靠传输。  
2. `网桥` 能隔离广播域。  
3. `ARP` 广播可穿越路由器。  
4. `TCP` 确认号是期望的下一字节序号。  
5. `TCP` 发送窗口取 `min(rwnd, cwnd)`。  
6. `NRZ` 没有同步信息。  
7. `曼彻斯特` 有同步信息。  
8. `IPv6` 路由器可以分片。  
9. `半关闭` 是一边关发送方向、一边还能收。  
10. `SYN` 不消耗序号。  

### 三、填空题（10分）

1. 协议三要素是____、____、____。  
2. 数据链路层三个基本问题是____、____、____。  
3. MAC 地址长度为____ bit。  
4. `SAP` 是____。  
5. `TCP` 连接建立过程是____。  
6. `Tcp` 连接释放后的主动关闭方通常进入____。  

### 四、简答题（30分）

1. 简述协议与服务的区别和联系。
2. 简述 IP 服务特点。
3. 简述 ARP 跨网工作流程。
4. 简述 TCP 与 UDP 的区别。
5. 简述流量控制与拥塞控制的区别。

### 五、大题（40分）

1. 时延计算题：给出 `L/R/D/V`，求发送时延、传播时延和总时延。
2. CRC 题：给出数据串和生成多项式，求余数和发送串。
3. 子网/CIDR 题：给出地址与前缀，求网络地址、广播地址、可用范围。
4. TCP 序号确认号题：给出 seq/ack/数据长度，求回复段。
5. 数据链路层滑动窗口与信道利用率题：给出 `L、R、RTT、Lack、Rack、Ws、n`，求 `U` 和 `Ws_min`。

## B卷

### 一、选择题（10分）

1. `SAP` 表示（ ）。A.服务访问点 B.服务原语 C.对等实体 D.网络号
2. `MAC` 服务特点是（ ）。A.无连接不可靠 B.可靠有连接 C.端到端 D.面向报文
3. `Rwnd` 表示（ ）。A.接收端能力 B.网络拥塞程度 C.最短帧长 D.传播时延
4. `GBN` 接收窗口通常为（ ）。A.1 B.2 C.4 D.8
5. `SR` 发送窗口上限通常为（ ）。A.2^n-1 B.2^(n-1) C.2^n D.1
6. `Ping` 使用（ ）。A.ARP B.ICMP C.TCP D.UDP
7. `ARP` 请求报文通常以（ ）发送。A.单播 B.广播 C.组播 D.任播
8. `半关闭` 说明（ ）。A.双方都不能收发 B.一边关发送一边还能收 C.只关接收 D.连接失效
9. `IPv4` 固定首部长度为（ ）。A.8B B.20B C.40B D.64B
10. `TCP` 拥塞控制看（ ）。A.rwnd B.cwnd C.SAP D.MTU

### 二、判断题（10分）

1. `TCP/IP` 课堂上一定按 5 层作答。  
2. `网桥` 与 `二层交换机` 都不隔离广播域。  
3. `确认帧发送时间` 永远可以忽略。  
4. `RTT` 等于单程传播时延。  
5. `U` 可以超过 1。  
6. `TCP` 连接释放是四次挥手。  
7. `SYN` 和 `FIN` 各消耗 1 个序号。  
8. `ICMP` 封装在 IP 中。  
9. `A/B/C` 类地址题已经完全失效。  
10. `PPP` 不提供可靠传输。  

### 三、填空题（10分）

1. `U = min(1, Ws × Tf / (Tf + ____ + ____))`。  
2. `Ws_min = ceil((Tf + RTT + Tack) / ____)`。  
3. `GBN`：`Ws ≤ ____`，`Wr = 1`。  
4. `SR`：`Ws ≤ ____`，`Wr ≤ ____`。  
5. `TCP` 确认号是期望收到的____。  
6. `TCP` 半关闭后仍可____对方数据。  

### 四、简答题（30分）

1. 交换机与网桥、集线器、路由器的区别。
2. 说明 TCP 三次握手和四次挥手。
3. 说明停止等待、GBN、SR 的窗口关系。
4. 说明老师口径中的四层与五层差别。
5. 说明数据链路层信道利用率公式中各量的含义。

### 五、大题（40分）

1. 停止等待协议利用率题。
2. GBN 窗口和利用率题。
3. SR 窗口和利用率题。
4. 反求 100% 利用率最小窗口题。
5. 综合题：TCP 序号 + 拥塞控制 + 半关闭。
