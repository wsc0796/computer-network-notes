# 08 闭卷训练卷

说明：本卷按真实题型结构改写。满分 100 分，建议总时长 100 分钟，其中客观题 25 分钟，简答题 25 分钟，大题 50 分钟。本卷不含应用层。

## 一、选择题（10题，每题1分，共10分）

1. 下列设备与层次对应正确的是（  ）  
A. 集线器-网络层  B. 交换机-数据链路层  C. 路由器-运输层  D. 网卡-应用层

2. 关于发送时延和传播时延，下列说法正确的是（  ）  
A. 发送时延只与距离有关  
B. 传播时延只与比特数有关  
C. 发送时延与发送速率有关，传播时延与传播距离有关  
D. 二者都只与带宽有关

3. 奈奎斯特公式适用于（  ）  
A. 有噪声信道极限容量  
B. 理想低通信道最高比特率  
C. 路由最短路径计算  
D. TCP拥塞控制

4. 对于共享式有线以太网，CSMA/CD 的核心特点是（  ）  
A. 先发后听  B. 先听后发并边发边听  C. 先冲突后退避  D. 只用于无线局域网

5. 交换机收到一个目的 MAC 未知的帧时，通常会（  ）  
A. 只发给默认网关  
B. 直接丢弃  
C. 除入端口外泛洪  
D. 改写目的 MAC 后再转发

6. `0.0.0.0` 与 `0.0.0.0/0` 的区别是（  ）  
A. 前者是默认路由，后者是本地回环  
B. 前者是未指定地址，后者可表示默认路由  
C. 前者和后者含义完全相同  
D. 前者用于广播，后者用于单播

7. RIP 中一条路由的跳数达到 16 时，表示该目的网络（  ）  
A. 代价最低  B. 仍然可达  C. 不可达  D. 需要分片

8. IPv4 分片中，片偏移字段的单位是（  ）  
A. bit  B. 字节  C. 4字节  D. 8字节

9. TCP 中真正限制发送窗口上限的是（  ）  
A. `max(rwnd, cwnd)`  
B. `min(rwnd, cwnd)`  
C. `rwnd + cwnd`  
D. 只看 `cwnd`

10. 下列关于 TCP 序号和确认号的说法正确的是（  ）  
A. 纯 ACK 也要占用 1 个序号  
B. ACK 号表示已经收到的最后一个字节序号  
C. SYN 和 FIN 都各占用 1 个序号  
D. 发送 100B 数据只占用 1 个序号

## 三、判断题（10题，每题1分，共10分）

1. 香农公式考虑了信噪比。  
2. 曼彻斯特编码每个比特中间都有跳变。  
3. GBN 中，`ACK3` 表示 0、1、2 已按序收到，下一步期待 3。  
4. SR 接收方不能缓存乱序帧。  
5. `0.0.0.0/0` 常用来表示默认路由。  
6. 除最后一片外，每片数据长度都必须是 8 字节整数倍。  
7. RIP 接收邻居通告后，应先把距离加 1 再比较。  
8. TCP 流量控制主要看 `cwnd`。  
9. TCP 纯 ACK 不占用序号。  
10. 三次重复 ACK 触发快重传，不必等待超时。

## 五、大题（4题，共40分）

### 1. 物理层题（10分）

某理想低通信道带宽为 `3 kHz`，每个码元有 `8` 种状态。

1. 用奈奎斯特公式求该信道的最高比特率。（4分）
2. 若要发送一个 `1 MB` 的文件，经过 `10 Mb/s` 链路，发送时延是多少？（3分）
3. 若链路长度为 `1000 km`，信号传播速率为 `2 × 10^8 m/s`，传播时延是多少？（3分）

### 2. 数据链路层题（10分）

1. 数据比特串为 `1011110`，生成多项式为 `x^3 + 1`。求除数、CRC 余数和发送比特串。（5分）
2. 某交换机当前 MAC 地址表如下：  

| MAC地址 | 端口 |
| --- | --- |
| A1 | 1 |
| B1 | 2 |
| C1 | 4 |

现有一帧从端口 `3` 进入，源 MAC 为 `D1`，目的 MAC 为 `B1`。再有一帧从端口 `2` 进入，源 MAC 为 `B1`，目的 MAC 为 `E1`。分别写出两帧的转发结果，以及两帧处理后交换表的变化。（5分）

### 3. 网络层题（10分）

已知某路由器收到目的 IP 为 `192.168.10.130` 的数据报，其路由表如下：

| 目的网络 | 下一跳 |
| --- | --- |
| 192.168.0.0/16 | R1 |
| 192.168.10.0/24 | R2 |
| 192.168.10.128/25 | R3 |
| 0.0.0.0/0 | R4 |

另有地址块 `192.168.20.0/24` 需要等长划分为 4 个子网；一条来自邻居 X 的 RIP 通告写着到网络 N 的距离为 `4`；某 IPv4 数据报总长度 `3820B`、首部 `20B`，经过 MTU 为 `1500B` 的链路。

1. 对于目的 IP `192.168.10.130`，应按最长前缀匹配转发到哪个下一跳？（2分）
2. 把 `192.168.20.0/24` 等长划分为 4 个子网，写出四个子网的网络地址和前缀。（3分）
3. 对于网络 N，路由器经邻居 X 学到的新距离应记为多少？为什么？（2分）
4. 对该数据报进行分片，写出各分片的数据长度、片偏移和 `MF`。（3分）

### 4. 运输层题（10分）

主机 A 的初始序号为 `1000`，主机 B 的初始序号为 `5000`。A 与 B 建立 TCP 连接后，A 发送 `300B` 数据，B 确认；随后 A 发送 `FIN`。另外，某时刻 `cwnd=20 MSS`，`ssthresh=16 MSS`，之后先收到 `3` 个重复 ACK，再在后续传输中发生超时。

1. 写出三次握手三个关键报文中的 `seq/ack`。（3分）
2. 写出 A 发送 `300B` 数据时的数据段 `seq`，以及 B 返回的确认号。（2分）
3. 写出 A 发送 `FIN` 时的 `seq`，以及 B 返回的确认号。（2分）
4. 若题目按“课程简化模型”处理 3 个重复 ACK，则新的 `ssthresh` 和 `cwnd` 各是多少？若后续又发生超时，再写新的 `ssthresh` 和 `cwnd`。（3分）
