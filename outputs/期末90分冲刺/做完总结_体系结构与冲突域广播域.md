## 二、三大对应关系（选择题填空必考）

### 2.1 设备 ↔ 所在层

| 设备 | 所在层 | 能不能隔离冲突域 | 能不能隔离广播域 |
|:----|:------|:--------------:|:--------------:|
| 中继器/集线器 | **物理层** | ✗ | ✗ |
| 网桥/交换机 | **数据链路层** | ✓ | ✗ |
| 路由器 | **网络层** | ✓ | ✓ |

> **记忆口诀：** 集物交链路路网
> （集线器=物理层, 交换机=数据链路层, 路由器=网络层）

### 2.2 PDU ↔ 所在层

| 层 | PDU名称 | 英文 |
|:---|:-------|:----|
| 物理层 | **比特** | Bit |
| 数据链路层 | **帧** | Frame |
| 网络层 | **数据报/分组** | Packet/Datagram |
| 运输层 | **段** | Segment |
| 应用层 | **报文** | Message |

> **记忆口诀：** 比帧数段报（从下到上：比特→帧→数据报→段→报文）

### 2.3 地址 ↔ 所在层

| 地址类型 | 长度 | 所在层 | 用途 |
|:--------|:---:|:------|:----|
| MAC地址 | **48bit**(6B) | 数据链路层 | 标识网卡，同一链路内寻址 |
| IP地址 | **32bit**(4B) | 网络层 | 标识主机，跨网络寻址 |
| 端口号 | **16bit**(2B) | 运输层 | 标识进程，端到端通信 |

## 三、冲突域 vs 广播域（简答高频）

### 3.1 定义速记

```
冲突域 = 同一时刻只能有一台设备发数据的范围
       └── 两台同时发就会"撞车"(冲突)

广播域 = 广播帧能传到的范围
       └── 你发一个广播，谁收得到谁就在同一广播域
```

### 3.2 四类设备对比

```
                     冲突域       广播域
                  ──────────  ──────────
集线器(Hub)      所有端口一起    一个广播域
交换机(Switch)   每端口独立      一个广播域
路由器(Router)   每端口独立      每端口独立
VLAN划分         每端口独立      每VLAN独立
```

**一句话总结（30秒口述版）：**

> 集线器什么都不隔离；交换机隔离冲突域但不隔离广播域；路由器两个都隔离；VLAN在交换机上划分广播域。

### 3.3 常见错误（考场上最容易丢分的）

```
❌ "交换机隔离广播域"
    → 错！交换机默认所有端口在同一广播域，广播帧会泛洪到所有端口
    → ✓ 正确说法：交换机隔离冲突域

❌ "交换机不隔离冲突域"
    → 错！交换机的每个端口是一个独立的冲突域（全双工模式下无冲突）
    → ✓ 每个端口独立冲突域

❌ "路由器不隔离广播域"
    → 错！路由器隔离广播域，广播帧不会经过路由器转发
    → ✓ 所以跨网段必须经过路由器

❌ "VLAN隔离冲突域"
    → 错！VLAN隔离的是广播域，同一VLAN内广播可达
    → ✓ VLAN划分广播域，不是冲突域
```

## 四、封装与解封装过程（简答题标准答案模板）

```
发送方(封装)：自上而下加首部
  应用层数据
  → 运输层加TCP/UDP首部(变成段)
  → 网络层加IP首部(变成数据报)
  → 数据链路层加MAC首部+尾部FCS(变成帧)
  → 物理层变成比特流发送

接收方(解封装)：自下而上拆首部
  物理层收到比特流
  → 数据链路层拆MAC首部+尾部(检错)
  → 网络层拆IP首部
  → 运输层拆TCP/UDP首部
  → 应用层拿到原始数据
```

**易丢分：** 漏掉数据链路层的尾部(FCS/CRC校验)，只说"加首部"不说"加尾部"
