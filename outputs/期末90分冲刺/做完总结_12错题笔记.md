## 判断题错题

### ❌ 第24题：ARP广播可以穿越路由器

**当时填：** 对（1）

**正确答案：** **错**

**为什么错：**
```
ARP请求是广播帧（目的MAC全F）
路由器 → 隔离广播域
广播帧不能穿越路由器
```

**正确理解：**
```
同网段通信：
  A发ARP广播"谁是192.168.1.20？" → 所有同网段设备都能收到
  B识别是自己 → 单播回复MAC地址

跨网段通信：
  A发现目标不在同网段 → ARP查的是默认网关的MAC
  → ARP广播仍然只在本地网络，不穿越路由器
```

**关联知识点：** [[做完总结_体系结构与冲突域广播域]] → 路由器隔离广播域

### ❌ 第27题：GBN协议接收方缓存乱序帧

**当时填：** 对（1）

**正确答案：** **错**

**为什么错：**
```
GBN (Go-Back-N)：接收方只按序接收
  → 收到乱序帧 → 直接丢弃！
  → 发送方超时后，重传从丢失帧开始的所有帧

SR (Selective Repeat)：接收方缓存乱序帧
  → 收到乱序帧 → 暂存缓存中
  → 发送方只重传丢失的那一个帧
```

**速记口诀：**
```
GBN：乱序就扔，回退N步重传
SR： 乱序先存，只重传丢的那个
```

### ❌ 第28题：流量控制针对接收方能力，拥塞控制针对网络能力

**当时填：** 错（0）

**正确答案：** **对**

**为什么错：** 这句话本身是**正确的**！你误判了。

```
流量控制 = 解决"接收方太慢"的问题
  接收方通过rwnd告诉发送方"我只能收这么多"
  端到端(接收方→发送方)

拥塞控制 = 解决"网络太堵"的问题
  发送方通过cwnd自我调节"网络可能累了，少发点"
  全局(网络整体状态)
```

**区分记忆表：**

| | 流量控制 | 拥塞控制 |
|:---|:--------|:--------|
| 解决什么 | 接收方缓冲区不够 | 网络链路拥堵 |
| 谁控制 | 接收方通知(rwnd) | 发送方自调(cwnd) |
| 性质 | 端到端 | 全局 |
| 公式 | 发送窗口 = min(**rwnd**, cwnd) | 发送窗口 = min(rwnd, **cwnd**) |

### ❌ 第29题：IPv6路由器可以对过大数据报分片

**当时填：** 对（1）

**正确答案：** **错**

**为什么错：**
```
IPv4：路由器可以分片（逐跳分片）
IPv6：路由器不分片！只能丢弃
      分片只能由源主机在发送前完成
```

**记忆口诀：** "IPv6路由器是直男——包太大？扔掉，不帮你切。"

### ❌ 第30题：传输时延 = 链路距离 ÷ 信号传播速率

**当时填：** 对（1）

**正确答案：** **错**

**为什么错：** 你混淆了**传输时延(发送时延)**和**传播时延**。

```
传输时延(发送时延) T_send = 数据长度 / 发送速率  = L / R
传播时延 T_prop = 链路距离 / 传播速度 = d / v
```

**题目说的公式 `d/v` 是传播时延，不是传输时延！**

**记忆口诀：**
```
"传"输时延 → 往管道里"塞"数据的时间 → L/R
"传"播时延 → 数据在管道里"跑"的时间 → d/v
```

## 本次错题原因归类

```
混淆概念型： 第28题(流量vs拥塞)、第30题(发送vs传播)
     ← 公式/定义没记牢，最容易靠口诀改正

记忆错误型： 第27题(GBN vs SR)、第29题(IPv4 vs IPv6)
     ← 对比记忆，两个放一起背

逻辑推理型： 第24题(ARP广播不能穿路由器)
     ← 理解了"路由器隔离广播域"就能推出
```

> 考场上遇到不确定的题，先用"路由器隔离广播域"这个结论去推——很多题都围绕这个展开。
