# 02_学习通高频简答补充

> 只保留学习通爱考、又能在 5-8 个得分点内写完的口径。

## 协议与服务区别和联系

关键词链：对等实体 - 服务访问点 - 服务原语 - 分层

标准答案：
1. 协议是对等实体之间通信必须遵守的规则。
2. 服务是下层向相邻上层提供的功能。
3. 对等实体之间通过协议通信，相邻层之间通过服务接口联系。
4. 服务访问点 SAP 是相邻两层交互的地点。
5. 服务原语是上层调用下层服务的命令。

压缩版：
协议管同层，服务管上下层，SAP 是接口，原语是命令。

## IP服务特点

关键词链：无连接 - 尽最大努力 - 不可靠 - 不按序

标准答案：
1. IP 提供无连接的数据报服务。
2. IP 提供尽最大努力交付。
3. IP 不保证可靠、不保证按序、不保证不丢失、不保证不重复。
4. 可靠性由运输层 TCP 等机制提供。

压缩版：
IP 只管尽量送到，不管一定到、按序到、重复不重复。

## ARP跨网工作流程

关键词链：同网查目标 - 跨网查网关 - 广播请求 - 单播响应

标准答案：
1. 主机先查 ARP 缓存。
2. 同网段通信时，ARP 解析目标主机 MAC。
3. 跨网段通信时，ARP 解析默认网关 MAC，不直接解析远端主机 MAC。
4. ARP 请求是广播，ARP 响应是单播。
5. ARP 广播不能穿越路由器。

压缩版：
同网问目标，跨网问网关；请求广播，响应单播。

## TCP与UDP比较

关键词链：连接 - 可靠 - 字节流/报文 - 控制 - 首部

标准答案：
1. TCP 面向连接，UDP 无连接。
2. TCP 可靠交付，UDP 尽最大努力交付。
3. TCP 面向字节流，UDP 面向报文。
4. TCP 有流量控制和拥塞控制，UDP 没有。
5. TCP 首部至少 20 字节，UDP 首部 8 字节。

压缩版：
TCP 有连接、可靠、字节流、有控制；UDP 无连接、不可靠、报文、首部小。

## 流量控制与拥塞控制区别

关键词链：接收方能力 - 网络能力 - rwnd - cwnd - min

标准答案：
1. 流量控制保护接收方，防止缓存溢出。
2. 拥塞控制保护网络，防止路由器和链路过载。
3. 流量控制看 `rwnd`，拥塞控制看 `cwnd`。
4. 发送窗口 = `min(rwnd, cwnd)`。

压缩版：
流控看接收方，拥控看网络，发送窗口取最小。

## 交换机、网桥、集线器、路由器区别

关键词链：层次 - MAC表 - 冲突域 - 广播域

标准答案：
1. 集线器工作在物理层，不识别 MAC。
2. 网桥和交换机工作在数据链路层，根据 MAC 表转发。
3. 集线器和交换机都隔离冲突域，但普通二层交换机不隔离广播域。
4. 网桥不隔离广播域，路由器隔离广播域。

压缩版：
集线器最笨，交换机学 MAC，网桥不隔离广播域，路由器隔离广播域。

## 三次握手、四次挥手及半关闭

关键词链：SYN - ACK - FIN - TIME-WAIT - 半关闭

标准答案：
1. 三次握手顺序是 SYN、SYN+ACK、ACK。
2. 作用是确认双方收发能力并协商初始序号。
3. 四次挥手顺序是 FIN、ACK、FIN、ACK。
4. 因 TCP 全双工，两个方向要分别关闭，所以是四次。
5. 主动关闭方进入 TIME-WAIT，等待 2MSL。
6. 一方关闭发送方向、仍能接收对方数据，叫半关闭。

压缩版：
三握建连，四挥关双向，主动方进 TIME-WAIT，关一边收一边叫半关闭。
