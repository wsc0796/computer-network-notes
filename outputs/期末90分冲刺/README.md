## 三阶段执行路线

### 阶段A：补缺（构建完整知识框架）

```
目标：掌握所有大题模板 + 补齐客观题知识盲区
时间：约6-8小时
1. 按 [07_大题固定模板](07_大题固定模板.md) 顺序，每类做1道基础例题+1道考试难度例题
2. 通读 [05_客观题速记册](05_客观题速记册.md) 第〇部分（教师原话考点）+ 第一部分（易混概念对比）
3. 错题标记并复做，直到脱离参考答案能完整写出步骤
```

### 阶段B：闭卷（模拟考试环境验收）

```
目标：三套训练卷全部达到80+分数
时间：约5-6小时（每套100分钟做+30分钟对答案）

按顺序完成：
1. [08_基础验收卷](08_闭卷训练卷.md) → 检验基本功
2. [12_学习通原题口径卷](12_学习通原题口径卷.md) → 确保学习通81题全覆盖
3. [14_高风险变式查漏卷](14_高风险变式查漏卷.md) → 筛查高分陷阱

每套做完后：
- 统计得分：选择__ 填空__ 判断__ 简答__ 大题__ = __/100
- 错题标注类型：概念错/公式错/计算错/单位错/记忆错
- 回到对应速记册重背错题考点
- 重做所有大题错题(直到做对)
```

### 阶段C：考前复查（保持手感+不进新内容）

```
目标：考前最后过一遍核心结论，不进新知识
时间：考前2小时

1. 看 [10_考前一页纸](10_考前一页纸.md) → 全篇过一遍(15分钟)
2. 默写：五层+PDU+所有公式(10分钟)
3. 口述6道简答题关键词链(15分钟)
4. 脑中过判断题TOP10陷阱(5分钟)
5. 各做1题：CRC、子网划分、TCP拥塞控制(20分钟)
6. 闭眼休息，不再学新内容

如果时间极其紧张：
  → 1小时版：[05_客观题速记册](05_客观题速记册.md) 第〇部分 + [10_考前一页纸](10_考前一页纸.md)
  → 2小时版：上面 + [07_大题固定模板](07_大题固定模板.md)（只做基础例题5-6类）
```

## 状态检查清单（阶段B/C交接时确认）

- [ ] 五层+PDU+设备能闭卷默写(一字不错)
- [ ] 对等实体/SAP/服务原语/协议vs服务能准确说出
- [ ] IP地址分类(A/B/C/D/E + 私有地址)能快速识别
- [ ] CRC步骤能闭卷默写
- [ ] 子网划分(VLSM)步骤能闭卷默写
- [ ] 拥塞控制四阶段+cwnd变化能画出(含超时vs 3重复ACK的区别)
- [ ] 奈氏/香农公式能写出 + dB换算
- [ ] CSMA/CD最小帧长公式能写出
- [ ] TCP三次握手/四次挥手能画出(含seq/ack)
- [ ] TCP半关闭含义能说出
- [ ] TCP确认号vs序号含义能准确区分
- [ ] TCP vs UDP六点区别能说出
- [ ] RIP更新规则能说出(含三个计时器:30s/180s/240s)
- [ ] GBN/SR区别能说出(含窗口上限)
- [ ] 交换机转发四个行为能说出
- [ ] 冲突域/广播域判断规则能说出
- [ ] ARP同网/跨网能说清
- [ ] PPP不可靠能说明原因
- [ ] 网桥不隔离广播域能说出
- [ ] 三套训练卷全部 ≥ 80分

## 放弃内容（不用纠结）

- 应用层全部(不考)
- CSMA/CA(知道是无线用即可)
- 二进制指数退避精确计算(记k=min(n,10)即可)
- ADSL/HFC/FTTx接入技术
- 停止等待协议详细推导(记住结论即可：信道利用率低)
