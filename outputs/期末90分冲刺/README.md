# 计算机网络期末90分冲刺包

按当前日期 2026-07-02 推算，考试时间为 2026-07-04 14:00。本包面向江西农业大学《计算机网络》期末，目标是网络概述、物理层、数据链路层、网络层、运输层达到90分冲刺水平。不包含应用层复习。

## 立即执行顺序

1. 先读 `00_资料审计报告.md`，确认本包依据和范围。
2. 今晚按 `03_今晚3小时执行稿.md` 执行，不扩展新资料。
3. 明日上午按 `04_明日上午做题训练.md` 做题。
4. 客观题用 `05_客观题速记册.md`。
5. 简答题用 `06_简答题背诵册.md`。
6. 大题用 `07_大题固定模板.md`。
7. 用 `08_闭卷训练卷.md` 闭卷检测，再看 `09_闭卷训练卷答案.md`。
8. 考前只看 `10_考前一页纸.md` 和错题。

## 90分使用规则

- 不要先看答案。
- 所有大题必须写步骤。
- 只要出现红线错误，即使分数够，也必须重做同类题。
- 正式考试能否整卷90分，还取决于你是否另行处理老师强调但本包排除的应用层内容；本包只完成用户指定范围。
