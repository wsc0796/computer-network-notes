# 05 客观题速记册

用于选择、填空、判断。背的时候不要逐字背解释，只背“关键词 + 陷阱”。

## 1. 选择题对比速记

| 对比 | 正确区分 |
|---|---|
| 转发 vs 路由 | 转发是按表把分组送到出口；路由是生成或更新转发表 |
| MAC地址 vs IP地址 | MAC用于同一链路内交付；IP用于跨网络寻址 |
| 直接交付 vs 间接交付 | 直接交付在同一网络；间接交付先给下一跳路由器 |
| ARP vs DHCP | ARP求MAC；DHCP获取IP等配置 |
| ICMP vs IP | ICMP封装在IP数据报中，用于差错报告和控制 |
| NAT vs 路由 | NAT改地址或端口；路由只选择下一跳 |
| RIP vs OSPF | RIP距离向量；OSPF链路状态 |
| OSPF vs BGP | OSPF自治系统内；BGP自治系统间 |
| IPv4 vs IPv6 | IPv4首部可变且有校验和；IPv6固定40字节，无首部校验和 |
| TCP vs UDP | TCP可靠、连接、字节流；UDP无连接、尽力交付、报文 |
| 复用 vs 分用 | 复用是多个应用交给运输层；分用是运输层交给正确进程 |
| rwnd vs cwnd | rwnd由接收方能力决定；cwnd由网络拥塞状态决定 |
| GBN vs SR | GBN接收方通常只按序接收；SR可缓存乱序帧 |
| 停止等待 vs 滑动窗口 | 停止等待一次一个未确认帧；滑动窗口可连续发送多个 |
| CSMA/CD vs CSMA/CA | CD检测冲突；CA避免冲突 |
| 交换机 vs 路由器 | 交换机看MAC；路由器看IP |
| 冲突域 vs 广播域 | 交换机隔离冲突域；路由器隔离广播域 |
| 奈奎斯特 vs 香农 | 奈奎斯特理想无噪声；香农考虑信噪比 |
| 编码 vs 调制 | 编码是数字信号表示；调制是载波参数变化 |
| FDM/TDM/WDM/CDMA | 频率、时间、波长、码片 |

## 2. 填空事实

1. 协议三要素：语法、语义、同步。
2. 五层模型自上而下：应用层、运输层、网络层、数据链路层、物理层。
3. 物理层PDU是比特。
4. 数据链路层PDU是帧。
5. 网络层PDU是IP数据报。
6. 运输层PDU是TCP报文段或UDP用户数据报。
7. 集线器工作在物理层。
8. 交换机工作在数据链路层。
9. 路由器工作在网络层。
10. 总时延包括发送、传播、处理、排队时延。
11. 奈奎斯特最高码元速率为2W Baud。
12. 香农公式为 C = W log2(1+S/N)。
13. 10Base-T中的10表示10Mb/s。
14. Base表示基带传输。
15. 曼彻斯特编码每个比特中间有跳变。
16. PPP常用于点到点链路。
17. CRC采用模2除法。
18. 以太网MAC地址通常48位。
19. 以太网最小帧长64字节。
20. ARP请求广播，ARP响应单播。
21. DHCP典型过程为 Discover、Offer、Request、ACK。
22. IPv4首部最小20字节。
23. IPv6基本首部固定40字节。
24. 私有地址包括10/8、172.16/12、192.168/16。
25. 127/8用于回环。
26. `0.0.0.0` 表示未指定地址。
27. `0.0.0.0/0` 可表示默认路由。
28. 255.255.255.255为受限广播地址。
29. RIP最大有效跳数为15，16表示不可达。
30. IP分片片偏移单位为8字节。
31. UDP首部长度为8字节。
32. UDP数据长度 = UDP总长度 - 8。
33. TCP连接由四元组标识。
34. SYN占用一个序号。
35. FIN占用一个序号。
36. 纯ACK不占用序号。
37. TIME_WAIT等待2MSL。
38. Karn算法不使用重传报文段样本测RTT。
39. SACK表示选择确认。
40. 零窗口时发送方用窗口探测报文避免永久等待。
41. TCP拥塞控制包括慢开始、拥塞避免、快重传、快恢复。

## 3. 判断陷阱50题

| 题号 | 判断题 | 答案 | 错误原因或改正 |
|---:|---|---|---|
| 1 | OSI模型和TCP/IP模型层数完全相同。 | 错 | OSI七层，TCP/IP常按四层或五层讲 |
| 2 | 协议只规定语法，不规定时序。 | 错 | 协议三要素含同步 |
| 3 | 路由器根据MAC地址选择跨网络路径。 | 错 | 路由器主要根据IP地址 |
| 4 | 发送时延与链路长度直接相关。 | 错 | 发送时延与数据量和发送速率相关 |
| 5 | 传播时延与数据量直接相关。 | 错 | 与距离和传播速度相关 |
| 6 | 奈奎斯特公式考虑信噪比。 | 错 | 香农考虑信噪比 |
| 7 | 信噪比dB越大，信道容量通常越大。 | 对 | 香农公式体现 |
| 8 | 曼彻斯特编码每位中间都有跳变。 | 对 | 中间跳变用于同步 |
| 9 | FDM按时间片共享信道。 | 错 | FDM按频率 |
| 10 | WDM常用于光纤通信。 | 对 | 按波长复用 |
| 11 | 数据链路层只负责传输比特流。 | 错 | 比特流是物理层 |
| 12 | 成帧可以帮助接收方识别帧边界。 | 对 | 帧定界作用 |
| 13 | 透明传输指数据内容不会被误认为控制标志。 | 对 | 需要填充机制 |
| 14 | CRC可以纠正所有错误。 | 错 | CRC主要检错 |
| 15 | CRC模2除法要借位。 | 错 | 异或，不借位不进位 |
| 16 | 停止等待协议任意时刻只允许一个未确认帧。 | 对 | 单帧滑动窗口 |
| 17 | GBN接收方必须缓存所有乱序帧。 | 错 | 这是SR特点 |
| 18 | SR发送窗口过大可能导致新旧序号混淆。 | 对 | 窗口通常不超过序号空间一半 |
| 19 | CSMA/CD适合无线局域网检测冲突。 | 错 | 无线常用CSMA/CA |
| 20 | 以太网最小帧长与冲突检测有关。 | 对 | 必须能检测最远冲突 |
| 21 | 交换机转发依据IP路由表。 | 错 | 二层交换依据MAC表 |
| 22 | 交换机隔离广播域。 | 错 | 路由器隔离广播域 |
| 23 | ARP用于由IP地址获得MAC地址。 | 对 | 同一链路内 |
| 24 | ARP请求通常单播发送。 | 错 | 请求广播，响应单播 |
| 25 | IP地址唯一决定主机所在链路的MAC地址。 | 错 | IP和MAC属于不同层次 |
| 26 | 同一IP数据报每经过一跳MAC地址都会改变。 | 对 | 链路层逐跳封装 |
| 27 | TTL每经过一个路由器通常减1。 | 对 | 防止无限循环 |
| 28 | IPv4首部校验和覆盖整个数据报数据部分。 | 错 | 只校验首部 |
| 29 | IPv4协议字段直接决定路由转发路径。 | 错 | 协议字段标识上层协议 |
| 30 | IPv6路由器不对过大分组分片。 | 对 | 由源主机处理 |
| 31 | 直接交付不需要经过路由器。 | 对 | 同一网络内 |
| 32 | 间接交付一定先发给下一跳路由器。 | 对 | 跨网络交付 |
| 33 | CIDR斜线后的数字越大，地址块越大。 | 错 | 前缀越长，地址块越小 |
| 34 | /26每个子网共有64个地址。 | 对 | 主机位6位 |
| 35 | 可用主机数永远等于地址总数。 | 错 | 常规子网要减网络地址和广播地址 |
| 36 | 最长前缀匹配是选匹配项中前缀最长的路由。 | 对 | 不是选跳数最小 |
| 37 | RIP收到距离后应先加1再比较。 | 对 | 加上到邻居的一跳 |
| 38 | RIP中16表示不可达。 | 对 | 最大有效15跳 |
| 39 | RIP同一下一跳发来的更差距离可以忽略。 | 错 | 同一下一跳要更新 |
| 40 | IP分片偏移单位是字节。 | 错 | 单位是8字节 |
| 41 | IP最后一片MF标志为0。 | 对 | 后面没有更多分片 |
| 42 | NAT只修改MAC地址。 | 错 | 修改IP地址，NAPT还修改端口 |
| 43 | UDP是面向连接协议。 | 错 | UDP无连接 |
| 44 | UDP首部只有4字节。 | 错 | 8字节 |
| 45 | UDP长度字段包含首部和数据。 | 对 | 数据长度要减8 |
| 46 | TCP是面向字节流的。 | 对 | 不是保留应用报文边界 |
| 47 | TCP三次握手第二次报文可同时带SYN和ACK。 | 对 | SYN+ACK |
| 48 | TCP纯ACK也消耗一个序号。 | 错 | 纯ACK不占序号 |
| 49 | rwnd由网络拥塞程度决定。 | 错 | rwnd由接收方缓存决定 |
| 50 | 超时通常说明拥塞更严重，TCP会降低cwnd。 | 对 | 进入慢开始 |
