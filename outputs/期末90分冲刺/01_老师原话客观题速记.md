# 01_老师原话客观题速记

> 目标：把学习通 81 题里最爱出现的“原话填空、判断陷阱、单选口径”压成闭卷速记。

## 老师原话填空专区

- 对等实体：协议约束的是对等实体。
- `SAP`：相邻两层实体交互的地点叫服务访问点。
- 服务原语：上层调用下层服务的命令叫服务原语。
- PDU：相邻层交换的数据单位，按层叫帧、数据报、段、报文。
- TCP/IP：课堂上常按 4 层，教材教学体系可按 5 层。
- 传播时延：信号在链路上传播的时间，`D / V`。
- 发送时延：帧全部比特推出去的时间，`L / R`。
- 基带：原始数字信号直接送到线路上传输。
- 单工：只单向。
- 半双工：双向但不能同时。
- 全双工：双向同时。
- `48`：MAC 地址长度 48 bit。
- `46`：以太网数据字段最小 46 字节。
- `2τ`：CSMA/CD 最坏冲突检测时间。
- 网络号：IP 地址里标识网络部分。
- 主机号：IP 地址里标识主机部分。
- 唯一：IP 地址在全网范围内应唯一。
- 三次握手：SYN、SYN+ACK、ACK。
- 半关闭：一方关闭发送方向，仍可接收对方数据。

## 客观题高频口径

1. IP 服务特点：无连接、尽最大努力、不保证可靠。
2. PPP：能检错，不提供可靠传输。
3. 以太网 MAC 服务：无连接、不可靠。
4. 交换机：自学习源 MAC，查目的 MAC。
5. 网桥/交换机：不隔离广播域，VLAN 才隔离。
6. ARP：同网查目标 MAC，跨网查默认网关 MAC。
7. Ping：ICMP 回送请求/回答。
8. 端口号：16 bit。
9. TCP 确认号：期望收到的下一个字节序号。
10. 专门确认 / 捎带确认：都属于 TCP 确认方式。
11. 通知窗口 `rwnd`：接收端能力。
12. 拥塞窗口 `cwnd`：网络拥塞状况。
13. `NRZ`：没有同步信息。
14. 曼彻斯特 / 差分曼彻斯特：有同步信息。
15. A/B/C 类地址：按首字节识别，仍可能出填空。

## 判断陷阱

- `PPP` 可靠传输 -> 错。
- `ARP` 广播能穿越路由器 -> 错。
- `网桥` 隔离广播域 -> 错。
- `rwnd` 和 `cwnd` 混用 -> 错。
- `ACK` 是最后已收字节 -> 错。
- `TCP` 面向报文 -> 错。
- `UDP` 面向字节流 -> 错。
- `IPv6` 路由器分片 -> 错。
- `CDMA` 码片正交内积等于 1 -> 错。

## 运输层老口径

- TCP 可靠性：确认、重传、序号。
- TCP 通知窗口：接收方说“我还能收多少”。
- TCP 拥塞窗口：发送方说“网络还能承受多少”。
- 半关闭：一边关发送，一边还能收。
