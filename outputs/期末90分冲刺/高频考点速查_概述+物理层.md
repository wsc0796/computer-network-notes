## 一、概述/体系结构（第1章）

### 1. 协议三要素 [S级]

| 要素 | 含义 | 考题 |
|------|------|------|
| **语法** | 用户数据和控制信息的**结构/格式** | 选择：语法规定了什么？→ 用户数据和控制信息 |
| **语义** | 每个字段/控制信息**代表什么含义** | — |
| **时序** | 事件发生的**先后顺序**和速率 | 填空：协议三要素____、____、____ |

> 口诀："语法定格式，语义说含义，时序管顺序"

### 2. 协议 vs 服务 [S级]

```
协议 = 水平方向 → 同一层对等实体之间的通信规则
服务 = 垂直方向 → 下层通过接口向上层提供的功能
```

| 判断题 | 对/错 |
|--------|:---:|
| 协议是垂直的，服务是水平的 | ✗ 反了 |
| 协议=对等层规则，服务=相邻层功能 | ✓ |

### 3. 三层体系结构对比 [A级]

```
OSI七层          TCP/IP四层        教学五层
7.应用层 ┐
6.表示层 ├→ 应用层 ──────→ 应用层
5.会话层 ┘
4.运输层 ──→ 运输层 ──────→ 运输层
3.网络层 ──→ 网际层 ──────→ 网络层
2.链路层 ┐
1.物理层 ├→ 网络接口层 ──→ 数据链路层 + 物理层
```

| 高频考题               | 答案            |
| ------------------ | ------------- |
| OSI/RM中，网络层之上是？    | **运输层**       |
| OSI最高层是？           | **应用层**       |
| TCP/IP有几层？         | **4层**        |
| TCP/IP网络接口层=教学哪两层？ | **数据链路层+物理层** |
| OSI中路由选择在哪层？       | **网络层**       |
| OSI中端到端连接在哪层？      | **运输层**       |
| OSI中数据格式转换/加密在哪层？  | **表示层**       |

### 4. 端到端通信 [A级]

> 端到端通信 = **边缘部分的端点**之间的通信（核心部分只转发，不发起通信）

```
边缘部分 = 主机（端系统），发起和接收通信
核心部分 = 路由器，只负责存储转发
```

### 5. 分层概念 [A级]

**正确的分层描述：**
- ✓ 保持网络灵活且易于修改
- ✓ 把相关的网络功能组合在同一层中

**错误的分层描述：**
- ✗ 所有网络体系结构都使用相同的层次名称和功能（OSI≠TCP/IP≠教学）

**分层好处（简答）：** 分解复杂问题 → 接口清晰 → 独立演进 → 便于标准化

## 二、物理层（第2章）

### 6. 通信方式 [A级]

| 方式 | 方向 | 例子 | 考题 |
|------|------|------|------|
| **单工** | 单向 | 广播、电视 | 广播电视是什么传输？→ 单工 |
| **半双工** | 双向轮流 | 对讲机、CSMA/CD | 不能同时收发 |
| **全双工** | 双向同时 | 电话、交换式以太网 | 双方可同时收发 |

> 陷阱："半双工允许双方同时发送" → ✗ 错
> 陷阱："全双工和半双工的唯一区别是传输速率" → ✗ 错，区别是能否同时

### 7. 调制方式 [A级]

| 缩写 | 调制参数 | 考题 |
|------|---------|------|
| **ASK** | 幅度 | — |
| **FSK** | 频率 | — |
| **PSK** | 相位 | — |
| **QAM** | **幅度+相位** | 幅度+相位两参数 → QAM |

> 口诀："ASK调幅、FSK调频、PSK调相、QAM幅度+相位一起来"
> 看到"两个参数同时调制"直接选QAM

### 8. 调制 vs 编码 [A级]

```
调制：数字 → 模拟（信号类型变了）
编码：数字 → 数字（只变波形，类型不变）
解调：模拟 → 数字
```

| 考题 | 答案 |
|------|------|
| 数字信号→模拟信号叫什么？ | **调制** |
| 调制解调技术用在什么场景？ | **模拟信道传输数字数据** |
| Modem = ? | **Mo**dulator + **Dem**odulator |

### 9. 比特率 vs 波特率 [A级]

> **比特率(bps) = 波特率(Baud) × log₂(M)**

| M值 | 调制方式 | log₂M |
|:--:|---------|:-----:|
| 2 | ASK/FSK/2-PSK | 1 |
| 4 | 4-PSK(QPSK) | 2 |
| 8 | 8-PSK | 3 |
| 16 | 16-QAM/16-PSK | 4 |
| 64 | 64-QAM | 6 |

| 考题 | 计算 |
|------|------|
| 300Baud, 4相PSK, 数据率？ | 300×2 = **600bps** |
| 4800bps, 16相PSK, 波特率？ | 4800÷4 = **1200Baud** |

### 10. 奈奎斯特 vs 香农 [S级]

| | 奈奎斯特(Nyquist) | 香农(Shannon) |
|------|------|------|
| 条件 | **无噪声**信道 | **有噪声**信道 |
| 公式 | C = 2W × log₂(V) | C = W × log₂(1+S/N) |
| 限制 | 带宽W + 电平数V | 带宽W + 信噪比S/N |

| dB → S/N换算 | |
|------|------|
| 10dB | S/N=10 |
| 20dB | S/N=100 |
| 30dB | S/N=**1000** |
| 40dB | S/N=10000 |

> 注意：S/N代入公式必须是**比值**（非dB），S/N = 10^(dB/10)

### 11. 信道复用技术 [A级]

| 缩写       | 全称     | 区分方式              | 适用场景   |
| -------- | ------ | ----------------- | ------ |
| **FDM**  | 频分复用   | 按频率划分             | 模拟通信   |
| **TDM**  | 同步时分复用 | **固定时间片**（位置=身份）  | 数字通信   |
| **STDM** | 统计时分复用 | **数据中加源标识**（动态分配） | 分组交换   |
| **WDM**  | 波分复用   | 按波长划分             | **光纤** |
| **CDMA** | 码分复用   | 正交地址码             | 3G移动通信 |
1：代表1，-1代表0，0代表没传到

| 高频考题          | 答案                       |
| ------------- | ------------------------ |
| 光纤上用什么复用？     | **WDM**（波分复用）            |
| WDM本质就是？      | **光的FDM**                |
| 同步TDM如何区分数据源？ | **固定时间片**                |
| STDM如何区分数据源？  | **数据中加数据源标识**            |
| 常用复用技术有哪五种？   | FDM、TDM、STDM、**CDM**、WDM |
| TDM≠STDM易错点   | STDM=统计时分，不是普通TDM        |

### 12. 接入网技术 [A级]

| 考题 | 答案 |
|------|------|
| 宽带网络两大关键技术？ | **骨干网技术 + 接入网技术** |
| HFC利用什么接入Internet？ | **有线电视网** |

## 三、判断题陷阱速查

| 陷阱说法 | 正确表述 |
|---------|---------|
| 频分复用所有用户在不同时间占用同样频带 | ✗ 那是**时分**复用 |
| 码分复用就是光的频分复用 | ✗ 那是**波分**复用 |

| 基带信号一定是数字信号 | ✗ 可以是模拟，关键在"未经调制" |
| 基带信号经调制后仍是基带信号 | ✗ 调制后是频带/宽带信号 |

## 五、数据链路层——冲突域与广播域 [S级]

### 1. 两个概念定义

| 概念 | 定义 | 一句话 |
|------|------|--------|
| **冲突域** | 同一时刻只允许一台设备发送的网络区域 | 共享介质 = 同一冲突域 |
| **广播域** | 广播帧能到达的所有设备的集合 | 广播帧传到的范围 |

### 2. 设备隔离能力对照表（核心！）

| 设备 | 工作层 | 转发依据 | 隔离冲突域 | 隔离广播域 |
|------|:---:|------|:---:|:---:|
| 集线器(Hub) | 物理层 | 无（信号广播） | ❌ | ❌ |
| 网桥(Bridge) | 数据链路层 | MAC地址 | ✅ | ❌ |
| 交换机(Switch) | 数据链路层 | MAC地址 | ✅ | ❌ |
| 路由器(Router) | 网络层 | IP地址 | ✅ | ✅ |
| VLAN | 逻辑层 | — | ❌ | ✅ |

> 口诀："集线器全共享，交换机隔冲突，路由器两个隔，VLAN补广播"

### 3. 经典计算题

| 考题 | 答案 |
|------|------|
| 48端口交换机，冲突域？广播域？ | **48个、1个** |
| N端口交换机，冲突域？广播域？ | **N个、1个** |
| 冲突域数 = **端口数**，广播域数 = **1**（不加VLAN/路由器） |

### 4. 填空题高频空

| 题目 | 答案 |
|------|------|
| 交换机的所有接口都在同一____内，而每个接口就是一个____ | **广播域**、**冲突域** |
| 交换机的所有接口都在同一个广播域内，而每个接口就是一个____ | **冲突域** |

### 5. 判断题六大陷阱

| 陷阱说法 | 对/错 | 更正 |
|---------|:---:|------|
| 网桥能隔离广播域 | ✗ | 网桥/交换机不隔离广播域 |
| 交换机每个端口是独立广播域 | ✗ | 是独立**冲突域** |
| VLAN可有效屏蔽冲突域 | ✗ | VLAN屏蔽的是**广播域** |
| Ethernet交换机=多接口集线器 | ✗ | =多接口**透明网桥** |
| 二层交换机不隔离广播域 | ✓ | 正确 |
| ARP广播能穿越路由器 | ✗ | 路由器隔离广播域，ARP不能穿越 |

### 6. CSMA/CD 核心计算 [S级]

| 概念 | 公式/数值 | 考题 |
|------|------|------|
| 争用期 | **2τ**（往返传播时延） | 冲突检测时间 = 最大传播时延的**2倍** |
| 10M争用期 | **51.2μs** | 51.2μs × 10Mbps = 512bit |
| 100M争用期 | **5.12μs** | 5.12μs × 100Mbps = 512bit |
| 最短帧长 | **64B**（512bit） | 争用期内可发送64B |
| 数据字段最小 | **46B**（64-18=46） | 不足46B需填充 |
| 最大帧长 | **1518B** | 数据字段最大1500B |

> 检测冲突两种方法：**减小电缆长度** 或 **增大最小帧长**

### 7. CSMA/CD 特点

> **介质利用率高 + 无法避免冲突**（传播时延导致碰撞窗口始终存在）

### 8. Ethernet MAC服务

> **无连接不可靠** — 不建连、无确认、无重传、出错丢弃。IP层也是无连接不可靠。

### 9. CRC循环冗余校验

| 事实 | 关键点 |
|------|------|
| 只能**检错**不能纠错 | 发现错误丢弃帧/请求重传 |
| 广泛使用原因 | 可检测**多位突发性差错** |
| 余数=0 | 未检测出错误 |
| 常用位数 | CRC-16(16位), CRC-32(32位) |

### 10. 可靠传输定义

> 可靠 = **确认机制（ACK + 超时重传）**，不是"面向连接"也不是"滑动窗口"
> PPP面向连接但不可靠（无确认无重传）；TCP确认+重传=可靠

### 11. DIX Ethernet vs IEEE 802.3

| 标准 | 包含 | 帧关键字段 |
|------|------|------|
| **DIX V2.0** | 物理层 + MAC子层 | **类型**(Type) |
| **IEEE 802.3** | 物理层 + MAC + **LLC子层** | 长度 + LLC头 |

> DIX**没有LLC子层**，IEEE 802.3才加了LLC

### 12. STP生成树协议

| 概念 | 关键点 |
|------|------|
| 根交换机选举依据 | **交换机ID（BID）** = 优先级 + MAC地址 |
| 作用 | 解决**交换机**之间的回路问题（不是路由器） |
| 选举规则 | BID最小者当选（先比优先级，再比MAC） |

### 13. 以太网命名规则

```
命名格式：速率 + Base/Broad + 介质
  10/100/1000 → 速率(Mbps)
  Base → 基带传输
  最后字母 → T=双绞线, F/FX/LX/SX=光纤
```

| 标准 | 介质 |
|------|------|
| 10BASE-T | 双绞线 |
| 100BASE-TX | **UTP 5类线**或STP（2对线） |
| 100BASE-FX | 光纤 |
| 1000BASE-LX | **光纤**（长波长1310nm） |
| 1000BASE-SX | 光纤（短波长850nm） |
| 1000BASE-T | 双绞线 |

### 14. 10BASE-T拓扑 [有争议]

> 标准：**物理星型 + 逻辑总线**。不同试卷答案不统一，以老师课件为准。

### 15. 广播风暴

| 考题 | 答案 |
|------|------|
| 可能**引起**广播风暴的设备 | **网桥/交换机**（不隔离广播） |
| 可**隔离**广播风暴的设备 | **路由器**（隔离广播域） + **VLAN** |

### 16. 全双工带宽

> 100Mbps端口全双工 = 实际带宽 **200Mbps**（收发各100M）

### 17. 数据链路层杂项速记

| 概念 | 关键点 |
|------|--------|
| MAC地址长度 | **48 bit** = 6字节 |
| MAC地址存储位置 | **适配器的ROM**（不是PC主板ROM） |
| 网桥/交换机转发依据 | **MAC地址** |
| Ethernet区分设备 | 根据**MAC地址** |
| 交换机=多接口 | **透明网桥**（不是集线器） |
| 10GE CSMA/CD | 只全双工，**不使用CSMA/CD** |
| 高速以太网不变 | 最短帧64B、最大帧1518B、争用期512bit时间**均不变** |

## 六、数据链路层补充 + 跨层概念

### 18. VLAN虚拟局域网

| 概念 | 关键点 |
|------|------|
| 技术基础 | **交换**技术（在交换机上实现） |
| 作用 | 在交换机上**逻辑隔离广播域** |
| 跨VLAN通信 | 必须通过**路由器**（三层转发） |
| Trunk口 | 承载多个VLAN，用802.1Q标签区分 |

> "VLAN就是交换机上的广播域划分工具"

### 19. 数据链路层服务类型

| 服务类型 | 是否存在 |
|---------|:---:|
| 无连接不确认 | ✓（Ethernet MAC） |
| 无连接确认 | ✓（某些无线链路） |
| 面向连接确认 | ✓（HDLC） |
| **面向连接不确认** | **✗ 不存在** |

> 面向连接必定有确认，所以"面向连接不确认"是矛盾组合，选这个就是错。

### 20. LAN/WAN决定要素

> 三个决定要素：**拓扑** + **传输介质** + **MAC方法**
> **传输速率**不是决定要素，只是性能指标

### 21. MAC地址DA字段位定义

```
MAC首字节(8位): b7 b6 b5 b4 b3 b2 b1 b0

b0 = I/G位:  0→单播  1→多播(含广播)
b1 = G/L位:  0→全局地址(厂商分配)  1→局部地址(管理员定义)
```

| DA最高位(b0) | 含义 |
|:---:|------|
| 0 | **单播地址** |
| 1 | **多播地址**（广播=全F是多播的特例） |

### 22. SAP（服务访问点）跨层速查

| 层间交互      | SAP名称                    | 考题               |
| --------- | ------------------------ | ---------------- |
| 应用层→运输层   | **端口号**（16bit）           | 应用进程通过端口号与传输实体交互 |
| 运输层→网络层   | **IP协议号**（TCP=6, UDP=17） | —                |
| 网络层→数据链路层 | **帧类型字段**                | —                |
| 数据链路层→物理层 | **网卡接口**                 | —                |

各层SAP简答评分点：运输层=端口号、网络层=IP地址、链路层=MAC地址

> 陷阱："运输层SAP=IP地址"→✗，运输层SAP=端口号

### 23. 服务原语四类

> **请求(Request) → 指示(Indication) → 响应(Response) → 确认(Confirm)**

陷阱：选项中出现"Transfer""Notify"等不是服务原语的词→直接排除

### 24. 令牌传递

| 标准 | MAC方式 | 冲突 |
|------|------|:---:|
| IEEE 802.3 (Ethernet) | CSMA/CD | 有冲突 |
| IEEE 802.4 (Token Bus) | 令牌传递 | **无冲突** |
| IEEE 802.5 (Token Ring) | 令牌传递 | **无冲突** |

> 以太网统治局域网，令牌环/令牌总线已淘汰。知道"令牌=无冲突"即可。

### 25. 集线器 = 物理星型 + 逻辑总线

| 维度 | 描述 |
|------|------|
| **物理拓扑** | **星型**（各站独立连到集线器） |
| **逻辑拓扑** | **总线**（集线器内部仍共享信道，所有端口在同一冲突域） |

> 集线器是物理层设备，收到信号无条件复制到所有端口 → 所有站点共享同一逻辑总线
> 这就是为什么集线器以太网仍需CSMA/CD

| 对比 | 集线器 | 交换机 |
|------|------|------|
| 逻辑拓扑 | **总线** | 星型（每端口独立） |
| 冲突域 | 1个 | 每端口1个 |
| 需要CSMA/CD | ✓ | 全双工不需要 |

### 26. 透明网桥

> **Ethernet采用透明网桥**（即插即用、自学习、对站点透明）
> 交换机 = 多接口的透明网桥

| 网桥类型 | 使用场景 | 特点 |
|---------|------|------|
| **透明网桥** | **Ethernet** ✓ | 自学习MAC表，即插即用 |
| 源路由网桥 | Token Ring | 由发送站指定路径，非即插即用 |

> 陷阱："Ethernet交换机和源路由网桥一样，即插即用"→ ✗，Ethernet用的是透明网桥

### 27. LAN的三种拓扑结构

| 拓扑 | 是否LAN | 特点 |
|------|:---:|------|
| 总线形 | ✓ | 共享信道，CSMA/CD适用 |
| 星形 | ✓ | 中心设备，10BASE-T |
| 环型 | ✓ | 令牌传递 |
| **网状形** | **✗** | WAN/骨干网用，成本高不适合LAN |

> 口诀："LAN三兄弟：总线、星型、环型。网状=WAN专属"

### 28. 10BASE-T拓扑 [补充汇总]

## 七、运输层（第5章）[S级]

### 1. 端口号

| 概念 | 关键点 |
|------|--------|
| 标识 | 标识主机上的**不同应用进程** |
| 长度 | **16bit**（范围0-65535） |
| 运输层SAP | **端口号** |

**三类端口号：**

| 类别 | 范围 | 说明 |
|------|:---:|------|
| **熟知端口号** | 0-1023 | 系统分配，固定给标准服务 |
| **注册端口号** | 1024-49151 | 用户进程使用 |
| **临时端口号** | 49152-65535 | 客户端临时使用 |

**必记熟知端口：**
```
FTP(21)  SSH(22)  Telnet(23)  SMTP(25)  DNS(53)
DHCP(67/68)  TFTP(69)  HTTP(80)  HTTPS(443)
```

> 传输层通过**端口号**把数据交付给上层应用（分用）

### 2. TCP vs UDP [S级]

| 维度 | TCP | UDP |
|------|-----|-----|
| 连接 | **面向连接**（三次握手） | **无连接** |
| 可靠性 | **可靠**（确认+重传+序号） | **不可靠**（尽力而为） |
| 数据单位 | **字节流**（不保留报文边界） | **报文**（保留边界） |
| 流量控制 | 有（滑动窗口） | 无 |
| 拥塞控制 | 有（四阶段） | 无 |
| 首部 | 20-60B（可变） | **8B**（固定） |
| 场景 | Web/文件/邮件 | DNS/视频/语音/实时通信 |

> 口诀："TCP像挂号信，UDP像平信"

### 3. TCP序号与确认号 [S级]

**核心规则：**
```
序号(seq) = 本报文段首字节序号
确认号(ack) = 期望收到的下一字节序号（累计确认）
SYN和FIN消耗一个序号
```

**本题计算规则：**
```
第三段seq=900 → 第二段seq=900-400=500 → 第一段seq=500-300=200
第一段覆盖[200,499]，第二段[500,899]丢失，第三段[900,1399]

累计确认：ack = 连续数据流的下一个 = 500（第二段开头）
即使收到第三段，缺口未补也只能确认到500
```

### 4. TCP流量控制

> 使用**可变大小的滑动窗口协议**
> 窗口 = **min(rwnd, cwnd)**，动态调整

| 概念 | 关键点 |
|------|------|
| rwnd | **接收窗口**（接收方通告，怕接收方撑死）|
| cwnd | **拥塞窗口**（发送方维护，怕网络堵死）|
| 最终窗口 | 取两者最小值 |

### 5. 传输层设计目的

> 弥补通信子网不足，提高服务可靠性与保证**服务质量（QoS）**

### 6. 各层协议分类（高频选择题）

| 层 | 协议 |
|------|------|
| **应用层** | HTTP, DNS, SMTP, FTP, DHCP, **RIP** |
| **运输层** | **TCP, UDP** |
| **网络层（互连层）** | **IP, ICMP, ARP, RARP, OSPF, IGMP** |
| **数据链路层** | **PPP**, Ethernet, CSMA/CD |
| **物理层** | 中继器, 集线器 |

> RIP虽功能上是路由协议，但考试中认定属应用层（基于UDP 520）
> **IGMP**：组播管理协议，告诉多播路由器本LAN是否有主机加入/退出多播组

## 八、网络层（第4章）[S级]

### 1. 子网划分核心计算（必考）

**三步公式法：**

```
① 掩码 → 前缀长度 /N
② 借位数 = N - 默认前缀
③ 子网数 = 2^借位数，可用主机数 = 2^(32-N) - 2
```

| 默认 | 前缀 | 默认掩码 |
|------|:---:|---------|
| A类 | /8 | 255.0.0.0 |
| B类 | /16 | 255.255.0.0 |
| C类 | /24 | 255.255.255.0 |

**典型题型：**

| 题干 | 计算 | 答案 |
|------|------|------|
| C类分8个子网 | 借3位→/27→256-224=32 | **255.255.255.224** |
| C类分16个子网 | 借4位→/28→256-240=16 | **255.255.255.240** |
| /24→/28 | 子网=2^4=16, 主机=2^4-2=14 | **16子网, 14主机** |
| /24→/29 | 子网=2^5=32, 主机=2^3-2=6 | **32子网, 6主机** |
| 掩码255.255.255.248(/29) | 子网=2^5=32, 主机=2^3-2=6 | **32子网, 6主机** |
| /30网络 | 总共4地址=1网+2主机+1广播 | **2台可用主机** |
| /27 | 子网=2^3=8, 主机=2^5-2=30 | **8子网, 30主机** |

### 2. CIDR块包含/24个数

> 公式：**2^(24 - 前缀长度)**
> /21包含 2^(24-21)=**8**个/24，/22包含**4**个，/23包含**2**个，/20包含**16**个

### 3. 非字节边界子网计算

| 掩码 | 前缀 | 第三字节块大小 | 区间划分 |
|------|:---:|:------------:|---------|
| 255.255.192.0 | /18 | 256-192=**64** | 0-63, 64-127, 128-191, 192-255 |
| 255.255.224.0 | /19 | 256-224=**32** | 0-31, 32-63, 64-95 ... |
| 255.255.240.0 | /20 | 256-240=**16** | 0-15, 16-31, 32-47 ... |
| 255.255.248.0 | /21 | 256-248=**8** | 0-7, 8-15, 16-23 ... |

> /18判同网段：看第三字节属于哪个64区间
> 114在[64-127] → 同一区间的是127，不在的是191/130/148

### 2. /30点对点网络

```
/30 = 255.255.255.252
例：192.168.2.0/30
  192.168.2.0  → 网络地址
  192.168.2.1  → 可用
  192.168.2.2  → 可用
  192.168.2.3  → 广播地址
```

### 3. ARP地址解析

| 考点 | 答案 |
|------|------|
| 功能 | **IP地址→MAC地址** |
| 请求方式 | **广播**（目的MAC=FF-FF-FF-FF-FF-FF） |
| 响应方式 | **单播** |
| 同一子网 | 查询**目标主机**的MAC |
| 不同子网 | 查询**默认网关**的MAC |
| ARP广播 | **不能穿越路由器**（路由器隔离广播域） |

### 4. ICMP报文类型

| 场景 | ICMP报文 |
|------|---------|
| **TTL减到0** | **超时（时间超过）** |
| 目的网络/主机不可达 | 目的不可达 |
| **路由器拥塞丢弃分组** | **源站抑制** |
| 路由不是最优 | 路由重定向 |
| **Ping测试连通性** | **回送请求和回答** |

> 应用层Ping基于ICMP，ICMP封装在IP中（不是TCP也不是UDP）

### 5. RIP vs OSPF

| 对比 | RIP | OSPF |
|------|-----|------|
| 类型 | **距离向量** | **链路状态** |
| 度量 | **跳数** | 链路开销/代价 |
| 交换对象 | 仅相邻路由器 | 向自治系统内**所有路由器**洪泛 |
| 交换内容 | 全部或主要路由表 | 自身相邻的**链路状态** |
| 更新时机 | **周期性**（30s） | **链路状态变化时** |
| 收敛 | 慢（16跳不可达） | 快 |
| VLSM/CIDR | RIPv1不支持，**RIPv2支持** | 支持 |
| 适用 | 小型网络 | 大型网络 |

### 6. 路由器

| 考点     | 答案              |
| ------ | --------------- |
| 主要功能   | **路由选择和分组转发**   |
| 转发依据   | **目的IP地址**      |
| 工作层    | **网络层**         |
| 直接交付条件 | 源和目的**子网号相同**   |
| 跨网通信   | 路由器检查**目的IP地址** |

> **网关**：实现不同网络协议转换，通过适当的**硬件与软件**完成

### 7. 直接广播 vs 受限广播

| 类型 | 形式 | 范围 |
|------|------|------|
| **直接广播** | A.B.C.**255**（主机位全1） | 特定网络内所有主机 |
| **受限广播** | **255.255.255.255** | 本网段所有主机（路由器不转发） |

> 例：202.114.211.255是直接广播地址（假设C类）
> 路由器收到直接广播 → 转发到对应网络；收到受限广播 → 不转发

### 8. IP地址分类

| 类别 | 第一字节 | 高位规则 | 二进制 | 网络号 | 主机号 |
|:---:|:-------:|:-------:|:-----:|:-----:|:-----:|
| A | **1-126** | 最高位固定**0** | 0xxxxxxx | 8位 | 24位 |
| B | **128-191** | 最高两位**10** | 10xxxxxx | 16位 | 16位 |
| C | **192-223** | 最高三位**110** | 110xxxxx | 24位 | 8位 |
| D | 224-239 | 最高四位**1110** | 1110xxxx | 多播 | — |

> 口诀：**0-A，10-B，110-C，1110-D**
> 考题："高三位为110表示该地址属于？" → **C类**

### 9. 网络层服务

> **无连接、不可靠、尽最大努力交付的数据报服务**

### 10. IPv6

| 考点 | 答案 |
|------|------|
| 地址长度 | **128位** |
| 记法 | **冒号十六进制** |
| 路由器分片 | **路由器不分片**（源主机负责） |
