# 四、简答题（5题 × 6分 = 30分）

## 31. 集线器/网桥/交换机/路由器区别（6分）

| 设备 | 工作层 | 转发依据 | 隔离冲突域 | 隔离广播域 |

**评分标准：** 表格完整正确6分（每个设备1.5分，工作层+转发+两域各算0.5分）

**30秒背诵版：** Hub=物理层什么都不隔，Switch=链路层隔冲突不隔广播，Router=网络层两个都隔。

## 32. TCP确认号与序号（6分）

**标准答案：**

1. **序号seq（2分）**：TCP报文段数据部分第一个字节的编号。TCP对每个字节编号。
2. **确认号ack（2分）**：期望收到的下一个字节的序号（即已连续收到的最后一个字节序号+1）。
3. **计算（2分）**：seq=200, data=300B → 最后字节=499。接收方回 ack = 499+1 = **500**，表示"0-499已收到，期望第500字节"。

**30秒背诵版：** seq=第一字节编号，ack=期望下一字节编号。ack=seq+数据长度。

---

## 33. 直接交付与间接交付（6分）

**标准答案：**

1. **直接交付（2分）**：目的主机与源主机在同一网络，不经过路由器。ARP查询目的主机MAC，直接封装帧发送。
2. **间接交付（2分）**：目的主机与源主机在不同网络，需经过路由器转发。ARP查询默认网关MAC。
3. **判断方法（2分）**：源主机用目的IP与自己子网掩码AND，结果=自己所在网络地址→直接交付；否则→间接交付。

**30秒背诵版：** 同网=直接(ARP查目标MAC)，跨网=间接(ARP查网关MAC)。用子网掩码AND判断。

## 34. IPv4与IPv6主要区别（6分，任意4点各1.5分）

1. **地址长度**：IPv4=32bit，IPv6=128bit
2. **分片行为**：IPv4路由器可分片(DF=0时)；IPv6路由器不分片(丢弃+ICMPv6 Packet Too Big)
3. **首部结构**：IPv4首部20-60B可变长，含校验和；IPv6首部固定40B，无校验和
4. **NAT需求**：IPv4因地址不足广泛使用NAT；IPv6地址充足不需要NAT
5. **安全性**：IPv6原生支持IPsec；IPv4的IPsec可选

---

## 35. 流量控制与拥塞控制区别（6分）

1. **控制目标（1.5分）**：流量控制→防止发送方过快导致接收方缓冲区溢出（端到端）；拥塞控制→防止过多数据注入导致网络拥塞（全局）。
2. **依赖变量（1.5分）**：流量控制→rwnd（接收方通告）；拥塞控制→cwnd（发送方维护）。
3. **实现机制（1.5分）**：流量控制→滑动窗口；拥塞控制→慢开始/拥塞避免/快重传/快恢复。
4. **发送窗口=min(rwnd,cwnd)（1.5分）**：发送窗口受两者共同约束。取min确保既不超过接收方能力(流量控制)，也不超过网络容量(拥塞控制)。哪个先成为瓶颈就以哪个为准。

# 五、综合应用题（40分）

## 36. CSMA/CD最大距离（10分）

**(1) R=100 Mbps下最大距离（3分）**

```
争用期 2τ = Lmin / R = 512 / (100×10⁶) = 5.12×10⁻⁶ s = 5.12 μs

τ = 2.56×10⁻⁶ s

d = τ × v = 2.56×10⁻⁶ × 2×10⁸ = 512 m
```

**答案：最大距离 = 512 m**

**(2) R=1 Gbps下最大距离（3分）**

```
2τ = 512 / (1×10⁹) = 0.512×10⁻⁶ s = 0.512 μs

τ = 0.256 μs

d = 0.256×10⁻⁶ × 2×10⁸ = 51.2 m
```

**答案：最大距离 = 51.2 m**

**(3) 保持512m，1 Gbps下的最短帧长（4分）**

```
τ = d/v = 512 / (2×10⁸) = 2.56×10⁻⁶ s
2τ = 5.12×10⁻⁶ s

Lmin = R × 2τ = 1×10⁹ × 5.12×10⁻⁶ = 5120 bit = 640 字节
```

**答案：最短帧长应为 640 B（5120 bit）**

> 启示：速率提高10倍→要么距离缩到1/10，要么最短帧扩大到10倍。这就是千兆以太网需要载波延伸技术的原因。

**评分标准：** (1)3分 (2)3分 (3)4分。每个小问公式1分+代入1分+结果1分

## 39. TCP序号确认号 + 拥塞控制（10分）

**(1) TCP seq和ack（6分）**

> 口径说明：500和800是握手完成后双方发送数据的当前序号（非ISN）。
> 即握手后A首个数据字节序号=500，B首个数据字节序号=800。
> 若题干改为ISN，则数据段seq应为ISN+1（因SYN消耗1个序号）。

a) A发送第一段：seq = **500**, ack = **800**（期待B的下一个字节=800，B尚未发数据，ack保持握手完成后的值）

b) A发送第二段：seq = **900**（=500+400），ack = **800**（未收到B新数据，ack不变）

c) B的确认：seq = **800**，ack = **1200**（=900+300，连续收到A的500~1199共700字节，期望A的下一个字节1200）

**(2) 拥塞控制（4分）**

a) **超时事件：**
```
超时 → ssthresh = cwnd/2 = 16/2 = 8 MSS
     → cwnd = 1 MSS
     → 重新进入慢开始
新值：ssthresh=8 MSS, cwnd=1 MSS
```

b) **3个重复ACK：**
```
3重复ACK → 快重传 + 快恢复
         → ssthresh = cwnd/2 = 16/2 = 8 MSS
         → cwnd = ssthresh = 8 MSS（不是从1开始！）
         → 直接进入拥塞避免阶段（线性增长）
新值：ssthresh=8 MSS, cwnd=8 MSS
```

**关键区别：** 超时→cwnd回1(慢开始)；3重复ACK→cwnd=ssthresh(快恢复，不回1)。这是最重要的考点！

**评分标准：**
- (1)每小问2分(seq+ack各1分)，共6分
- (2)a和b各2分：ssthresh计算(1分)+cwnd计算(1分)
