## 3. 确认纳入的考试范围

纳入：

- 网络概述：分层模型、PDU、协议三要素、交换方式、时延、设备与层次。
- 物理层：信道容量、奈奎斯特、香农、编码与调制、复用、传输介质、10Base命名。
- 数据链路层：成帧、透明传输、差错检测、CRC、停止等待、GBN、SR、CSMA/CD、CSMA/CA、以太网、交换机。
- 网络层：IPv4、特殊地址、子网、CIDR、VLSM、最长前缀、路由聚合、RIP、OSPF/BGP基础、IP分片、ARP、DHCP、ICMP、NAT、IPv6。
- 运输层：UDP、TCP、端口与分用、三次握手、四次挥手、seq/ack、可靠传输、流量控制、拥塞控制、RTT/RTO、Karn、SACK、零窗口。

排除：

- 应用层专题，包括 DNS、HTTP、HTTPS、FTP、SMTP、POP3、MIME 等。往年卷中出现过应用层，但用户明确要求本冲刺包不加入应用层；这些内容只在审计中记录，不安排训练时间。

## 4. 发现的冲突和处理

| 冲突 | 处理 |
|---|---|
| 某模拟卷中 CRC 例题 `1011110 / 1001` 给出余数 `011` | 采用专项资料校正版：余数 `100`，发送帧 `1011110100` |
| 有资料把可靠传输与TCP滑动窗口混写 | 本冲刺包区分：数据链路层窗口按帧编号，TCP窗口按字节编号 |
| 有资料把“覆盖知识点”当作“达到90分” | 本冲刺包改为：正式卷90分、非大题18/20、高风险变式5/6三重验收 |
| 有资料把UDP首部长度直接当数据长度 | 本冲刺包固定规则：UDP数据长度 = UDP总长度 - 8 |
| 有资料把IPv4协议字段归入转发/分片控制字段 | 本冲刺包采用修正口径：TTL、MF/片偏移、首部校验和与转发或分片强相关，协议字段只标识上层协议 |
