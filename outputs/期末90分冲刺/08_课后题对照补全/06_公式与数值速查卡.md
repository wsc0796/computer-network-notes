# 06_公式与数值速查卡

## 时延与吞吐

发送时延 = L / R

传播时延 = D / V

总时延 = 发送 + 传播 + 处理 + 排队

时延带宽积 = 带宽 × 传播时延

RTT = 往返时间

## 物理层

奈奎斯特：C = 2W log2M

香农：C = W log2(1 + S/N)

SNR(dB) = 10 log10(S/N)

S/N = 10^(SNR(dB)/10)

比特率 = 码元速率 × log2M

## CSMA/CD

最短帧：Lmin = 2τR = 2DR/V

最大距离：Dmax = Lmin × V / 2R

比特时间 = 1 / R

争用期 = 2τ

二进制指数退避：k = min(重传次数, 10)，r ∈ [0, 2^k - 1]

## 网络层

CIDR地址数 = 2^(32-n)

传统主机数 = 2^(32-n) - 2

网络地址 = IP AND 掩码

广播地址 = 主机位全1

IP非末分片数据长度 = floor((MTU-H)/8) × 8

片偏移 = 数据起始位置 / 8

## 数据链路层滑动窗口与信道利用率

数据帧发送时间：Tf = L / R

确认帧发送时间：Tack = Lack / Rack

一个发送周期：T = Tf + RTT + Tack

窗口内帧的总发送时间：t = Ws × Tf

信道利用率：U = min(1, Ws × Tf / (Tf + RTT + Tack))

停止等待：Ws = 1

若序号字段为n bit：

GBN：Ws ≤ 2^n - 1，Wr = 1

SR：Ws ≤ 2^(n-1)，Wr ≤ 2^(n-1)

达到100%利用率的最小窗口：Ws_min = ceil((Tf + RTT + Tack) / Tf)

注意：发送时延不是传播时延；RTT不是单程传播时延；数据链路层GBN/SR窗口不是TCP的rwnd/cwnd；ACK发送时间是否忽略必须看题干；U最大为1。

## 运输层

TCP实际窗口 = min(rwnd,cwnd)

TCP理论吞吐量 = min(链路带宽, 窗口/RTT)

带宽时延积 = 带宽 × RTT

下一序号 = 当前序号 + 数据长度 + SYN/FIN

确认号 = 期望收到的下一字节序号

超时：ssthresh = 原cwnd/2，cwnd = 1 MSS

3重复ACK：快重传，ssthresh = 原cwnd/2，cwnd = ssthresh附近，进入快恢复/拥塞避免
