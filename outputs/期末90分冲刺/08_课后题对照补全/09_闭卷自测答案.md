## 四、简答题

1. TCP与UDP：TCP面向连接、可靠、字节流、一对一、有流控和拥塞控制、首部至少20B；UDP无连接、尽最大努力、面向报文、支持一对多、无流控拥塞控制、首部8B。
2. ARP：IP到MAC；先查缓存；同网段广播请求目标IP，目标主机单播响应；跨网段查询默认网关MAC；ARP广播不能穿越路由器。
3. CSMA/CD：先听后发；空闲发送忙则等待；边发边听；碰撞停止并发送干扰信号；二进制指数退避后重发；适用于半双工共享式以太网。
4. 流控与拥控：流控防止接收方缓冲溢出，依据rwnd，端到端；拥控防止网络拥塞，依据cwnd，全局；发送窗口=min(rwnd,cwnd)。
5. 三次握手：C发SYN seq=x；S回SYN+ACK seq=y ack=x+1；C回ACK seq=x+1 ack=y+1。作用：确认双方收发能力、协商初始序号、防旧连接请求。

2. G=1011，r=3。M补0为110101000。模2除余数111。发送串=110101111。（考点：CRC）

5. 甲回复纯ACK：seq=乙段ack=2046；ack=乙段seq+数据长度=1913+100=2013。（考点：TCP序号确认号）

## 四、简答题

1. IP是网络层逻辑地址，IPv4 32bit，用于跨网络寻址，普通转发端到端不变；MAC是链路层物理地址，48bit，用于当前链路交付，每一跳改变。
2. RIP：IGP、距离向量、跳数、16不可达、适合小网络。OSPF：IGP、链路状态、最短路径、收敛快、适合较大AS内部。BGP：EGP、AS之间、路径向量/策略路由。
3. 四次挥手：FIN、ACK、FIN、ACK。TIME-WAIT在主动关闭方，等待2MSL，确保最后ACK到达，并让旧报文在网络中消失。
4. PPP：点到点协议；提供成帧、链路控制、网络层协议配置；用FCS检错；不提供可靠传输，无序号确认重传。
5. 慢开始：cwnd从1开始指数增长；拥塞避免：到ssthresh后线性增长；快重传：3个重复ACK立即重传；快恢复：ssthresh减半，cwnd到ssthresh附近后拥塞避免，超时则cwnd回1。

## 五、大题

1. 奈氏：C=2×3000×log2(4)=12000bps。香农：S/N=10^(30/10)=1000，C=3000×log2(1001)≈30000bps。理论上限取较小：12kbps。（考点：奈氏/香农）
2. L=64×8=512bit。Dmax=L×V/(2R)=512×2×10^8/(2×10^7)=5120m。（考点：CSMA/CD）
3. 192.168.1.200匹配/24，也匹配192.168.1.128/25；选最长前缀/25，因此走B。（考点：最长前缀匹配）
4. 源端口0x0721=1825；目的端口0x0045=69；总长度0x002C=44B；数据长度=44-8=36B；目的端口69为TFTP，方向为客户端到服务器。（考点：UDP首部）
5. RTT开始cwnd：1、2、4、8、9、10。若第6个RTT发生超时，按当时cwnd约10处理：ssthresh=5，cwnd=1MSS，重新慢开始。若题目按RTT结束值判定，以题目给定事件点为准。（考点：拥塞窗口）

## 新增专项大题20答案：数据链路层滑动窗口与信道利用率

已知：L=2000 bit，R=2 Mbps，Lack=200 bit，Rack=1 Mbps，RTT=8 ms。

1. Tf = L/R = 2000/(2×10^6) = 1 ms。Tack = Lack/Rack = 200/(1×10^6) = 0.2 ms。T = Tf + RTT + Tack = 1 + 8 + 0.2 = 9.2 ms。

2. 停止等待Ws=1：

U = min(1, 1×1/9.2) ≈ 0.1087 = 10.87%。

3. GBN，n=3：

Ws ≤ 2^3 - 1 = 7，Wr = 1。

最大U = min(1, 7×1/9.2) ≈ 0.7609 = 76.09%。

4. SR，n=3：

Ws ≤ 2^(3-1) = 4，Wr ≤ 4。

最大U = min(1, 4×1/9.2) ≈ 0.4348 = 43.48%。

5. 满利用率最小窗口：

Ws_min = ceil((Tf + RTT + Tack)/Tf) = ceil(9.2/1) = 10。

注意：这里RTT已经是往返时间，不再乘2；Tack题目已给长度和速率，不能忽略；利用率结果不能超过1。
