## 第二部分：简答题高频考点（每题5～6分，共30分）

> 以下按出现概率从高到低排列。
> 每道题的**30秒口述版**用于快速背诵，**评分点**用于阅卷自查。

---

### ★ 第1题：TCP三次握手过程（必考，6分）

**30秒口述版：**
```
客户端SYN→服务器SYN+ACK→客户端ACK。前两次证明客户端能发能收，
第三次证明服务器能发。作用是协商序号、防失效连接。
```

**评分点（缺一个扣1分）：**
```
[ ] 第一次：SYN=1, seq=x，进入SYN-SENT
[ ] 第二次：SYN=1, ACK=1, seq=y, ack=x+1，进入SYN-RCVD
[ ] 第三次：ACK=1, seq=x+1, ack=y+1，进入ESTABLISHED
[ ] SYN消耗1个序号（必须写！）
[ ] 作用：确认收发能力 + 协商序号 + 防失效连接
```

---

### ★ 第2题：TCP与UDP的区别（必考，6分）

**30秒口述版：**
```
TCP面向连接、可靠、字节流、一对一、有流量/拥塞控制、首部20B
UDP无连接、不可靠、报文、一对多等、无控制、首部8B
```

**评分点（6点，每点1分）：**
```
[ ] 面向连接 vs 无连接
[ ] 可靠 vs 不可靠（确认/重传/序号）
[ ] 字节流 vs 报文（保留边界）
[ ] 一对一 vs 可多对多
[ ] 有流量/拥塞控制 vs 无
[ ] 首部20B vs 8B
```

---

### ★ 第3题：TCP四次挥手 + TIME-WAIT（高频，6分）

**30秒口述版：**
```
A发FIN→B回ACK→B发完数据也发FIN→A回ACK并等2MSL。
因为是全双工双向关闭，所以四次。主动关闭方在TIME-WAIT。
```

**评分点：**
```
[ ] 第一次：A→B, FIN=1
[ ] 第二次：B→A, ACK=1
[ ] 第三次：B→A, FIN=1, ACK=1
[ ] 第四次：A→B, ACK=1
[ ] 主动关闭方进入TIME-WAIT，等2MSL
[ ] TIME-WAIT作用：确保最后ACK能到达 + 让旧报文消失
```

---

### ★ 第4题：CSMA/CD工作过程（高频，6分）

**30秒口述版：**
```
先听后发、边发边听、碰撞停止、随机重发。
空闲就发，忙就等，发时听碰撞，撞了就停发干扰信号，退避重发。
```

**评分点：**
```
[ ] 先听后发（监听载波）
[ ] 空闲发送，忙则等待
[ ] 边发边听（碰撞检测）
[ ] 碰撞→停止发送→发干扰信号
[ ] 随机退避（二进制指数退避）
[ ] 重发，连续16次失败则丢弃
```

---

### ★ 第5题：流量控制 vs 拥塞控制（高频，6分）

**30秒口述版：**
```
流量控制解决接收方太慢（端到端，rwnd），拥塞控制解决网络太堵（全局，cwnd）。
发送窗口 = min(rwnd, cwnd)。
```

**评分点：**
```
[ ] 流量控制保护接收方，端到端
[ ] 拥塞控制保护整个网络，全局
[ ] 流量控制通过rwnd通告
[ ] 拥塞控制通过cwnd自调
[ ] 发送窗口 = min(rwnd, cwnd)
[ ] 二者独立但共同约束发送速率
```

### ★ 第6题：五层体系结构及各层功能（必考，6分）

**30秒口述版：**
```
应用层：为应用程序服务（报文）
运输层：进程间通信（段）
网络层：路由转发（数据报）
链路层：相邻节点传输（帧）
物理层：比特流传输（比特）
```

**评分点：**
```
[ ] 5层名称全部正确且顺序对
[ ] 各层PDU正确（报文/段/数据报/帧/比特）
[ ] 运输层=进程间通信，网络层=路由选择
[ ] 封装过程：从上到下加首部
```

---

### ★ 第7题：ARP工作过程（高频，6分）

**30秒口述版：**
```
用IP查MAC。先看缓存，没有再广播问"谁是X.X.X.X？"，
目标单播回答"是我"。跨网段查网关的MAC。
```

**评分点：**
```
[ ] ARP功能：IP→MAC
[ ] 先查ARP缓存
[ ] 缓存未命中→广播请求（目的MAC全F）
[ ] 目标主机单播响应
[ ] 同网段查目标，跨网段查网关
[ ] ARP广播不能穿越路由器
```

---

### ★ 第8题：交换机自学习和转发（高频，6分）

**30秒口述版：**
```
先学源MAC→入端口，再查目的MAC→决定转发/泛洪/过滤。
已知定向转，未知则泛洪，同端口就过滤。
```

**评分点：**
```
[ ] 学习源MAC与入端口对应
[ ] 查目的MAC决定转发行为
[ ] 表中有且端口不同→定向转发
[ ] 表中无→泛洪（除入端口）
[ ] 目的端口=入端口→过滤
[ ] 广播帧→泛洪
```

---

### ★ 第9题：集线器与交换机区别（中频，6分）

**30秒口述版：**
```
集线器物理层不识别MAC，所有端口一个冲突域；
交换机链路层识别MAC，每端口独立冲突域。
```

**评分点：**
```
[ ] 工作层：集线器=物理层，交换机=数据链路层
[ ] 冲突域：集线器=所有端口一个，交换机=每端口一个
[ ] 广播域：两者默认都只有一个
[ ] 带宽：集线器共享，交换机独享
[ ] MAC识别：集线器不能，交换机能
[ ] 全双工：集线器不支持，交换机支持
```

---

### ★ 第10题：IP地址与MAC地址区别（中频，6分）

**30秒口述版：**
```
IP决定最终去哪（网络层、32bit、端到端不变），
MAC决定当前交给谁（链路层、48bit、每跳改变）。
```

**评分点：**
```
[ ] 工作层不同（网络层 vs 链路层）
[ ] 长度不同（32 vs 48 bit）
[ ] 性质不同（逻辑地址 vs 硬件地址）
[ ] 传输中是否改变（端到端不变 vs 每跳改变）
[ ] 作用不同（跨网络路由 vs 当前链路交付）
[ ] IP决定最终目的地，MAC决定下一跳
```

---

### ★ 第11题：RIP路由表更新规则（中频，6分）

**30秒口述版：**
```
邻居距离+1；原下一跳相同→必须更新；原下一跳不同→更短才替换；
16跳不可达；180s失效不转发；再120s删除。
```

**评分点：**
```
[ ] 收到邻居表→每条跳数+1
[ ] 下一跳相同→无条件替换（无论变大变小）
[ ] 下一跳不同→只有更短才替换
[ ] 16跳=不可达
[ ] 失效计时器180s→标记不可达，不用于转发
[ ] 删除计时器再等120s→从表中删除
```

---

### ★ 第12题：分组交换的特点（中频，6分）

**30秒口述版：**
```
报文划分分组→加首部→存储转发→独立选路→目的重组。
优点：利用率高、故障容错；缺点：时延不确定。
```

**评分点：**
```
[ ] 分组交换过程：划分→加首部→转发→重组
[ ] 存储转发机制
[ ] 分组可独立选择路径
[ ] 链路利用率高（统计复用）
[ ] 时延不确定（排队时延）
[ ] 相比电路交换：无连接、共享资源
```

**30秒口述版：**
```
复杂变简单、独立演进、标准化接口、某层改变不影响其他层。
```

**评分点：**
```
[ ] 复杂问题分解为若干子问题
[ ] 每层只负责特定功能
[ ] 层间使用标准接口
[ ] 便于维护和升级
[ ] 某层实现改变不影响其他层
[ ] 促进标准化
```

### ★ 第14题：拥塞控制四种算法（慢开始/拥塞避免/快重传/快恢复）（中频，6分）

**30秒口述版：**
```
慢开始：cwnd从1开始每RTT翻倍到ssthresh；
拥塞避免：每RTT+1到超时或3ACK；
超时→ssthresh减半、cwnd=1、重新慢开始；
3ACK→快重传、ssthresh减半、cwnd=ssthresh、进拥塞避免。
```

**评分点：**
```
[ ] 慢开始：cwnd=1，每RTT翻倍
[ ] 拥塞避免：每RTT+1 MSS
[ ] 超时：ssthresh=cwnd/2, cwnd=1，重新慢开始
[ ] 3重复ACK：快重传丢失段
[ ] 快恢复：ssthresh=cwnd/2, cwnd=ssthresh
[ ] 发送窗口=min(rwnd,cwnd)
```

### ★ 第15题：协议与服务的区别和联系（低频，6分）

**30秒口述版：**
```
协议是水平关系（对等实体间规则），服务是垂直关系（下层向上层）。
本层用下层服务，执行协议后向上层提供新服务。
```

**评分点：**
```
[ ] 协议定义对等实体通信规则
[ ] 协议三要素：语法、语义、时序
[ ] 服务是下层向相邻上层提供的功能
[ ] 协议是水平的，服务是垂直的
[ ] 本层使用下层服务
[ ] 本层执行协议后向上层提供服务
```

## 第三部分：2分钟考场速查

### 填空题最后检查清单

```
[ ] 所有数值的单位都对了？（bit/Byte/s）
[ ] PDU名称没写混？（帧≠数据报≠段）
[ ] 设备层对应写对了？（集线器=物理层）
```

### 简答题答题模板（通用）

```
1. 定义/概念（一句话说清楚是什么）
2. 过程/步骤（按顺序写，分点）
3. 关键数值/公式（如果有）
4. 作用/目的/意义（为什么需要）
5. 对比区分（如果是比较题，必写差异点）
```

> **阅卷潜规则：** 简答是按"采分点"给分的，不是按字数。每个评分点写到就给分，写漏就扣分。宁可写短但要写全，不要长篇大论漏了关键句。
