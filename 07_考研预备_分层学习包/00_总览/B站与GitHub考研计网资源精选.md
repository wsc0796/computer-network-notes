```text
特点：专注「计网考研每日一题」系列，全部是计算题/易错题
  IP 地址计算、子网划分、地址块分配、IP 分片、UDP 分片、

  「IP地址块的分配方案-计网考研」（32.8 万播放，2024-11）

经典题例（地址块计算，与子网专题联动）：
  140.120.84.24/20 → 最小地址 140.120.80.0（主机位全0）
                     最大地址 140.120.95.255（主机位全1）
                     掩码 255.255.240.0，共 2¹²=4096 个地址

与湖科大每日一题的区别：
  湖科大 = 系统课程 + 每日一题（跟着课程节奏）
  计网小学弟 = 纯计算题专项（查漏补缺、刷题用）

用法：复习完子网专题后，刷计网小学弟的题当"验收"——
  能独立做对，说明子网计算过关；做错进 05_错题本
```
