# 408 真题答案来源映射表

> 目的：将 OCR 题目、原始题面和可靠答案来源逐题关联。未建立映射的题目只能用于考点训练，不能标为“官方答案正确”。
>
> 本表不把本地课程试卷、二手题解或模型回答自动升级为 408 官方答案。

## 状态定义

| 状态 | 含义 |
|---|---|
| `待建` | 只有 OCR 或整理笔记，尚未定位原始题面和可靠答案来源。 |
| `题面已核` | 已定位原始题面或可追溯扫描件，但答案来源尚未核验。 |
| `答案待核` | 已有二手解析或交叉计算，仍没有足以确认的可靠答案来源。 |
| `已复核` | 原始题面、可靠答案来源和笔记解析均已逐题核对，记录了核对日期。 |

## 使用规则

```text
1. OCR 丢失题图、窗口状态、表格或选项时，先标“答案待核”，不凭上下文补造条件。
2. 原始题面与解析出现冲突时，记录冲突，不以多数二手答案投票决定结论。
3. 本地课程试卷只可核验资料中明确引用的同卷同题号内容；它不是 408 统考答案键。
4. 完成映射前，在学习笔记中将对应解析标注为“答案待核，当前仅用于考点训练”。
```
