## 采用审阅结论的规则

```text
资料“可进入强化”不等于学习者已达到强化。

学习者可称为“达到强化水平”的最低证据：
1. 首次 90 分钟未见题模拟验收至少 20/25，且综合题不低于 6/9；
2. 两周后另一套同难度未见题至少 20/25；
3. 两次错误均有原因、订正和对应笔记路径；
4. 能闭卷解释至少两个跨层场景，例如 DNS + HTTP + TCP，或 IP 分片 + MTU + TCP MSS。

任意一项不满足时，结论应是“资料可用，学习者尚未证明达到强化”。试题、答题纸和解析必须分离保存，完成原始作答前不得查看解析。
```
