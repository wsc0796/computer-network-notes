## 一、IEEE 802.11 无线局域网

### 1. CSMA/CA vs CSMA/CD

| 对比 | CSMA/CD（以太网） | CSMA/CA（802.11） |
|------|:---------------:|:----------------:|
| 检测方式 | **碰撞检测**(边发边听) | **碰撞避免**(发前先听) |
| 工作原理 | 发→检测到冲突→停止→退避重发 | 发前监听→退避→发→收方ACK |
| 无线特性 | 不适合无线（无法同时发和听） | 专为无线设计 |
| 确认 | 无（数据链路层无ACK） | **每帧都要ACK** |

**为什么无线不能用CSMA/CD？**
```
① 无线网卡难以同时发和听（半双工硬件限制）
② 隐藏站问题：A发B，C听不到A但能听到B
③ 信号衰减：碰撞检测在无线中不准确
```

### 2. 隐藏站问题与RTS/CTS

```
A ───────── B ───────── C

A在发数据给B, C检测不到A(太远) → C以为信道空闲 → C也发给B → 碰撞！

解决方法: RTS/CTS (可选)
A→B: RTS (Request to Send)
B→A: CTS (Clear to Send) → C听到CTS, C知道"B在忙", 就等待
A→B: Data
B→A: ACK
```

### 3. DCF vs PCF

| 方式 | 全称 | 特点 |
|:---:|------|------|
| **DCF** | 分布式协调功能 | **必须实现**、竞争信道、CSMA/CA |
| **PCF** | 点协调功能 | **可选**、无竞争、接入点轮询 |

> 实际部署中DCF为主，PCF几乎不用

### 4. 802.11帧格式

```
├─────┬─────┬──┬──┬──┬──┬───┬───┬───┬───┬─────┬───┬─────┤
│Frame│Dura│A│F│M│W│    │    │    │    │     │   │  FCS│
│Ctrl │tion│D│C│F│EP│Addr1│Addr2│Addr3│Seq│Addr4│   │     │
│ 2B  │ 2B │1│1│1│1│ 6B  │ 6B  │ 6B │ 2B│ 6B  │2B │ 4B  │
└─────┴─────┴─┴─┴─┴─┴────┴────┴────┴───┴─────┴───┴─────┘
```

**4个地址的用途：**

| 场景 | Addr1(RA) | Addr2(TA) | Addr3 | Addr4 |
|:---:|:---------:|:---------:|:----:|:----:|
| AP→站点 | 目的 | BSSID(AP) | 源 | — |
| 站点→AP | BSSID(AP) | 源 | 目的 | — |
| 无线分布 | 目的 | 源 | 目的 | 源 |

## 二、VLAN完整

### 1. 802.1Q标签

```
标准以太网帧:
├── 目的MAC ── 源MAC ── 类型/长度 ── 数据 ── FCS ──┤

带802.1Q标签的帧:
├── 目的MAC ── 源MAC ── 802.1Q标签(4B) ── 类型/长度 ── 数据 ── FCS ──┤
                         ├── TPID(0x8100,2B) ── PCP(3bit)+DEI(1bit)+VID(12bit) ──┤
```

| 字段 | 说明 |
|:---:|------|
| TPID | 0x8100，标明是802.1Q帧 |
| PCP | 优先级(0-7) |
| DEI | 丢弃合格指示 |
| **VID** | **VLAN ID(1-4094)**，0x000表示不携带VLAN，0xFFF保留 |

### 2. 端口类型

| 类型 | 用途 | 收帧行为 | 发帧行为 |
|:---:|------|---------|---------|
| **Access** | 连接PC/终端 | 收到无标签帧→打上端口VLAN标签 | 转发前→剥掉标签发无标签帧 |
| **Trunk** | 连接另一台交换机 | 接收带标签帧 | 保持标签转发（允许通过指定VLAN）|
| Hybrid | 混合 | 可收有/无标签帧 | 有选择地保留或剥离标签 |

### 3. VLAN间路由

```
VLAN10(192.168.10.0/24)       VLAN20(192.168.20.0/24)
  ┌─────────┐                    ┌─────────┐
  │   PC-A   │                    │   PC-B   │
  └────┬────┘                    └────┬────┘
       │                             │
       └─────────Switch────Trunk─────┘
                          │
                      路由器(子接口)
                    ┌───────────────┐
                    │ eth0.10: 10.1 │ ← VLAN10网关
                    │ eth0.20: 20.1 │ ← VLAN20网关
                    └───────────────┘

PC-A→PC-B: 同一台交换机、不同VLAN → 必须经路由器转发
```

> **VLAN隔离广播域**，不同VLAN间通信必须经过三层设备（路由器/三层交换机）

## 三、广域网协议

### 1. HDLC

| 特性 | 说明 |
|------|------|
| 类型 | **面向比特**的协议 |
| 帧格式 | 标志(01111110) + 地址 + 控制 + 信息 + FCS + 标志 |
| 透明传输 | **零比特填充**（连续5个1后插0）|
| 传输模式 | NRM(正常响应)/ABM(异步平衡)/ARM(异步响应) |
| 使用场景 | 点对点同步链路 |

**HDLC帧类型：**

| 类型 | 说明 |
|:---:|------|
| I帧 | 信息帧，承载数据，捎带确认/轮询 |
| S帧 | 监督帧，流量控制/差错控制（RR/RNR/REJ）|
| U帧 | 无编号帧，链路建立/释放/模式设置 |

### 2. PPP协议深入

| 特性 | PPP | HDLC |
|:---:|:---|:---|
| 面向 | **字节** | 比特 |
| 透明传输(异步) | **字节填充**(0x7E→0x7D 0x5E) | — |
| 透明传输(同步) | 零比特填充（同HDLC） | 零比特填充 |
| 认证 | PAP(明文)/CHAP(加密) | 一般无 |
| 多协议支持 | 通过NCP协商 | 通过协议字段 |
| 可靠传输 | 默认不可靠（无序号/确认/重传）| 可配置 |

**PPP状态图：**
```
链路静止 → 链路建立(LCP协商) → 认证(可选) → 网络层协议(NCP) → 链路打开
  ↑                                                        │
  └────────────────────── 链路终止 ──────────────────────────┘
```

## 四、网桥 + 交换机细节

### 1. 透明网桥算法

```
自学习过程:
① 收到帧 (frame arrives from source S on port X)
② 在转发表中记录 (S, X)
③ 查转发表看目的MAC是否在表中
   - 在表中，端口=入口 → 丢弃（过滤）
   - 在表中，端口≠入口 → 从该端口转发
   - 不在表中 → 泛洪到除入口外所有端口

老化：MAC表条目有TTL（默认300s），超时删除
```

### 2. 三种交换方式对比

| 方式 | 转发时机 | 延迟 | 错误检测 |
|:---:|---------|:---:|:-------:|
| **存储转发** | 完整收到帧并CRC校验后 | 最高 | **完整检测** |
| **直通** | 读到目的MAC后立即转发 | 最低 | 无检测 |
| **无碎片** | 读完64B前导后转发 | 中 | 避免碎片 |

> 考题：转发帧速度最慢的是**存储转发**，最快的是**直通**

### 3. 广播帧处理对比

```
        集线器    交换机(无VLAN)   路由器
广播帧:   扩散所有口    泛洪所有口     丢弃（不转发）
组播帧:   扩散所有口    视组播设置     可能转发
未知帧:   扩散所有口    泛洪所有口     —
```

## 五、海明码（考题）

### 1. 编码

```
数据位: m位 → 添加校验位 r位
条件: 2^r ≥ m + r + 1

数据位m和校验位r的对应:
m=4 → r=3;  m=8 → r=4;  m=16→ r=5

海明码的校验位放在 2^i 位置(1,2,4,8,16...)
每个校验位负责：该校验位+所有位置号有该位二进制位的位
```

**例题：数据1011，求海明码**
```
m=4 → r=3, 码长=7位

位置:  P1 P2 D1 P3 D2 D3 D4
        1  2  3  4  5  6  7

D1=1(位3), D2=0(位5), D3=1(位6), D4=1(位7)

P1(位1)=D1⊕D2⊕D4=1⊕0⊕1=0 (位3,5,7)
P2(位2)=D1⊕D3⊕D4=1⊕1⊕1=1 (位3,6,7)
P3(位4)=D2⊕D3⊕D4=0⊕1⊕1=0 (位5,6,7)

海明码: 0 1 1 0 0 1 1
        1 2 3 4 5 6 7
```

### 2. 纠错

```
收到码字后重新计算校验位P1'P2'P3', 与收到的P1P2P3比较
错误位置 = P1⊕P1' + 2×(P2⊕P2') + 4×(P3⊕P3')
```

## 六、物理层拾遗

### 1. 物理层四特性

| 特性 | 说明 |
|:---:|------|
| **机械** | 接口形状、引脚数量、尺寸 |
| **电气** | 电压范围、信号电平、传输速率 |
| **功能** | 各引脚功能（数据/控制/定时/地）|
| **过程** | 事件发生顺序 |

### 2. 串行 vs 并行

| 对比 | 串行 | 并行 |
|:---:|:----|:----|
| 传输 | 1位/时钟周期（一根线） | 多位/时钟周期（多根线）|
| 距离 | **远距离** | 近距离 |
| 干扰 | 小 | 大（线间串扰）|
| 成本 | 低 | 高 |
| 典型 | USB、SATA、以太网 | 旧式打印机端口、IDE |

### 3. 接口标准

| 标准 | 说明 |
|:----:|------|
| EIA RS-232C | 串行通信接口标准，DB-9连接器 |
| USB | 通用串行总线 |
| RJ-45 | 8P8C连接器，以太网双绞线用 |

### 4. 传输介质深入

| 介质 | 带宽 | 距离 | 抗干扰 |
|:---:|:----|:----|:------|
| 5类UTP | 100MHz/100m | 100m | 一般 |
| 超5类/6类 | 250MHz | 100m | 较好 |
| 多模光纤 | 宽 | 550m | 强 |
| 单模光纤 | 极宽 | 数十km | 最强 |

### 5. 典型时延计算（带宽时延积）

```
带宽时延积 = RTT × 带宽
            = 数据链路容量
            = 在传输途中能容纳的比特数

例: RTT=100ms, 带宽=10Mbps
    带宽时延积 = 0.1s × 10Mbps = 1Mb = 125KB
    意味着"管道"中可以容纳125KB的在飞数据
```

## 七、选择题高频陷阱

| 陷阱说法 | 纠正 |
|---------|------|
| 802.11使用CSMA/CD | ✗ 802.11使用**CSMA/CA** |
| 交换机隔离广播域 | ✗ 交换机只隔离冲突域，不隔离广播域 |
| VLAN隔离冲突域 | ✗ VLAN隔离**广播域** |
| 存储转发延迟最小 | ✗ 存储转发延迟**最大**，直通延迟最小 |
| 以太网需要帧结束定界符 | ✗ 以太网不需要帧结束定界符 |
| 802.11每帧不需要ACK | ✗ 802.11每帧必须ACK |
| HFC利用电话线接入 | ✗ HFC利用**有线电视网** |
| ADSL上下行速率相同 | ✗ ADSL**不对称**，上行慢下行快 |
| 海明码只能检错不能纠错 | ✗ 海明码**可纠错1位**（CRC只能检错）|
| PPP是面向比特的协议 | ✗ PPP是**面向字节**（HDLC才是面向比特）|
| CSMA/CD冲突可以避免 | ✗ 冲突**不可避免**（传播时延导致碰撞窗口）|
