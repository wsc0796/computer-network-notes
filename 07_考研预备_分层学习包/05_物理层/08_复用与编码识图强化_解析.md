# 复用与编码识图强化（解析版）

## 答案

`1. B  2. B  3. A  4. A  5. A`

## 解析

1. WDM 用不同波长在光纤中并发传输。FDM 分频、TDM 分时、CDMA 分码。
2. TDM 的资源单位是重复出现的时间片，不是频段、波长或码片。
3. `R·A/4=(0+2+2+0)/4=1`，`R·B/4=(0-2-2+0)/4=-1`，因此 A 发送 `+1`、B 发送 `-1`。
4. 按题干给定映射逐单元读出 `1 0 1 1 0`。
5. 初始为高：第 1 位跳变到低，第二位不变，第三位跳变到高，第四位跳变到低，第五位不变，故为 `10110`。
