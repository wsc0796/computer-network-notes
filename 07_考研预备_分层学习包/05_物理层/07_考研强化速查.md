# 考研强化 · 物理层速查

> 物理层是 408 记忆密集型章节：公式 4 个 + 编码 4 种 + 调制 4 种 + 复用 5 种。
> 目标：公式能秒算、编码能识图、概念不混。

---

## 一、两大核心公式

### 1. 奈奎斯特（无噪声，理想低通信道）

```text
C = 2W · log₂(V)

W = 带宽 (Hz)
V = 可区分的离散信号状态数/调制状态数（QAM/PSK 是星座点数）
C = 极限数据传输速率 (bps)
注：经典 2W 结论针对理想低通信道；带通信道结论不同。
```

### 2. 香农（有噪声）

```text
C = W · log₂(1 + S/N)

⚠️ S/N 是比值，不是 dB！
dB → 比值：S/N = 10^(dB/10)

常见换算（直接背）：
  10dB → 10
  20dB → 100
  30dB → 1000   ← 最常考
  40dB → 10000
```

### 3. 波特率 ↔ 比特率

```text
比特率 (bps) = 波特率 (Baud) × log₂(V)

波特率 = 每秒传输的码元数（码元可携带多位信息）
```

### 4. 联合考法（408 最爱）

```text
奈氏算一个上限 C₁，香农算一个上限 C₂，取 min（瓶颈决定实际速率）

规律：
  信噪比低（20dB）+ 电平多（32）→ 香农是瓶颈
  信噪比高（30dB）+ 电平少（8） → 奈氏是瓶颈
```

## 二、编码与调制

### 1. 四种编码（基带）

| 编码 | 特点 | 识别方法 |
|------|------|----------|
| **NRZ** | 两个稳定电平表示 0/1，位内无跳变（具体极性按题图约定） | 看电平 |
| **NRZ-I** | 边界跳变=1，无跳变=0 | 看边界有没有跳 |
| **曼彻斯特** | 位中间必有跳变，方向映射以题干/题图约定为准 | 看中间跳变方向 |
| **差分曼彻斯特** | 位中间必有跳变，边界跳=0 不跳=1 | 看边界跳变 |

```text
识别两步走：
① 每个位中间有跳变吗？
   没有 → NRZ 或 NRZ-I
   有   → 曼彻斯特 或 差分曼彻斯特
② 进一步区分：
   NRZ vs NRZ-I：NRZ 看电平（高/低映射以题图约定为准），NRZ-I 看边界（有跳=1,无跳=0）
    曼彻斯特 vs 差分曼彻斯特：曼彻斯特看中间跳变方向（方向映射以题干/题图约定为准），
                             差分曼彻斯特看边界跳变（有跳=0,无跳=1）
```

> 曼彻斯特编码自带时钟（位中间必有跳变），编码效率 50%。
> 10Base-T 用曼彻斯特；常见 100BASE-TX 使用 4B/5B + MLT-3；1000Base-X 用 8B/10B 编码。

### 2. 四种调制（带通）

| 调制 | 改变载体 | 记忆 |
|------|----------|------|
| **ASK** | 幅度 | Amplitude（振幅） |
| **FSK** | 频率 | Frequency（频率） |
| **PSK** | 相位 | Phase（相位） |
| **QAM** | 幅度+相位 | 组合调制；频谱效率通常较高（取决于阶数、信噪比、误码要求） |

> 2024 真题：需要 2 个不同频率载波的是 **二进制 FSK（2FSK）**（MFSK 可用更多频率）。

## 三、五种复用技术

| 复用 | 原理 | 特点 |
|------|------|------|
| **FDM** | 频率分割 | 按频带划分；数字数据调制后同样可用 |
| **TDM** | 时间分割 | 同步，固定时隙，用户空闲也占 |
| **STDM** | 统计时分 | 异步，按需分配时隙，利用率高 |
| **WDM** | 波分复用 | 光纤，光的不同波长 |
| **CDMA** | 码分多址 | 正交码序列，同频同时 |

> 对比：TDM 固定时隙浪费带宽；STDM 动态分配更高效。

## 四、传输方式与介质

```text
单工：只能一个方向（广播）
半双工：双方都能发，但不能同时（对讲机）
全双工：双方可同时收发（电话）

传输介质：
  双绞线：10Base-T（100m）
  同轴电缆：粗缆 10Base-5（500m）、细缆 10Base-2（185m）
  光纤：10Base-F，损耗低抗干扰强

10Base 命名：
  10 = 10 Mbps
  Base = 基带传输
  T = 双绞线  F = 光纤  5 = 粗缆  2 = 细缆
```

## 五、采样定理与 PCM（408 考点）

```text
采样定理（奈奎斯特采样）：采样频率 ≥ 2 × 信号最高频率
  （fs ≥ 2f_max，否则混叠失真）

PCM（脉冲编码调制）三步骤：
  采样 → 量化 → 编码

码率计算：
  码率 = 采样频率 × 量化位数（每样本 bit 数）
  例：8kHz 采样、8 bit 量化 → 64 kbps（电话语音）

量化级数 M → 位数 = log₂(M)
  128 级 → 7 bit；256 级 → 8 bit
```

## 六、物理层接口四特性（408 考点）

```text
① 机械特性：接口形状、引脚数目、排列
② 电气特性：各引脚电压范围、电平含义
③ 功能特性：各引脚的功能（数据/控制/定时/电源）
④ 过程特性：事件发生顺序（何时发出、何时应答）

不属于接口规范范围：物理地址（那是数据链路层的 MAC）
```

## 七、三种交换时延公式（23-25 连续出题）

```text
传输时间 = 文件大小 / 链路速率（仅指有效文件本身的发送时间）
分组数 N = ⌈文件大小 / (分组大小 - 首部开销)⌉（向上取整）

分组交换（h 条等速链路、存储转发、忽略传播/处理/排队）：
  T = (N + h - 1) × 分组发送时延
  ⚠️ 该式只在各分组等长（末分组被填充到完整长度）时成立；
  末分组不足且未填充时，须单独计算末分组的发送时间，不能按 N × 完整分组长。
  链路实际发送量 = 文件有效数据量 + N × 每分组首部开销

报文交换：T = h × 报文发送时延（逐跳整份转发）
电路交换：T = 建立时延 + 传输时间

⚠️ 三种交换无固定快慢顺序，必须按题给条件计算。
```

## 八、其他必背

```text
码元：承载信息的最小信号单位，可以是 2 电平（1 bit）或多电平（多 bit）

误码率：BER = 出错比特数 / 总比特数
  电话线：10⁻⁴ ~ 10⁻⁶；光纤：10⁻⁹ ~ 10⁻¹²
  （范围随介质质量、距离、速率变化，非绝对）

物理层设备：中继器（Repeater）、集线器（Hub）
  ——数字中继器/集线器对数字信号**再生、整形并转发**（不是简单放大；
    单纯放大会连同噪声一起放大），不隔离冲突域

传输介质分两类：
  导向：双绞线、同轴电缆、光纤
  非导向：无线电波、微波、红外线、激光
```

## 九、选择题高频陷阱

| 陷阱说法 | 纠正 |
|---------|------|
| 30dB 信噪比 = S/N = 30 | 30dB → S/N = **1000** |
| 香农公式里直接用 dB | 必须**先转比值**再代入 |
| 无噪声信道用香农公式 | 无噪声用**奈奎斯特**（2W·log₂V） |
| 比特率就是波特率 | 比特率 = 波特率 × log₂(V)，多电平时不同 |
| 双绞线是宽带传输 | 10Base-T 是**基带**传输 |
| 集线器隔离冲突域 | 集线器（物理层）**不隔离**冲突域，交换机（链路层）才隔离 |
| 曼彻斯特编码效率 100% | 效率 **50%**（通常每比特占两个信号间隔） |
| 数字信号必须用 FSK 传 | 基带信道可直接传数字信号；通过**带通信道**时通常必须数字调制 |
