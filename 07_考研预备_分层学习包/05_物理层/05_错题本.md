## 0. 做题前必看：物理层高频陷阱（预填）

| # | 陷阱说法 | 正解 | 来源 |
|:--:|---------|------|------|
| P1 | 30dB → S/N = 30 | 30dB → S/N = **1000**（S/N = 10^(dB/10)） | 陷阱清单 |
| P2 | 香农公式直接用 dB 值 | 香农公式里 S/N 是**比值**，必须先把 dB 转成比值 | 陷阱清单 |
| P3 | 奈奎斯特只考数据速率 | 奈氏有两条结论：**最高码元率 = 2W（Baud）**、**最高比特率 = 2W·log₂(V)**——两者都要会 | 陷阱清单 |
| P4 | 比特率 = 波特率 | 比特率 = 波特率 × **log₂(V)** | 陷阱清单 |
| P5 | 10Base-T 是宽带传输 | 10Base-T 的 Base = **基带**传输 | 04 题型训练 |
| P6 | 有噪声就只用香农公式 | **同时给定 W、V、S/N 时，奈氏和香农分别计算并取较小值**；只给其中一个上限条件时才用对应公式 | 2016 真题 |
