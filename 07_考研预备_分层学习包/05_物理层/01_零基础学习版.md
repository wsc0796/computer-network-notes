## 1. 物理层解决什么问题

物理层解决的是：

```text
如何把比特 0/1 转换成物理信号，并在传输介质上传输。
```

它不关心数据代表什么含义，只关心：

```text
怎么编码
怎么发送
能传多快
能传多远
噪声会造成什么限制
```

## 2. 物理层主线

```text
比特
    ↓
编码成信号
    ↓
通过介质传输
    ↓
受带宽、噪声、信噪比限制
    ↓
用奈奎斯特/香农公式估算极限速率
```

## 3. 比特率与波特率

比特率：

```text
每秒传输多少比特，单位 bps。
```

波特率：

```text
每秒传输多少码元，单位 Baud。
```

关系：

```text
若每个码元携带 n bit，则比特率 = 波特率 * n。
```

## 4. 编码方式

已有资料重点补强四种：

| 编码 | 识别要点 |
|---|---|
| NRZ | 高低电平直接表示 0/1，中间不一定跳变 |
| NRZ-I | 遇到 1 翻转，遇到 0 不翻转 |
| 曼彻斯特 | 每个比特中间都有跳变 |
| 差分曼彻斯特 | 每个比特中间有跳变，位开始是否跳变表示数据 |

考试重点：

```text
看波形识别编码类型。
```

## 5. 10Base 命名

常见记忆：

```text
10 表示 10 Mbps。
Base 表示基带传输。
T 表示双绞线。
5 表示粗缆约 500m。
2 表示细缆约 185m。
```

## 6. 奈奎斯特公式

适用：

```text
无噪声、理想低通信道。
```

公式：

```text
C = 2W * log2(V)
```

其中：

```text
W 是带宽（必须换算成 Hz，C 单位是 bit/s）。
V 是码元种类数/离散信号状态数/调制状态数 M
  （不只是"电平数"——QAM/PSK 里 V 是星座点数，
   只有题目明确给了相位数×振幅数时才直接相乘）。
```

等价核心考点（408 常考）：

```text
理想低通信道最高码元传输速率 = 2W（Baud）
最大比特率 = 最大码元率 × 每码元比特数 = 2W * log2(V)

log2(V) = 每个码元携带的比特数
V=2 → 1bit/码元；V=4 → 2bit/码元；V=16 → 4bit/码元
```

## 7. 香农公式

适用：

```text
有噪声信道。
```

公式：

```text
C = W * log2(1 + S/N)
```

如果给的是 dB：

```text
SNR(dB) = 10 * log10(S/N)
```

常见：

```text
30 dB -> S/N = 1000
```

## 7.5 奈氏 + 香农联合约束（408 大题核心）

```text
若题目同时给带宽、噪声/SNR、调制状态数：
  奈氏算一个上限 C₁ = 2W·log₂(V)
  香农算一个上限 C₂ = W·log₂(1+S/N)
  最终取 min（瓶颈决定实际速率）

⚠️ 不能机械理解为"无噪声只用奈氏、有噪声只用香农"——
  题同时给两个条件时，必须两个都算再取较小值。

规律（04 题型训练有 4 道变式）：
  信噪比低（20dB）+ 状态多（32）→ 香农是瓶颈
  信噪比高（30dB）+ 状态少（8） → 奈氏是瓶颈
```

## 9. 408 真题专章（半幺郎 分章节真题，2009-2025）

> 来源：`08_网盘资料接入/extracted_true_questions/02-物理层真题OCR.md`
> 考情：概念题（编码、接口特性）+ 计算题（奈氏/香农结合调制、三种交换方式 23-25 年连续出题）。

### 9.1 调制与波特率/比特率计算

**2011 真题（单选）**：若某通信链路的数据传输速率为 2400bps，采用四相位调制，则该链路的波特率是？

> 答案：**1200 波特**。
> 公式：波特率 = 比特率 / log₂(V) = 2400 / log₂(4) = 2400/2 = 1200。

**2022 真题（单选）**：在一条带宽为 200kHz 的无噪声信道上，若采用 4 个幅值的 ASK 调制，则该信道的最大数据传输速率是？

> 答案：**800kbps（C）**。
> 奈氏：C = 2W·log₂(V) = 2×200k×log₂(4) = 800kbps。
> 原题图明确给出 "200kHz" 和 "4 个幅值"；无噪声信道使用奈奎斯特上限，V=4 时每个码元承载 2 bit，故不能写成 400kbps。

**2009 真题（单选）**：在无噪声信道下，某通信链路的带宽为 3kHz，采用 4 个相位、每个相位具有 4 种振幅的 QAM 调制技术，则该通信链路的最大数据传输速率是？

> 答案：**24kbps**。
> V = 4 相位 × 4 振幅 = 16；C = 2×3000×log₂16 = 6000×4 = 24kbps。

**2023 真题（单选）**：某无噪声理想信道带宽为 4MHz，采用 QAM 调制，若该信道的最大数据传输速率是 48Mbps，该信道采用的 QAM 调制方案是？

> 答案：**QAM-64**。
> C = 2×4M×log₂(V) = 48M → log₂(V) = 6 → V = 64。

### 9.2 三种交换方式时延计算（23-25 连续出题）

**2010 真题（单选）**：采用"存储-转发"方式的分组交换网络中，所有链路的数据传输速率为 100Mbps，分组大小为 1000B（头 20B）。若主机 H1 向 H2 发送一个大小为 980000B 的文件，则不考虑分组拆装时间和传播延迟的情况下，从 H1 发送开始到 H2 接收完为止需要的时间至少是？

> 答案：**约 80ms**。
> 思路：数据分成 980000/980 = 1000 个分组；每分组发送时延 = 1000×8/100Mbps = 0.08ms。
> 原题附 H1-R-H2 拓扑（h=2 条等速链路）：T = (N+h-1)×0.08ms = (1000+2-1)×0.08 ≈ **80ms**。
> ⚠️ 链路数 h 由题图决定——没有 h 无法得到唯一答案，答题时先数链路再套 (N+h-1)。

**2013 真题（单选）**：主机甲通过一个路由器（存储转发）与主机乙互联，两段链路速率均 10Mbps，分别用报文交换和分组大小为 10kb 的分组交换发送 8Mb 报文，忽略传播延迟和分组头开销，两种方式完成传输的总时间分别为？

> 答案：**1600ms 和 801ms**。报文交换需在两段链路上各完整发送一次，时间为 800ms+800ms=1600ms；分组交换中 N=8Mb/10kb=800、每个分组发送时延为 1ms、链路数 h=2，因此 T=(N+h-1)×1ms=(800+2-1)×1ms=801ms。
> 核心：**报文交换逐跳整份转发，分组交换可流水线**。

**2025 真题（单选）**：主机 H1 向 H2 发送 2MB 文件，电路交换（建立 32ms、链路 10Mbps）、分组交换（分组 4KB）、报文交换（存储转发），从 H1 发送开始到 H2 接收完为止三种方式所需时间的大小关系为？

> 图中分组/报文交换网络经过 R1、R2 两台路由器，即 h=3 条链路。电路交换 Tc=32ms+2MB×8/10Mbps=1.632s；分组交换 N=2MB/4KB=500（按十进制单位 1MB=10⁶B、4KB=4000B 计）、每个分组发送时延为 3.2ms，Tps=(N+h-1)×3.2ms=(500+3-1)×3.2ms=1.6064s；报文交换 Tms=3×1.6s=4.8s。因此 **T分组 < T电路 < T报文**。不能把三种交换方式背成脱离拓扑和建立时延的固定排序。
> ⚠️ 若按 1MB=2²⁰B、4KB=4096B 则 N=512，三个数值随之改变，但大小关系不变——考题按十进制惯例，答题按题给单位换算。
> 考点：**三种交换的时延公式对比**。

### 9.3 数据报与虚电路

**2020 真题（单选）**：下列关于虚电路网络的叙述中，错误的是？

> 答案：**"为每条虚电路分配带宽"错误**——建立虚电路不等于必然为其预分配固定带宽（具体网络可做资源预留，但不是虚电路的必然属性）。
> 正确项：可以保证数据分组传输顺序、建立虚电路时需要进行路由选择、根据电路号（VCID）转发分组。

### 9.4 介质与接口特性（概念题）

**2019 真题（单选）**：100Base-T 快速以太网使用的导向传输介质是？

> 答案：**双绞线**。

**2012 真题（单选）**：在物理层接口特性中，用于描述完成每种功能的事件发生顺序的是？

> 答案：**过程特性**（机械/电气/功能/过程四大特性）。

**2018 真题（单选）**：下列选项中，不属于物理层接口规范定义范围的是？

> 答案：**物理地址**（物理地址是数据链路层 MAC 地址；接口形状=机械特性、引脚功能=功能特性、信号电平=电气特性）。

### 9.5 物理层 408 考情总结

```text
概念题重点：编码方式识别（NRZ/曼彻斯特/差分曼彻斯特）、物理层接口四特性
计算题两大类：奈氏+香农（结合调制 V 值）、三种交换方式时延（23-25 连续出题）
公式速记：
  波特率 = 比特率 / log₂(V)
  C = 2W·log₂(V)（无噪声）
  C = W·log₂(1+S/N)（有噪声，S/N 是比值）
  V = 相位数 × 振幅数（QAM）
```
