# 计算机网络考研预备：分层学习包使用说明

本目录用于大二下阶段把计算机网络整理成后续考研可复用资料。

每一层固定保留 4 份笔记：

```text
01_零基础学习版.md
02_课堂截图对应笔记.md
03_原资料包对照补强.md
04_题型训练.md
```

总错题统一放在：

```text
00_总错题表/计算机网络_总错题表.md
```

## 使用顺序

每学一层都按这个流程：

```text
1. 看视频并截图
2. 生成课堂截图对应笔记
3. 生成零基础学习版
4. 和原资料包对照，生成补强笔记
5. 做题型训练
6. 错题进入总错题表
```

## 层级顺序

建议按自顶向下：

```text
01_应用层
02_运输层
03_网络层
04_数据链路层
05_物理层
```

## 完成标准

每一层完成时，至少做到：

```text
能闭卷讲主线
能背核心概念
能做基础题
能说清错题原因
能知道考研常考题型
```

## 强化时间边界

```text
核心投入：以当年 408 计网考纲、未见题和错题复测为准。
了解即可：HTTP/3、QUIC、TLS 1.3 等现代工程细节，以及 06_网络安全中的扩展内容。
不因笔记更深而挤占真题、限时卷和错题复测的时间。
```

## 资料覆盖不等于学习者已掌握

本目录中的“完整”“已补全”仅表示资料结构和题型已准备，不能证明学习者已经达到强化水平。

要把资料状态升级为“学习者已验证”，至少需要留下：

```text
1. 闭卷复述：能独立讲清每层主线与易混概念。
2. 限时作答：完成未见过的选择、计算和综合题，保留原始答案与用时。
3. 订正闭环：错题能定位到知识点并在间隔复测中做对。
4. 跨层迁移：能解释题目中的分层、封装、地址、可靠传输和安全机制如何衔接。
```
