## 6. IP 分片计算（408 必考）

```
分片规则：
  除最后一片外，每片数据长度必须是 ___B 的整数倍（片偏移字段单位）
  （最后一片可以不是 8B 整数倍）
  总长度 = 数据 + ______B 首部
  MF=1 → 后面还有分片；MF=___ → 最后一片
  片偏移 = 该片数据起始位置 / ____

真题演练：
MTU=800B，原始数据报 1580B（首部20B）：
  每片最大数据 = (800-20)/8 取整×8 = ______B（=776）
  原始数据 = ______B（=1560，即 1580-20）
  分片数 = ______（=3：776 + 776 + 8）
  各片偏移 = ______、______、______（=0、97、194）
```
