## 0. 做题前必看：网络层高频陷阱（预填）

| # | 陷阱说法 | 正解 | 来源 |
|:--:|---------|------|------|
| N1 | RIP 是网络层协议 | RIP 是**应用层**协议（UDP 520） | 陷阱清单 |
| N2 | OSPF 基于 UDP/TCP | OSPF 直接封装在 **IP**（协议号 89） | 陷阱清单 |
| N3 | ARP 是数据链路层协议 | ARP 是**网络层**协议 | 陷阱清单 |
| N4 | DHCP 是网络层协议 | DHCP 是**应用层**协议（UDP 67/68） | 陷阱清单 |
| N5 | ICMP 封装在 UDP 中 | ICMP 直接封装在 **IP** 中 | 陷阱清单 |
| N6 | IPv6 地址 32bit | IPv6 地址 **128bit** | 陷阱清单 |
| N7 | IPv6 有广播地址 | IPv6 **没有广播地址**（用组播代替） | 陷阱清单 |
| N8 | TTL 减到 0 发目的不可达 | TTL 减到 0 发**超时（时间超过）** | 陷阱清单 |
| N9 | 路由器拥塞丢弃发超时 | 拥塞丢弃发 **ICMP 源点抑制（Source Quench）**——该机制已废弃，按历史真题作答时仍选它；现代实现不发 | 陷阱清单 |
| N10 | 可用主机数 = 2^h | 普通广播子网可用主机数 = **2^h - 2**（去网络号和广播地址）；例外：/31 点对点链路、/32 主机路由 | 陷阱清单 |
| N11 | 子网数 = 2^n - 2 | 子网数 = **2^n**（新口径） | 陷阱清单 |
| N12 | 片偏移以 1 字节为单位 | 片偏移以 **8 字节**为单位 | 陷阱清单 |
| N13 | 子网划分增加可用 IP | 子网划分**减少**可用 IP 总数 | 陷阱清单 |
