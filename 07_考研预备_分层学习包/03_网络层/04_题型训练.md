## 2. 必背公式与规则

```text
地址总数 = 2^主机位数
可用主机数 = 2^主机位数 - 2
片偏移单位 = 8 字节
最长前缀匹配：多个匹配时选前缀最长者
RIP 最大跳数：15，16 表示不可达
路由聚合：找所有地址的"最长公共前缀"
```

## 3. D1：子网划分题（选填计算常出）

**公式速记：**

```text
已知 IP 和掩码 → 求网络地址
  ① 把 IP 和掩码写成二进制
  ② IP AND 掩码 = 网络地址

已知 网络地址/前缀 → 求广播地址
  ① 主机位全部置 1
  ② 网络地址 + (2^主机位数 - 1)

可用主机范围 = 网络地址+1 ~ 广播地址-1
可用主机数 = 2^主机位数 - 2
```

**例题1：**

> IP = 192.168.1.130，掩码 = 255.255.255.192（/26），求网络地址、广播地址、可用主机范围。

```text
步骤：
  192.168.1.130        → 11000000.10101000.00000001.10 000010
  255.255.255.192      → 11111111.11111111.11111111.11 000000
  ──────────────────────────────────────────────────────────
  AND结果（网络地址）   → 11000000.10101000.00000001.10 000000
                       = 192.168.1.128/26

  广播地址：主机位（后6位）全置 1
            11000000.10101000.00000001.10 111111
            = 192.168.1.191

  可用范围：192.168.1.129 ~ 192.168.1.190
  可用主机数：2^6 - 2 = 62
```

**例题2：**

> 某公司使用 192.168.1.0/24，需要划分 4 个等长子网，求每个子网的网络地址、广播地址、可用范围。

```text
步骤：
  需要 4 个子网 → 借 2 位（2^2 = 4）
  原 /24 → /26，子网掩码 255.255.255.192
  每个子网有 2^6 - 2 = 62 个可用地址

  子网1：192.168.1.0/26   广播 192.168.1.63    可用 1~62
  子网2：192.168.1.64/26  广播 192.168.1.127   可用 65~126
  子网3：192.168.1.128/26 广播 192.168.1.191   可用 129~190
  子网4：192.168.1.192/26 广播 192.168.1.255   可用 193~254
```

## 4. D2：路由聚合题

**规则：找所有地址的"最长公共前缀"**

**例题：**

> 将以下 4 条路由聚合成一条：172.16.0.0/24、172.16.1.0/24、172.16.2.0/24、172.16.3.0/24

```text
步骤：
  172.16.0.0/24 → 172.16.000000 00.0
  172.16.1.0/24 → 172.16.000000 01.0
  172.16.2.0/24 → 172.16.000000 10.0
  172.16.3.0/24 → 172.16.000000 11.0
                  └──── 前22位相同 ────┘
  聚合结果：172.16.0.0/22

  验证：/22 有 2^(24-22) = 4 个 /24，恰好覆盖这4条。
```

## 5. D2：最长前缀匹配（路由表转发题）

**三步法：**
```text
① 目的IP 与每条路由的掩码做 AND（或用 /x 判断范围）
② 落在网络地址范围内 → 这条匹配
③ 多条匹配 → 选 /x 最大的那个
```

**例题：**

路由表：
| 目的网络 | 下一跳/接口 |
|---------|-----------|
| 192.168.1.0/24 | 接口0 |
| 192.168.1.128/25 | 接口1 |
| 192.168.0.0/16 | 接口2 |
| 0.0.0.0/0 | 接口3 |

目的IP = **192.168.1.130**，从哪个接口转发？

```text
逐条检查：
  192.168.1.0/24   → 范围 192.168.1.0~255      ✅ 匹配 /24
  192.168.1.128/25 → 范围 192.168.1.128~255    ✅ 匹配 /25 ← 最长
  192.168.0.0/16   → 范围 192.168.0.0~255.255  ✅ 匹配 /16
  0.0.0.0/0        → 全部匹配                  ✅ 匹配 /0

选最长前缀 → 接口1
```

## 6. D3：RIP 距离向量更新题（大题常考）

**更新三规则：**
```text
收到邻居的更新表，邻居的所有距离 +1，然后：
① 新网络 → 添加
② 距离更短 → 更新
③ 来自同一邻居 → 强制更新（不管距离变大变小）
```

**例题：**

路由器 R 当前路由表：
| 目的网络 | 距离 | 下一跳 |
|---------|:----:|:-----:|
| N1 | 3 | R2 |
| N2 | 5 | R3 |
| N3 | 2 | R1 |

收到邻居 R2 发来的路由表：
| 目的网络 | 距离 |
|---------|:----:|
| N1 | 2 |
| N2 | 4 |
| N4 | 3 |

求更新后的路由表。

```text
R2 的每条距离 +1 → N1:3, N2:5, N4:4

逐条对比：
  N1：R2 发来距离 3，当前也是 3（下一跳 R2，同一邻居）
      → 同一邻居 → 强制更新（即使相等也更新）
      → N1: 3, R2 ✓（不变）

  N2：R2 发来距离 5，当前是 5（下一跳 R3）
      → 新距离 5 ≥ 当前 5，且不是同一邻居 → 不更新
      → N2: 5, R3 ✓（不变）

  N4：新网络，当前路由表没有
      → 直接添加 → N4: 4, R2

更新后：
| 目的网络 | 距离 | 下一跳 |
|---------|:----:|:-----:|
| N1 | 3 | R2 |
| N2 | 5 | R3 |
| N3 | 2 | R1 |
| N4 | 4 | R2 |
```

## 7. D3：RIP vs OSPF 对比模板

| 对比项 | RIP | OSPF |
|-------|-----|------|
| 算法 | 距离向量（Bellman-Ford） | 链路状态（Dijkstra） |
| 度量 | 跳数 | 带宽/开销 |
| 最大跳数 | 15（16=不可达） | 无限制 |
| 更新方式 | 定期广播整个路由表 | 触发洪泛链路状态 |
| 收敛速度 | 慢（可能计数到无穷） | 快 |
| 复杂度 | 简单 | 复杂 |
| 适用 | 小型网络 | 大型企业/ISP |

**一句话记死：**
```text
RIP   = 小区快递（15跳极限 + 定期广播 = 只能小网络）
OSPF = 顺丰全国网（无跳数限制 + 触发更新 = 可到任何AS内部）
BGP  = 国际物流（谈策略、谈价格 = 互联网AS之间）
```

**适用场景的底层逻辑：**
```text
RIP 的 15 跳极限和定期广播机制 → 只能在小网络里玩
OSPF 的全网拓扑一致性要求     → 只能在 AS 内部用
BGP 的策略驱动特性             → 必须在 AS 之间用
```

**简答模板：**
```text
RIP 基于距离向量算法，以跳数为度量，最大 15 跳，16 跳表示不可达。
路由器每 30 秒向邻居广播整个路由表，收敛较慢，适合小型网络。

OSPF 基于链路状态算法，以链路带宽为度量，无跳数限制。
路由器通过洪泛链路状态信息让全网拓扑一致，收敛快，适合大型网络。
```

## 8. D4：IP 分片计算题

**公式：**
```text
数据长度 = 总长度 - IP首部（通常20字节）
每片数据长度 ≤ (MTU - 20)；除最后一片外必须是 8 的整数倍
片偏移 = 前一片的数据累计长度 / 8
MF：1 表示后面还有分片，0 表示最后一片
```

**例题：**

> IP 数据报总长 1500 字节（含 20 字节首部），需经过 MTU=620 字节的链路，求分片情况。

```text
原始数据长度 = 1500 - 20 = 1480 字节
MTU = 620，每片最大数据长度 = 620 - 20 = 600 字节
600 / 8 = 75，是 8 的倍数，符合要求

分片数 = ceil(1480 / 600) = 3 片

分片1：数据 0~599（600字节），偏移 0，  MF=1
分片2：数据 600~1199（600字节），偏移 75，MF=1
分片3：数据 1200~1479（280字节），偏移 150，MF=0
                                                  ↑ 最后一片 MF=0

| 分片 | 总长度 | 数据长度 | 片偏移 | MF |
|:----:|:-----:|:--------:|:-----:|:--:|
| 1 | 620 | 600 | 0 | 1 |
| 2 | 620 | 600 | 75 | 1 |
| 3 | 300 | 280 | 150 | 0 |
```

## 9. D4：简答模板库

### ARP 解析过程
```text
主机已知目标 IP 但不知道目标 MAC 时，
在同一局域网内广播 ARP 请求。
目标主机收到后单播回复 ARP 响应，告知自己的 MAC 地址。
发送方随后将 IP 数据报封装成帧发往该 MAC 地址。
```

### NAT 的作用
```text
NAT 在内网地址和公网地址之间做映射转换，
使多个内网主机共享一个公网 IP 访问互联网。
它缓解了 IPv4 地址短缺，但破坏了端到端透明性。
```

### DHCP 的 DORA 过程
```text
Discover：主机广播"谁给我 IP？"
Offer：DHCP 服务器广播"用这个 IP 吧"
Request：主机广播"我要了这个 IP"
ACK：服务器确认，租期开始
```

### 路由器转发分组过程
```text
① 收到 IP 数据报
② 取出目的 IP 地址
③ 查路由表，最长前缀匹配找到下一跳/端口
④ TTL 减 1，重新计算首部校验和
⑤ 将分组从对应端口转发出去
⑥ 若无匹配 → 丢弃，发 ICMP 差错报文
```

### 静态路由 vs 动态路由
```text
静态路由由管理员手动配置，不依赖路由协议。
优点是简单、可控、不占用网络带宽；
缺点是拓扑变化时需要人工调整，适合小型稳定网络。

动态路由通过路由协议自动交换信息，
能自适应拓扑变化，适合大型复杂网络。
```

## 12. 补丁3：ARP 跨网络陷阱（大题常出）

**场景题：**

> 主机 A（192.168.1.2/24）访问互联网服务器 B（8.8.8.8）。
> 请问：① A 会 ARP 查询谁的 MAC？② 数据帧中的目的 MAC 是什么？

```text
答：
① A 发现 B 不在同一子网，不会查 B 的 MAC，
   而是查默认网关（路由器接口 192.168.1.1）的 MAC。
② 帧中的目的 MAC = 网关接口的 MAC，不是 B 的 MAC。
```

> **一句话：跨网络通信时，ARP 永远查下一跳路由器的 MAC，不是最终目的主机的 MAC。**

## 13. 补丁4：VLSM 不等长子网划分

**公式：**
```text
核心原则：从大到小分配
① 最大需求的子网先分
② 每分完一个，剩余地址块继续分
```

**例题：**

> 使用 192.168.1.0/24 地址块，按以下需求划分子网：
> 部门A：100台 | 部门B：50台 | 部门C：20台 | 部门D：10台

```text
部门A 需 100 台 → 需要 2^7 - 2 = 126 ≥ 100，主机位 7 位 → /25
  子网1：192.168.1.0/25，可用 1~126
  剩余地址：192.168.1.128/25

部门B 需 50 台 → 需要 2^6 - 2 = 62 ≥ 50，主机位 6 位 → /26
  子网2：192.168.1.128/26，可用 129~190
  剩余地址：192.168.1.192/26

部门C 需 20 台 → 需要 2^5 - 2 = 30 ≥ 20，主机位 5 位 → /27
  子网3：192.168.1.192/27，可用 193~222
  剩余地址：192.168.1.224/27

部门D 需 10 台 → 需要 2^4 - 2 = 14 ≥ 10，主机位 4 位 → /28
  子网4：192.168.1.224/28，可用 225~238
  剩余地址：192.168.1.240/28（留用）
```

## 14. 补丁5：IP 分片完整规则

**在现有分片计算基础上，补充以下概念题：**

```text
① 同一原始数据报的各分片，标识字段相同 → 重组时归组依据
② DF=1 时禁止分片，超 MTU 则丢弃+ICMP
③ 最后一片的 MF=0，且数据长度可以不是 8 的整数倍
④ 分片由目的主机重组，不是中间路由器（IPv6 路由器也不分片）
⑤ 只要有一个分片丢失，整个原始数据报无法正常重组
```

**概念判断题：**

| 题干 | 答案 |
|------|------|
| 同一原始数据报的各分片 IP 首部完全相同 | ❌ 片偏移和 MF 不同 |
| 分片由中间路由器重组 | ❌ 由目的主机重组 |
| 最后一片的 MF=1 | ❌ MF=0 |
| 所有分片的数据长度都必须是 8 的倍数 | ❌ 最后一片可以不是 |
| 一个分片丢失，其他分片可以正常用 | ❌ 整个数据报无法重组 |

## 15. 408 真题专章（半幺郎 分章节真题，2009-2025）

> 来源：`08_网盘资料接入/extracted_true_questions/04-网络层真题OCR.md`
> 定位：网络层是**体系结构中最重要的层次**，预计 2026 年有很大概率命制大题。
> 最重要的考点：IPv4 分组格式、IPv4 地址、NAT、子网划分、路由聚合、子网掩码、CIDR、ARP、路由算法和路由协议、路由器。

### 15.1 考点一：IPv4 分组与分片

**2021 真题（单选）**：若路由器向 MTU=800B 的链路转发一个总长度为 1580B 的 IP 数据报（首部长度 20B）时进行了分片，且每个分片尽可能大，则第一个分片的总长度字段和 MF 标志位的值分别是？

> 答案：**796 和 1**。
> 计算：最大数据长度 = floor((800-20)/8)×8 = 776B；首片总长度 = 776+20 = 796B，片偏移以 8B 为单位。
> 关键：**分片数据必须是 8B 的整数倍**（片偏移字段以 8B 为单位）；总长度=数据+20；MF=1 表示后面还有分片。

**2018 真题（综合大题 9 分，分片）**：公司网络 IP 地址空间 192.168.1.0/24 均分给销售部和技术部两个子网。销售部子网 MTU=1500B，技术部子网 MTU=800B。假设主机 192.168.1.1 向主机 192.168.1.208 发送一个总长度为 1500B 的 IP 分组（首部 20B），路由器通过接口 F1 转发该 IP 分组时进行了分片：
> (1) 若分片时尽可能分为最大片，一个最大 IP 分片封装数据的字节数是多少？
> (2) 至少要分为几个分片？
> (3) 每个分片的片偏移量是多少？
> 思路：MTU=800 → 数据 ≤ 780B（且 8B 整数倍）→ 776B/片；1500-20=1480B 数据 → 1480/776 向上取整 = 2 片（776+704）。
> 片偏移：第 1 片 0，第 2 片 776/8=97。
> 考点：**分片计算三要素 = 最大数据字节数（8B 对齐）+ 分片数 + 片偏移（×8）**。

### 15.2 考点二：IPv4 地址与 NAT

**2017 真题（单选）**：下列 IP 地址中，只能作为 IP 分组的源 IP 地址但不能作为目的 IP 地址的是？

> 答案：**0.0.0.0**（本机源地址，表示"本网络中的本主机"）。
> 127.0.0.1 可作源和目的（回环）；255.255.255.255 只作目的（有限广播）。

**2023 真题（单选）**：主机 168.16.84.24/20 所在子网的最小可分配 IP 地址和最大可分配 IP 地址分别是？

> 答案：**168.16.80.1 和 168.16.95.254**。
> 计算：/20 → 第三字节低 4 位是主机位；84 = 01010100，网络边界 0101 0000=80；最小 = 网络地址+1 = 80.1，最大 = 广播地址-1 = 95.254。
> 陷阱：问"可分配"要排除网络地址（全0）和广播地址（全1）。

**2023 真题（单选，NAT）**：网络拓扑中路由器 R2 实现 NAT 功能，若主机 H 向 Internet 发送一个 IP 分组，则经过 R2 转发后该 IP 分组的源 IP 地址是？

> 答案：**R2 的外网接口 IP**（NAT 把内网私有地址替换为公网地址）。
> 考点：NAT 只改源地址（出方向）和目的地址（入方向），不改端口时是基础 NAT，改端口是 NAPT。

**2016 真题（单选，NAT）**：连接 R1、R2 和 R3 之间的点对点链路使用 201.1.3.x/30 地址，当 H 访问 Web 服务器时，R2 转发出去的封装 HTTP 请求报文的 IP 分组的源 IP 地址和目的 IP 地址分别？

> 答案：**201.1.3.x（R2 外接口）和 130.18.10.1（Web 服务器）**。
> 考点：NAT 后源地址变为出口路由器公网地址，目的地址不变。

**2020 真题（综合大题 9 分，NAT+ARP）**：校园网两个局域网通过路由器 R1、R3 互联接入 Internet，R2 为 NAT 路由器。问：
> (1) 为使 H2 和 H3 能访问 Web 服务器（使用默认端口），NAT 转换表结构如何？
> (2) H2 访问 Web 服务器时，发送前源/目的 IP？经过 R3 转发后的源/目的 IP？经过 R2 转发后的源/目的 IP？
> 考点：**NAT 转换表（内网IP:端口 ↔ 外网IP:端口）+ 逐跳 IP 地址变化**——源地址在 NAT 处改写，目的地址不变（出方向）。

### 15.3 考点三：子网划分与 CIDR（核心大题考点）

**2017 真题（单选）**：若将网络 21.3.0.0/16 划分为 128 个规模相同的子网，则每个子网可分配的最大 IP 地址个数是？

> 答案：**510**。
> 计算：/16 → /23（128=2⁷），主机位 9 位 → 2⁹-2 = 510。

**2019 真题（单选）**：若将 101.200.16.0/20 划分为 8 个子网，则可能的最小子网的可分配 IP 地址数是？

> 答案：**126**（官方答案，对应 /25）。
> 推理：/20 均分 8 个子网得 8 个 /23（每子网 2⁹-2 = 510 可用）；题目问"**可能的最小子网**"，即 8 个子网允许不等大（VLSM）——把某个 /23 继续细分，最小子网可到 /25 → 2⁷-2 = **126**。
> ⚠️ 两种口径的答案：等长划分 = 510（/23）；"可能的最小"按官方答案 = 126（/25）——本题问"最小"选后者；若原题选项不含 126 则按选项对应口径作答。

**2022 真题（单选）**：若某主机的 IP 地址是 183.80.72.48，子网掩码是 255.255.192.0，则该主机所在网络的网络地址是？

> 答案：**183.80.64.0**。
> 计算：255.255.192.0 → 第三字节 11000000；72 = 01001000；01001000 & 11000000 = 01000000 = 64 → 183.80.64.0。
> 方法：**IP 与掩码按位 AND，非 255/0 的字节逐位算**——第三字节是唯一需要二进制运算的字节。

**2021 真题（单选，子网包含判断）**：现将一个 IP 网络划分为 3 个子网，若其中一个子网是 192.168.9.128/26，则下列网络中不能是另外两个子网之一的是？

> 思路：192.168.9.128/26 占用了 .128~.191；另外两个子网必须与它**不重叠**、块边界对齐，且与原网互补覆盖。
> 判断准则（逐一验证选项）：
> ① 与 192.168.9.128/26 **重叠**的块（如 192.168.9.128/25 覆盖 .128-.255、.128/27 是 .128/26 内部的小块等与 .128-.191 有交集）→ **一定不能是**；
> ② 不重叠但**无法与另一个子网凑齐原网**（如只覆盖一半且块错位）→ 也不能是；
> ③ 典型互补划分（若原网为 /24）：192.168.9.0/25 + .128/26 + .192/26。
> ⚠️ 注意别把 .64/26（覆盖 .64-.127）误判为与 .128/26 重叠——它俩恰好相邻不重叠；
> 判断重叠只看地址区间是否相交，不看块大小。
> 考点：**子网边界不重叠 + 块大小对齐 + 覆盖完整**。原题四个选项按此准则逐一排除，含与 .128/26 重叠者即答案。

**2025 真题（综合大题，卫星链路子网划分）**：总部网工程部分配 IP 地址空间 10.10.0.0/24 再划分为 3 个子网：生活区子网不少于 13 台，作业子网和管理区子网均不少于 60 台。问：
> 思路：60台 → /26（2⁶-2=62≥60），13台 → /27 或更小。
> 分配：生活区 /27（30台）→ 10.10.0.0/27；作业区 /26 → 10.10.0.32/26？不对——先大后小：作业/管理各 /26（.0 和 .64），生活 /27（.128）。
> 考点：**VLSM 先大后小分配 + 边界对齐**（详见 08_子网专题.md）。

### 15.4 考点四：路由聚合（聚合计算）

**2018 真题（单选）**：某路由表中有转发接口相同的 4 条路由表项，目的网络地址分别为 35.230.32.0/21、35.230.40.0/21、35.230.48.0/21 和 35.230.56.0/21，将该 4 条路由聚合后的目的网络地址为？

> 答案：**35.230.32.0/19**。
> 计算：32=00100000、40=00101000、48=00110000、56=00111000；公共前缀：001（前 3 位相同）→ 32 的第三字节前 3 位是 001 → 聚合 /21-2=/19。
> 关键：**找最长公共前缀，看块大小（4 个 /21 = /19）**。

**2011 真题（单选）**：路由器 R1 只有到达子网 192.168.1.0/24 的路由，为使 R1 可以将 IP 分组正确地路由到图中所有的子网，需要在 R1 中增加的一条路由（目的网络、子网掩码、下一跳）是？

> 思路：目标子网与已知子网不同 → 增加一条更具体路由或默认路由。
> 考点：**路由表匹配规则（最长前缀优先）+ 缺省路由**。

**2013 真题（综合大题 9 分，AS 与聚合）**：Internet 的两个自治系统构成网络，AS1 由路由器 R1 连接两个子网构成，AS2 由 R2、R3 互联并连接 3 个子网构成。问：
> (1) 利用路由聚合技术给出 R2 的路由表（尽可能少的表项）；
> (2) R2 收到目的 IP 194.17.20.200 的分组，从哪个接口转发？
> (3) R1 与 R2 之间利用哪个路由协议交换路由信息？该协议报文被封装到什么协议中？
> 答案要点：(3) **BGP**（跨自治系统用边界网关协议），报文封装在 **TCP** 中。
> 考点：**RIP/OSPF 域内、BGP 域间 + 各自封装（RIP-UDP 520、OSPF-IP 89、BGP-TCP 179）**。

### 15.5 考点五：ARP 协议

**2012 真题（单选）**：ARP 协议的功能是？

> 答案：**根据 IP 地址查询 MAC 地址**。

**2018 真题（单选）**：路由器通过以太网交换机 S1 和 S2 连接两个网络，主机 H1 向 H2 发送一个 IP 分组，则 H1 发出的封装该 IP 分组的以太网帧的源 MAC 地址、H2 收到的封装该 IP 分组的以太网帧的目的 MAC 地址分别是？

> 答案：**源 = H1 的 MAC；H2 收到的帧目的 = H2 的 MAC**（最后一跳送达 H2 时，路由器把目的 MAC 改成 H2 的 MAC）。
> 关键：**MAC 地址逐跳变化**——H1 发出的帧目的 MAC 是第一跳路由器接口的 MAC；跨网转发时每跳改写目的/源 MAC，最终到达 H2 的那一帧目的 MAC 是 H2 自己的 MAC。

**2011 真题（综合大题）**：主机 MAC 地址 00-15-C5-C1-5E-28，IP 地址 10.2.128.100（私有地址），进行 Web 请求的以太网数据帧前 80B 十六进制及 ASCII 内容。问：主机的默认网关 MAC 地址是什么？

> 考点：**跨网访问 → ARP 查默认网关的 MAC**，帧的目的 MAC = 网关 MAC。

### 15.6 考点六：DHCP 协议

**2025 真题（单选）**：新接入网络的主机 H 通过 DHCP 服务器获取 IP 地址，封装 DHCP REQUEST 报文的 IP 数据报的目的 IP 地址和源 IP 地址分别是？

> 答案：**目的 = 255.255.255.255（广播，因为此时 H 还没有 IP）**，源 = 0.0.0.0。
> 考点：DHCP DORA 中 Discover/Request 用**广播**（0.0.0.0 → 255.255.255.255）。

**2022 真题（综合大题，DHCP+帧）**：H4 通过 DHCP 动态获取 IP 地址过程中，H4 首先发送了 DHCP 报文 M：
> (1) M 是哪种 DHCP 报文？（Discover）
> (2) 路由器 E0 接口能否收到封装 M 的以太网帧？（能——广播帧在本广播域内由交换设备洪泛，路由器默认不转发广播，但直连接口能收到）
> (3) 向 DHCP 服务器转发的封装 M 的以太网帧的目的 MAC 地址？（FF-FF-FF-FF-FF-FF 广播）
> 考点：**DHCP Discover = IP 广播 + MAC 广播**。

### 15.7 考点七：ICMP / IPv6 / SDN

**2012 真题（单选）**：在 TCP/IP 体系结构中，直接为 ICMP 提供服务的协议是？

> 答案：**IP**（ICMP 直接封装在 IP 中，协议号 1）。

**2010 真题（单选）**：若路由器 R 因为拥塞丢弃 IP 分组，则此时 R 可向发出该 IP 分组的源主机发送的 ICMP 报文类型是？

> 答案：**源点抑制（Source Quench）**（已废弃但经典考法）。
> 对比：TTL 减到 0 → 超时；目的不可达 → 目的主机/网络不可达。

**2023 真题（单选，IPv6）**：下列关于 IPv4 和 IPv6 的叙述中，正确的是？
> ① IPv6 地址空间是 IPv4 地址空间的 2⁹⁶ 倍（✅）
> ② IPv4 和 IPv6 的基本首部长度均可变（❌ IPv6 固定 40B）
> ③ IPv4 向 IPv6 过渡可以采用双协议栈和隧道技术（✅）
> ④ IPv6 首部的 Hop-Limit 字段等价于 IPv4 首部的 TTL 字段（✅）
> 答案：**①②③④ 中 ①③④ 正确**。

**2022 真题（单选，SDN）**：在 SDN 网络体系结构中，SDN 控制器向数据平面的 SDN 交换机下发流表时所使用的接口是？

> 答案：**南向接口**（控制器 ↔ 交换机 = 南向；应用 ↔ 控制器 = 北向；控制器之间 = 东/西向）。

### 15.8 考点八：路由协议（RIP 距离向量）

**2010 真题（单选）**：某自治系统内采用 RIP 协议。若路由器 R1 收到其邻居路由器 R2 的距离向量，距离向量中包含信息 <net1, 16>，则能得出的结论是？

> 答案：**R1 不能经过 R2 到达 net1**（距离 16 = 不可达，RIP 最大有效跳数 15）。

**2016 真题（单选）**：假设 R1、R2、R3 采用 RIP 协议交换路由信息且均已收敛。若 R3 检测到网络 201.1.2.0/25 不可达，并向 R2 通告一次新的距离向量，则 R2 更新后到达该网络的距离是？

> 答案：**16**（R2 经 R3 到达该网络：R3 通告不可达 = 16，下一跳不变 → 更新为 16；坏消息传得慢，该网络随即标记不可达）。
> 更新规则：收到 <net, D> 时——若原下一跳是发送者 → 无条件更新为新值；若原下一跳不同 → 仅当 D < 原距离才更新，否则保持。
> 经典陷阱：**距离 16 = 不可达；RIP 最多 15 跳**。

**2021 真题（单选，距离向量计算）**：某网络中的所有路由器均采用距离向量路由算法计算路由。路由器 E 与邻居路由器 A、B、C 和 D 之间的直接链路距离分别是 6、10、12 和 6，且 E 收到邻居路由器的距离向量，则路由器 E 更新后到达目的网络 N1 和 N2 的距离分别是？

> 思路：对每个邻居：距离 = 邻居到目标的距离 + E到邻居的链路距离，取最小。
> 考点：**Bellman-Ford：d(E, N) = min(邻居距离 + 链路代价)**（详见 09_RIP路由更新专题.md）。

**2017 真题（单选，封装）**：直接封装 RIP、OSPF、BGP 报文的协议分别是？

> 答案：**RIP→UDP、OSPF→IP、BGP→TCP**。
> 记忆：**RIP 搭 UDP（520）、OSPF 直上 IP（89）、BGP 走 TCP（179）**。

### 15.9 考点九：网络层设备

**2010 真题（单选）**：下列网络设备中，能够抑制广播风暴的是？

> 答案：**路由器**（路由器隔离广播域；中继器/集线器/网桥都不隔离广播）。

**2012 真题（单选）**：下列关于 IP 路由器功能的描述中，正确的是？
> ① 运行路由协议、设置路由表（✅）
> ② 监测到拥塞时，合理丢弃 IP 分组（✅）
> ③ 对收到的 IP 分组头进行差错校验，确保传输的 IP 分组不丢失（❌ IP 不保证可靠）
> ④ 根据目的 IP 地址转发到合适的输出线路（✅）
> 答案：**①②④ 正确**。

**2015 真题（单选，最长前缀匹配）**：某路由器的路由表，收到目的地址为 169.96.40.5 的 IP 分组，转发接口是？

> 思路：逐条匹配路由表，多条匹配时选**最长前缀**。
> 考点：**最长前缀匹配 + 默认路由兜底**（详见 10_路由表构建与聚合专题.md）。
