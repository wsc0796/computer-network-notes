## 0. 做题前必看：运输层高频陷阱（预填）

| # | 陷阱说法 | 正解 | 来源 |
|:--:|---------|------|------|
| T1 | TCP 面向报文，UDP 面向字节流 | **TCP 面向字节流，UDP 面向报文**（正好反过来） | 总错题表 |
| T2 | UDP 提供可靠服务 | UDP 是**尽最大努力交付**，不提供可靠服务 | 总错题表 |
| T3 | UDP 首部最小 20 字节 | UDP 首部固定 **8 字节**；TCP 首部最小 20 字节 | 总错题表 |
| T4 | 网络层服务类型不影响运输层运行机制 | ◐ 有条件的对（特定判断题）：运输层机制不因下层数据报/虚电路而重写，但下层可靠性/顺序会影响运输层采用的机制，服务质量也受网络层影响——完整判断题需保留题干限定 | 总错题表 |
| T5 | TCP 首部固定 20B | TCP 首部 **20-60B**（选项字段可变） | 陷阱清单 |
| T6 | 快重传后进入慢开始 | 快重传后进入**快恢复**（跳过慢开始）——TCP Reno/408 简化模型；Tahoe 在重复 ACK 后回到慢开始 | 陷阱清单 |
| T7 | TTL 减到 0 发"目的不可达" | TTL 减到 0 发**超时（时间超过）**——⚠️ 本项属于网络层 ICMP 考点，运输层错题本中仅作提醒，章节归因以网络层为准 | 陷阱清单 |
| T8 | 确认号 = 最后收到的字节序号 | 确认号 = **期望收到的下一个字节序号** | 陷阱清单 |
| T9 | TCP 发送窗口 = rwnd | 发送窗口 = **min(rwnd, cwnd)** | 陷阱清单 |
