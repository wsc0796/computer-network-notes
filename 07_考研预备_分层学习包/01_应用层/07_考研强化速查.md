## 一、DNS（域名系统）

### 1. 层次结构

```
根域名服务器 (13组, 标号a-m)
├── 顶级域名服务器 (TLD): .com, .cn, .org, .edu
│   ├── 权威域名服务器: 各组织自己维护
│   │   └── 本地域名服务器 (递归解析器)
```

### 2. 查询方式

| 方式 | 过程 | 负载方 |
|------|------|--------|
| **递归查询** | 本地DNS问根→根问TLD→TLD问权威→逐层返回 | **本地DNS负担重** |
| **迭代查询** | 根告诉本地"去问TLD"，TLD告诉"去问权威" | **根/TLD负担轻** |

> 典型流程：**主机→本地DNS(递归) → 根(迭代) → TLD(迭代) → 权威(迭代) → 返回**

### 3. DNS缓存

- 本地DNS服务器缓存结果（有TTL）
- 浏览器也有DNS缓存
- 缓存可减轻根/TLD压力

### 4. DNS报文

> 使用 **UDP 53**（大多数查询）
> 区域传输用 **TCP 53**（数据量超过512B时）

| 字段 | 说明 |
|------|------|
| 标识符 | 匹配请求和响应 |
| 标志 | QR(查询/响应)、AA(权威)、RD(期望递归)、RA(可用递归) |
| 问题数/回答数/权威数/附加数 | 4个计数字段 |

## 二、HTTP/HTTPS

### 1. HTTP连接方式

| 方式 | 特点 | 每个对象连接数 |
|------|------|:-----------:|
| **非持久连接** | 每个对象一个TCP连接 | N个对象= N次TCP |
| **持久连接（HTTP 1.1默认）** | 同一连接传多个对象 | 1次TCP |
| **流水线** | 不等待响应连续发送请求 | 1次TCP，请求连续发 |

> HTTP 1.0默认非持久，HTTP 1.1默认持久+流水线

### 2. HTTP报文结构

**请求报文：**
```
方法 URL 版本
首部字段名: 值
(空行)
实体主体（POST时有）
```

**响应报文：**
```
版本 状态码 短语
首部字段名: 值
(空行)
实体主体
```

### 3. 方法

| 方法 | 用途 |
|------|------|
| GET | 请求资源 |
| POST | 提交数据 |
| HEAD | 请求响应首部（不返回实体）|
| PUT | 上传文件 |
| DELETE | 删除文件 |

### 4. 状态码

| 状态码 | 含义 |
|:-----:|------|
| 1xx | 信息性 |
| 2xx | 成功（200 OK） |
| 3xx | 重定向（301 永久迁移, 302 临时） |
| 4xx | 客户端错误（404 未找到） |
| 5xx | 服务器错误（503 服务不可用）|

### 5. Cookie

```
用户 ←→ 浏览器 ←Cookie→ 服务器

Cookie用途：
- 身份识别
- 会话管理
- 个性化推荐
```

### 6. 缓存

| 机制 | 说明 |
|------|------|
| **强缓存** | Expires / Cache-Control: max-age，未过期直接用 |
| **协商缓存** | Last-Modified / ETag → 304 Not Modified |

### 7. HTTPS

> HTTP + SSL/TLS（443端口）

```
HTTPS握手：
① 客户端发支持的加密套件+随机数
② 服务器返回证书+选定的加密套件+随机数
③ 客户端验证证书，生成预主密钥，用服务器公钥加密发送
④ 双方用三个随机数生成会话密钥
⑤ 之后通信用会话密钥对称加密
```

### 8. HTTP版本对比

| 版本 | 特点 |
|:---:|------|
| 1.0 | 非持久，每个对象一个TCP |
| 1.1 | 持久+流水线，Host首部，块传输 |
| 2.0 | 多路复用、二进制分帧、服务器推送、首部压缩 |
| 3.0 | 基于QUIC（UDP），0-RTT连接建立 |

## 三、FTP（文件传输协议）

### 1. 双连接

| 连接 | 方向 | 端口 |
|------|------|:---:|
| **控制连接** | 整个会话保持 | TCP **21** |
| **数据连接** | 传输文件时创建，传输完关闭 | TCP **20**（主动） |

### 2. 两种模式

| 模式 | 数据连接建立方式 |
|------|----------------|
| **主动模式（PORT）** | 服务器主动连客户端20端口 |
| **被动模式（PASV）** | 服务器开放端口，客户端主动连 |

> 防火墙环境下常用被动模式

### 3. 特点

- 控制连接带外传输（out-of-band）
- 服务器保留状态（跟踪用户当前位置）
- 用户名/密码认证

## 四、电子邮件

### 1. 体系结构

```
用户代理(UA) ←SMTP→ 邮件服务器 ←SMTP→ 邮件服务器 ←POP3/IMAP→ 用户代理(UA)
    Outlook           发送端                接收端              Outlook
```

### 2. 协议对比

| 协议 | 端口 | 作用 | 特点 |
|------|:---:|------|------|
| **SMTP** | 25 | 发送/转发邮件 | 推协议(push)，ASCII，不能处理附件→MIME扩展 |
| **POP3** | 110 | 接收邮件（下载） | 拉协议(pull)，下载后默认删除服务器邮件 |
| **IMAP** | 143 | 接收邮件（在线操作） | 拉协议，邮件保留服务器，管理文件夹 |
| **MIME** | — | SMTP附件扩展 | 将二进制→ASCII传输 |

### 3. SMTP vs HTTP

| 特性 | SMTP | HTTP |
|------|------|------|
| 方向 | 推(push) | 拉(pull) |
| 格式 | 7位ASCII | MIME/二进制 |
| 连接 | 持续 | 可根据版本不同 |
| 状态码 | 3位数字 | 3位数字 |

## 五、DHCP（动态主机配置协议）

### 1. DORA过程

```
① Discover（广播）: "谁有IP给我？"
② Offer（可选广播/单播）: "我用这个IP给你"
③ Request（广播）: "我要用这个IP"
④ ACK（可选广播/单播）: "确认，你可以用"
```

### 2. 关键点

| 点 | 说明 |
|---|------|
| 端口 | 客户端 **67**，服务器 **68** |
| 传输层 | UDP |
| 地址租期 | 到期需续约 |
| 跨网段 | 需要DHCP中继代理（relay agent）|

> 考题：DHCP用广播请求，因为客户端此时还没有IP地址

## 八、选择题高频陷阱

| 陷阱说法 | 纠正 |
|---------|------|
| DNS使用TCP 53 | ◐ 大多数查询用UDP 53（超过512B才用TCP 53） |
| 根域名服务器存储所有域名映射 | ✗ 根只存储TLD服务器的IP，不存储具体域名 |
| 递归查询比迭代查询快 | 不一定，递归加重本地DNS负担 |
| HTTP 1.0默认持久连接 | ✗ HTTP 1.0默认**非持久** |
| FTP数据连接一直保持 | ✗ 控制连接保持，数据连接每次传输新建 |
| SMTP直接传二进制文件 | ✗ SMTP是ASCII，二进制需MIME编码 |
| POP3邮件保留在服务器 | ✗ POP3默认**下载后删除**（IMAP才保留） |
| DHCP服务器端口67，客户端68 | ✗ 客户端**67**，服务器**68**（说反了！） |
| RIP是网络层协议 | ✗ RIP是应用层协议（基于UDP 520） |
