## 参考答案

### 1. DNS 查询过程
① 递归（主机只发一次） ② 迭代；本地 DNS 问**根**，根返回 **TLD** 转介；再问 **TLD**，TLD 返回**权威服务器**转介；最后问**权威服务器**并得到目标 IP

### 2. HTTP 持久 vs 非持久
非持久：N 次 TCP 连接；每对象耗时 = 建连 1 RTT + 请求响应 1 RTT = 2 RTT；从开始建立首连计时为 **2N RTT**，首连已建立时为 **(2N-1) RTT**
持久：1 次 TCP 连接（限定同一服务器且连接未关闭）；流水线 = 发送请求**不用**等待响应

### 3. FTP 双连接
控制连接：端口 **21**，**保持**（整个会话）
数据连接：端口 **主动=服务器源端口20 / 被动=服务器临时端口**，**传输完关闭**
主动模式：服务器**主动**连客户端；被动模式：服务器**开放端口等**客户端连
（主动模式服务器源端口 **20**，客户端数据端口是临时端口；被动模式服务器用**临时端口**，不是固定 20）

### 4. 电子邮件协议
发送邮件：**SMTP** 端口 **25**；接收方式1：**POP3** 端口 **110** 特点：**下载到本地**（下载后删除/保留由客户端配置决定）；接收方式2：**IMAP** 端口 **143** 特点：**邮件保留服务器、在线操作**
格式扩展：**MIME**；二进制→ASCII：**base64**（常用编码之一，还有 quoted-printable）

### 5. 端口号默写
FTP数据 **20（主动模式服务器源端口）**、FTP控制 **21**、SSH **22**、Telnet **23**、SMTP **25**、DNS **53**、DHCP服务器 **67**、DHCP客户端 **68**、TFTP **69**、HTTP **80**、POP3 **110**、IMAP **143**、HTTPS **443**、RIP **520**

### 6. 浏览器访问网页全过程
① DNS：域名→IP 解析（递归+迭代） ② TCP：三次握手建立连接
③ HTTPS 时先进行 TLS 握手 ④ HTTP：请求并接收 HTML
⑤ 浏览器解析 HTML 后，再对 CSS/JS/图片等资源发送请求 ⑥ 浏览器解析并渲染

### 7. DNS 层次结构与缓存
命名层次：根（**13 个逻辑标识 A-M，通过任播部署大量实例**）→ **顶级**域名服务器（.com/.cn/.org）→ **权威**域名服务器（各组织维护）
查询入口：主机 → 本地域名服务器（**递归解析器，位于命名层次树之外**）
缓存位置：① **浏览器** ② **操作系统** ③ **本地域名服务器**；有效期由 **TTL** 控制

### 8. HTTP 报文结构与状态码
请求报文：**首部**字段、**(空行)**、实体主体（**POST/PUT/PATCH 等**方法时有）
状态码：1xx **信息性** 2xx **成功**（200=**OK**） 3xx **重定向**（301=**永久迁移**、304=**协商缓存命中**） 4xx **客户端错误**（404=**未找到**） 5xx **服务器错误**（503=**服务不可用**）
方法：GET=**请求资源** POST=**提交数据** HEAD=**只请求响应首部** PUT=**用请求内容创建/整体替换目标资源**

### 9. DHCP（DORA）
① **Discover（广播）** ② **Offer（可选广播/单播）** ③ **Request（广播）** ④ **ACK（可选广播/单播）**
用**广播**（客户端还没有 IP）；端口：客户端 **68**，服务器 **67**；传输层：**UDP**；跨网段需要 **DHCP 中继代理**

### 10. HTTPS 握手（旧式 TLS_RSA 简化流程）
① 支持的**加密套件** ② **证书** ③ 客户端**验证**证书，生成**预主密钥** ④ **会话**密钥 ⑤ 用**会话密钥对称**加密
（TLS 同时提供完整性/认证保护；TLS 1.3 已取消 RSA 密钥传输，改用 (EC)DHE）

### 11. 协议归属速查
RIP：**应用**层，**520**；DHCP：**应用**层，**67/68**；OSPF：直接封装在 **IP 报文**（协议号 **89**）；
ARP：按本资料采用的 **408/目标教材口径归为网络层（接口协议）**，负责 **IP 地址 → MAC 地址**；DNS：**应用**层，常用 **UDP 53**

### 12. 网络应用模型
C/S：**客户端**主动请求、**服务器**持续提供服务，客户端之间通常**不能**直接通信；P2P：节点地位**对等**，既可请求也可**提供/上传**资源

### 13. Cookie、Web 缓存与 CDN
Cookie 保存**会话状态/用户标识**；`Set-Cookie` 在**响应**报文；协商缓存未修改返回 **304**；CDN 把内容部署到靠近**用户**的边缘节点

### 14. WWW 与 URL
WWW 采用 **C/S** 模型，核心角色包括浏览器、**Web 服务器**和超链接/HTML；URL 基本格式为 **协议://主机:端口/路径**

### 15. 邮件格式与 Web 邮件
邮件格式为**首部 + 空行 + 主体**，常见首部有 From、To、**Subject**；浏览器与 Web 邮件系统之间使用 **HTTP/HTTPS**，邮件服务器之间使用 **SMTP**；IMAP 是**邮件访问**协议
