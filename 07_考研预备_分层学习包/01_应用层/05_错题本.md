## 0. 做题前必看：408 应用层高频陷阱（预填）

| # | 陷阱说法 | 正解 | 来源 |
|:--:|---------|------|------|
| A1 | DNS 使用 TCP 53 | 大多数查询用 **UDP 53**；EDNS 下 UDP 可超 512B，通常是在**收到截断响应、区域传送或明确要求 TCP** 时使用 TCP | 陷阱清单 |
| A2 | 根域名服务器存储所有域名映射 | 根区只保存**顶级域的委派信息**（NS 记录及必要 glue 记录），不存具体域名映射 | 陷阱清单 |
| A3 | 递归查询比迭代查询快 | 不一定；递归/迭代描述的是查询责任与返回方式，快慢取决于缓存、链路和服务器状态 | 陷阱清单 |
| A4 | HTTP 1.0 默认持久连接 | HTTP 1.0 默认**非持久**，1.1 默认持久 | 陷阱清单 |
| A5 | FTP 数据连接一直保持 | **控制连接保持，数据连接每次传输新建** | 陷阱清单 |
| A6 | SMTP 直接传二进制文件 | 408 传统 SMTP 模型传 7 位 ASCII；MIME 声明内容类型/编码，二进制常用 base64 等内容传输编码转成 ASCII | 2018 真题 |
| A7 | POP3 必须下载后删除服务器邮件 | POP3 **支持**下载并删除/下载并保留，由**客户端配置决定**；IMAP 典型是保留在服务器 | 陷阱清单 |
| A8 | DHCP 客户端端口 67，服务器 68 | **服务器 67，客户端 68**（记法：服务器先被分配端口） | 陷阱清单 |
| A9 | RIP 是网络层协议 | RIP 是**应用层**协议（UDP 520） | 陷阱清单 |
| A10 | SMTP 负责收邮件 | SMTP **只管发**（用户→服务器、服务器→服务器）；收信用 POP3/IMAP | 2012/2013 真题 |
| A11 | FTP 数据连接固定用客户端 20 端口 | 20 是**服务器数据连接的源端口**（主动模式）；目标端口由客户端 PORT 命令声明的临时端口决定 | 2017 真题 |
| A12 | 非持久连接每对象只花 1 个 RTT | 非持久每对象 = **建立连接 1 RTT + 请求响应 1 RTT = 2 RTT** | 2024 真题 |
| A13 | FTP/SMTP/HTTP 可使用无连接运输服务 | 四者中常规 **DNS** 查询可使用 UDP 无连接服务；FTP、SMTP、传统 HTTP 基于 TCP | 2018 真题第33题 |
