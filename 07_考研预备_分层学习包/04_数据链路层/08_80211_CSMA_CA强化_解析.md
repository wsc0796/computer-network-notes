# 802.11 与 CSMA/CA 强化题（解析版）

## 答案

`1. B  2. C  3. B  4. C`

## 解析

1. 无线网卡发射时本机强信号会掩盖远处信号，不能像有线共享以太网那样边发边可靠检测碰撞，因此使用避免碰撞、确认和退避。
2. ACK、CTS 等高优先级控制帧在 SIFS 后发送；SIFS 短于 DIFS。
3. 隐藏终端的两个发送方彼此听不到，但都能到达同一接收方。RTS/CTS 让听到 CTS 的邻站暂缓发送。
4. 使用预约时的完整顺序是 RTS、SIFS、CTS、SIFS、DATA、SIFS、ACK；在 RTS 前还需完成竞争、DIFS 等待和随机退避。
