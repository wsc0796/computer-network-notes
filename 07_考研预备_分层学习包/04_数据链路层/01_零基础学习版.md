## 1. 数据链路层解决什么问题

数据链路层解决的是：

```text
相邻节点之间如何可靠/有效地传输帧。
```

它不负责端到端，也不负责跨多个网络的路由。它关注的是一段链路上的传输。

可以这样理解：

```text
网络层关心 IP 分组往哪走。
数据链路层关心这一跳怎么把帧发过去。
```

## 2. 数据链路层主线

```text
把网络层数据报封装成帧
    ↓
解决帧边界和透明传输
    ↓
进行差错检测
    ↓
在共享信道中解决介质访问控制
    ↓
用 MAC 地址和交换机实现局域网通信
```

## 3. 三个基本问题

数据链路层常考三个基本问题：

```text
封装成帧
透明传输
差错检测
```

封装成帧：

```text
在数据前后加首部和尾部，使接收方能识别帧边界。
```

透明传输：

```text
无论数据中出现什么比特组合，都不能被误认为控制信息或帧边界。
```

差错检测：

```text
检测传输过程中是否发生比特错误。
常用方法是 CRC。
```

## 4. CRC

CRC 是循环冗余校验，用于差错检测。

做题流程：

```text
1. 看生成多项式对应的二进制位串。
2. 设生成多项式位数为 k，则在原数据后补 k-1 个 0。
3. 用模 2 除法除以生成多项式。
4. 得到余数，把余数接到原数据后面作为校验序列。
```

注意：

```text
CRC 主要用于检错，不是纠错。
模 2 加减法等价于异或，不进位、不借位。
```

## 5. PPP

PPP 是点对点协议，常用于点对点链路。

需要记：

```text
PPP 不提供可靠传输。
PPP 支持封装成帧、透明传输和差错检测。
```

## 6. 介质访问控制与 CSMA/CD

在共享信道中，多个站点可能同时发送数据，产生冲突。

CSMA/CD：

```text
载波监听多点接入/碰撞检测。
```

核心思想：

```text
先听再发，边发边听，冲突停止，随机退避后重发。
```

常见结论：

```text
最坏情况下检测到冲突需要 2 倍端到端传播时延。
CSMA/CD 主要用于传统共享式以太网。
```

## 7. MAC 地址与交换机

MAC 地址：

```text
数据链路层地址，通常 48 位。
```

交换机工作在：

```text
数据链路层。
```

交换机 MAC 表学习：

```text
交换机根据收到帧的源 MAC 地址和进入端口动态学习 MAC 表。
转发时根据目的 MAC 地址查表。
查不到时泛洪。
```

## 8. 介质访问控制体系（408 主干，必须整块掌握）

多个站点共享信道时，谁先发、怎么避免冲突——介质访问控制分三大类：

```text
① 信道划分（无冲突，预先分配）
    频分复用 FDM、时分复用 TDM、波分复用 WDM、码分复用 CDMA
   → 各自占用独立资源，永远不会冲突

② 随机访问（有冲突风险，边发边解决）
    ALOHA（纯/时隙）：随便发，冲突重传
    CSMA（载波监听）：先听再发——1-坚持（听到空闲立即发）/ 非坚持（随机等再听）/
                     p-坚持（概率 p 发，1-p 等）
    CSMA/CD（碰撞检测，有线以太网）：先听再发，边发边听，冲突停止，退避重发
    CSMA/CA（碰撞避免，无线 802.11）：不能边发边听 → 先预约（RTS/CTS）、
                      DIFS/SIFS 等待、ACK 确认，解决隐藏终端问题
   → 可能冲突，靠退避算法重试

③ 轮询/令牌（无冲突，轮流使用）
    轮询（Polling）：主站轮流询问从站
    令牌传递（Token Passing）：拿到令牌才能发，令牌环形传递（如令牌环）
   → 有主控或令牌保证同一时刻只有一个站点发
```

记忆锚点：

```text
CSMA/CD 用在有线以太网（能边发边听）
CSMA/CA 用在无线 802.11（无线信号边发边听不现实，改用预约+确认）
CDMA/TDMA/FDMA 都是无冲突的；只有 CSMA 类可能冲突（2013 真题）
IFS：SIFS(短) < PIFS < DIFS(长)；EIFS 只在错误接收后出现
```

## 9. 408 真题专章（半幺郎 分章节真题，2009-2025）

> 来源：`08_网盘资料接入/extracted_true_questions/03-数据链路层真题OCR.md`
> 考情：计算大题（停等/GBN/SR 利用率、CSMA/CD 时延、最小帧长）+ 概念（CDMA/CSMA-CA/交换机）。

### 9.1 CSMA/CD 时延计算（408 高频）

**2010 真题（综合大题 9 分）**：某局域网采用 CSMA/CD，数据传输速率 10Mbps，主机甲和主机乙之间电缆 2km，信号传播速度 200000km/s。若甲和乙发送数据时发生冲突：
> (1) 从开始发送数据时刻起，到两台主机均检测到冲突时刻止，最短需要多长时间？
> (2) 最长需要多长时间？
> 思路：最短 = 传播时延 τ = 2/200000 = 10μs（乙发数据时甲还没停，甲在 τ 后检测到）；最长 = 2τ = 20μs。
> 公式：**τ = 距离/传播速度；最短检测时间 = τ；最长检测时间 = 2τ（争用期）**。

**2019 真题（单选）**：假设一个采用 CSMA/CD 协议的 10Mbps 局域网，最小帧长是 128B，则在一个冲突域内两个站点之间的单向传播延时最多是？

> 答案：**51.2μs**。
> 公式：最短帧长 = 2τ × 速率 → τ = 最短帧长/(2×速率) = 128×8/(2×10×10⁶) = 51.2μs。

**2009 真题（单选）**：CSMA/CD 网络中，传输介质是一根完整的电缆，传输速率 1Gbps，信号传播速度 200000km/s。若最小数据帧长度减少 800bit，则最远的两个站点之间的距离需要？

> 答案：**减少 80m**。
> 公式：最短帧长 = 2×(距离/传播速度)×速率 → 距离 = 帧长×传播速度/(2×速率)；帧长减 800 → 距离减 800×200000×10³/(2×10⁹) = 80m。

### 9.2 二进制指数退避（2023/2025 连考）

**2023 真题（单选）**：已知 10Base-T 以太网的争用时间片为 51.2μs。若网卡在发送某帧时发生了连续 4 次冲突，则基于二进制指数退避算法确定的再次尝试重发该帧前等待的最长时间是？

> 答案：**768μs（C）**。
> 公式：第 n 次冲突后，退避时间 = 随机整数 r × 51.2μs，r ∈ [0, 2ⁿ-1]。第 4 次冲突时 r 最大 = 2⁴-1 = 15，所以最大等待时间 = 15×51.2μs = 768μs。

**2025 真题（单选）**：10Base-T 以太网中，主机甲与乙处于同一个冲突域。若连续发生 11 次冲突，则甲再发送所需要等待的最大时间间是？

> 答案：**52.3776ms（C）**。
> 公式：k = min(11, 10) = 10，r 最大 = 2¹⁰-1 = 1023，所以最大等待时间 = 1023×51.2μs = 52.3776ms。
> 关键：**退避上限是 2^10 个候选时间片，最大随机数是 2^10-1**，不能把 2047 当成上限。

### 9.3 GBN/SR 设计题（408 综合大题）

**2025 真题（综合大题，GBN 卫星链路设计）**：卫星链路单向传播时延较大，基于 GBN 协议设计一个面向可靠传输的链路层协议 SLP，支持路由器 R1 向 R2 发送数据，SLP 数据帧长为 1500B，忽略 ACK 帧长度，要求 SLP 单向信道利用率不低于 80%：
> (1) 发送窗口大小至少为多少？
> (2) SLP 序号至少应使用多少比特？
> 思路：利用率 = 发送时间×窗口 / (发送时间 + 2τ)。窗口 ≥ 0.8×(发送时间+2τ)/发送时间。GBN 要求窗口 ≤ 2ⁿ-1。
> 考点：**卫星链路高传播时延 → 大窗口 + 序号位数**（详见 07_考研强化速查 三协议对比）。

**2017 真题（综合大题 9 分，GBN 捎带确认）**：甲乙双方均采用后退 N 帧协议（GBN）进行持续的双向数据传输，且双方始终采用捎带确认。帧长均为 1000B，数据帧的发送序号和确认序号字段均为 3 比特，信道传输速率 100Mbps，RTT=0.96ms：
> (1) 从 t0 到 t1 时刻，甲方可以确认乙方已正确接收的数据帧有多少个？
> (2) 从 t1 时刻起，甲方在不出现超时且未收到乙方新的确认帧之前，最多还可以发送多少个数据帧？
> (3) 甲方可以达到的最大信道利用率是多少？
> 考点：**捎带确认（piggyback）+ GBN 窗口 + 利用率**——3 比特序号 → 窗口 ≤ 7。

### 9.4 CDMA 与 MAC 概念（选择题）

**2014 真题（单选）**：站点 A、B、C 通过 CDMA 共享链路，若 C 从链路上收到的序列是 (3,0,3,0,3,0,-2,0,-2,0,2,0)，则 C 收到 A 发送的数据是？

> 方法（OCR 未转录出 A 的码片，逻辑如下）：
> 用 **A 的码片序列**与接收序列做内积——每个 bit 时段（4 个码片）分别计算：
> 内积 = Σ(接收值 × A码片值)，内积 > 0 → 该 bit 为 1，内积 < 0 → 为 0。
> ⚠️ 真题原文的码片序列栏 OCR 缺失，必须按原题图/原 PDF 的 A 码片计算，不能凭 C 的码片推出。
> 考点：CDMA 靠正交码片区分信号，接收方用目标站的码片做内积解出该站数据。

**2013 真题（单选）**：下列介质访问控制方法中，可能发生冲突的是？

> 答案：**CSMA**（CDMA/TDMA/FDMA 都是无冲突的；CSMA 是随机访问，可能冲突）。

**2011 真题（单选）**：对正确接收到的数据帧进行确认的 MAC 协议是？

> 答案：**CSMA/CA**（无线协议用确认帧；CSMA/CD 有线不确认）。

### 9.5 CSMA/CA 与 802.11（无线，选择题常考）

**2018 真题（单选）**：IEEE 802.11 无线局域网的 MAC 协议 CSMA/CA 进行信道预约的方法是？

> 答案：**交换 RTS 与 CTS 帧**（解决隐藏终端问题）。

**2020 真题（单选）**：802.11 无线局域网中，主机 H 与 AP 之间发送或接收 CSMA/CA 帧的过程中，在 H 或 AP 发送帧前所等待的帧间间隔时间（IFS）中最长的是？

> 答案：**DIFS（分布式帧间间隔）**。
> 正常发送数据帧涉及的 IFS：SIFS < PIFS < DIFS，其中 **DIFS 最长**（优先级越高等待越短）；
> EIFS 只在**错误接收帧后**使用，数值大于 DIFS，但不在正常发送的 IFS 比较之列——所以该题答案仍是 DIFS。

**2024 真题（单选）**：采用 CSMA/CA 的 802.11 无线局域网中，DIFS=128μs，SIFS=28μs，RTS、CTS 和 ACK 帧的发送顺序及等待时间？

> 答案：等待 **DIFS(128μs)** + 竞争窗口内**随机退避**（CSMA/CA 完整流程；若题已省略退避过程则只写 DIFS）后发送 **RTS** → 等 **SIFS(28μs)** 发送 **CTS** → 等 **SIFS(28μs)** 发送 **DATA** → 等 **SIFS(28μs)** 发送 **ACK**。
> 顺序固定：RTS → SIFS → CTS → SIFS → DATA → SIFS → ACK；只有开始抢信道时等 DIFS，之后帧间都用更短的 SIFS。

### 9.6 链路层 408 考情总结

```text
计算重点：CSMA/CD 争用期/最小帧长（τ、2τ、最短帧长公式）、
          GBN/SR 窗口与利用率（卫星链路是近年热点）、二进制指数退避
概念重点：CDMA 码片计算、CSMA/CA 的 RTS/CTS、802.11 IFS

公式速记：
  τ = 距离/传播速度
  最短帧长 = 2τ × 速率
  争用期 = 2τ
  退避时间 = r × 争用时间片，r ∈ [0, 2ᵏ-1]，k=min(冲突次数, 10)，连续 16 次冲突放弃
  利用率 = min(1, 窗口×发送时间 / (发送时间 + 2τ + T_ACK))  ← 必须封顶 1，题给 ACK 帧长则计入
  GBN 窗口 ≤ 2ⁿ-1，SR 窗口 ≤ 2ⁿ⁻¹
```
