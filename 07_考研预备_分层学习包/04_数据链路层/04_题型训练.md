## 2. 必背速记

```text
数据链路层 PDU 是帧。
三个基本问题：封装成帧、透明传输、差错检测。
CRC 用于检错，不负责纠错。
PPP 不保证可靠传输。
MAC 地址通常 48 位。
交换机工作在数据链路层。
交换机通过源 MAC 地址动态学习 MAC 表。
CSMA/CD：先听再发，边发边听，冲突停止，随机退避。
```

## 3. CRC 做题模板

```text
1. 生成多项式转二进制。
2. 原数据后补 r 个 0，r = 生成多项式位数 - 1。
3. 模 2 除法。
4. 余数不足 r 位就在前面补 0。
5. 原数据 + 余数 = 发送序列。
```

## 4. 简答模板

### 交换机工作原理

```text
交换机工作在数据链路层，根据 MAC 地址转发帧。
交换机收到帧后，根据源 MAC 地址和入端口动态学习 MAC 表；
转发时根据目的 MAC 地址查表，若找到则从对应端口转发，若找不到则泛洪。
```

## 5. 408 真题专章（半幺郎 分章节真题，2009-2025）

> 来源：`08_网盘资料接入/extracted_true_questions/03-数据链路层真题OCR.md`
> 链路层是 408 **计算大题重灾区**：停等/GBN/SR 的利用率、窗口大小、重传帧数几乎年年考。

### 5.1 考点一：CRC 与差错控制

**2023 真题（单选）**：若甲向乙发送数据时采用 CRC 校验，生成多项式为 G(x) = x⁴ + x + 1（即 G = 10011），则乙接收到下列比特串时，可以断定其在传输过程中未发生错误的是？

> 答案：用 10011 对收到的比特串做模 2 除法，余数为 0 表示**未检出差错**（CRC 可能漏检某些错误模式，不能说"无错误"）。
> 考点：CRC 是**检错**不是纠错；余数为 0 表示未检出错误。

**2025 真题（单选）**：有差错检测编码集为 {1001, 1010, 0110, 1100, 1111, 0011}，其检错、纠错能力为？

> 思路：计算编码集的最小海明距离 d_min。逐对核对不同位数（如 1001 vs 1010 有 2 位不同、
> 1001 vs 0110 有 4 位不同、0110 vs 0011 有 2 位不同……），全部 15 对的最小值 = **2**。
> 结论：d_min = 2 → **可检错 1 位，不能保证纠错**（d_min ≥ 3 才能纠错 1 位）。
> 考点：海明距离决定检错纠错能力（`d_min - 1` 检错，`⌊(d_min-1)/2⌋` 纠错）。

### 5.2 考点二：停止-等待协议计算

**2018 真题（单选）**：主机甲采用停-等协议向主机乙发送数据，数据传输速率 3kbps，单向传播时延 200ms，忽略确认帧传输时延。当信道利用率等于 40% 时，数据帧的长度为？

> 公式：信道利用率 = 发送时间 / (发送时间 + 2×传播时延)
> 设帧长 L，发送时间 = L/3000。0.4 = (L/3000) / (L/3000 + 0.4) → 解得 **L = 800 比特**。
> 核心：停-等协议一个周期 = 发送 + 等确认（2 倍单向传播时延）。

**2020 真题（单选）**：假设主机甲采用停-等协议向主机乙发送数据帧，数据帧长与确认帧长均为 1000B，数据传输速率 10kbps，单向传播时延 200ms，则甲的最大信道利用率为？

> 答案：**40%**（题给确认帧长 1000B，必须计入 ACK 发送时间）。
> 计算：数据帧发送时间 = 8000bit/10000 = 0.8s；ACK 发送时间同为 0.8s（帧长相等）；
> 周期 = 0.8（数据） + 0.2（传播） + 0.8（ACK） + 0.2（传播） = 2.0s；
> 利用率 = 0.8 / 2.0 = **40%**。
> ⚠️ 忽略 ACK 发送时间会误算成 66.7%——题给确认帧长度时必须计入。

### 5.3 考点三：GBN（后退 N 帧）计算

**2009 真题（单选）**：数据链路层采用 GBN 协议，发送方已经发送了编号为 0~7 的帧。当计时器超时时，若发送方只收到 0、2、3 号帧的确认，则发送方需要重发的帧数是？

> 答案：**4**。GBN 采用**累计确认**：收到 3 号确认表示 0~3 全部正确，所以只需重发 4、5、6、7 号帧。

**2012 真题（单选）**：两台主机之间采用 GBN 传输数据，数据传输速率 16kbps，单向传播时延 270ms，数据帧长度范围 128~512 字节，接收方总是以与数据帧等长的帧进行确认。为使信道利用率达到最高，帧序号的比特数至少为？

> 答案：**3 位**（以王道解析为准，口径 = 允许发送方固定使用最长帧）。
> 思路（取**最长帧 512B** 使窗口填满信道）：
> - 发送时间 T = 512×8/16000 = 0.256s；ACK 发送时间同为 0.256s（等长确认）
> - 一个周期 = 0.256 + 0.54（2τ） + 0.256 = 1.052s
> - 要利用率最高（窗口填满信道）：窗口 W ≥ ceil(1.052/0.256) = 5
> - GBN：W ≤ 2ⁿ-1 → n=3（2³-1=7 ≥ 5）✅
> ⚠️ 两种口径（先确认题目假设）：
> ① 允许固定用最长帧 → 512B → 窗口 5 → **3 位**（官方口径）；
> ② 要求帧长 128~512B 任意变化时都不间断 → 按最短帧 128B 算：T=0.064s、周期 0.668s、窗口 ≥ 11 → 序号 **4 位**。
> 题目说"利用率最高"按 ①；说"最短帧也连续发送"按 ②，不要混用。

**2014 真题（单选）**：主机甲与主机乙之间使用 GBN 传输数据，甲的发送窗口尺寸为 1000，数据帧长 1000 字节，信道带宽 100Mbps，乙每收到一个数据帧立即用短帧确认（忽略其传输时延）。若单向传播时延为 50ms，则甲可以达到的最大平均数据传输速率约为？

> 答案：约 **80Mbps**。
> 思路：窗口 1000 帧 × 每帧 80μs = 80ms 连续发送；首个 ACK 约在 100.08ms 返回，中间空闲约 20ms。
> 吞吐 ≈ 1000×8000bit / 100.08ms ≈ 79.94Mbps ≈ 80Mbps（不能写成"连续发送不停顿"——实际有约 20ms 空闲）。

### 5.4 考点四：SR（选择重传）计算

**2011 真题（单选）**：数据链路层采用 SR 协议传输数据，发送方已发送 0~3 号数据帧，现已收到 1 号帧的确认，而 0、2 号帧依次超时，则此时需要重传的帧数是？

> 答案：**2**（重传 0 和 2 号）。SR 是**独立确认**，只重传出错的帧，不重传后面的帧（对比 GBN 的累计确认）。

**2024 真题（单选）**：主机甲通过 SR 滑动窗口协议向主机乙发送帧，序号位数为 3 比特，乙只对正确接收的数据帧进行独立确认，发送窗口与接收窗口大小相同且均为最大值。甲在 t1 时刻和 t2 时刻发送的数据帧分别是？

> 题干条件：序号 3 比特 → SR 窗口 = 2ⁿ⁻¹ = **4**（发送=接收=4，均为最大值）。
> 解题规则（题图给出窗口状态时按此推）：
> ① t 时刻发送的帧 = 发送窗口内"已发送但尚未确认"的帧；
> ② 乙独立确认（逐帧确认）——收到某帧的确认只使对应槽位右移，不累计；
> ③ t1、t2 的帧号由题图中发送窗口位置与已确认帧共同决定。
> ⚠️ 题图在 OCR 转录中缺失，选项无法独立验证——刷此题时对照原卷窗口图，
> 训练重点是 SR 逐帧确认 + 窗口右移规则（与 GBN 累计确认的区别）。

**2023 真题（单选）**：假设通过同一信道，数据链路层分别采用停-等协议、GBN 协议和 SR 协议（帧长相同、忽略确认帧长度、帧序号位数为 3 比特）传输数据，三个协议的发送方最大信道利用率分别是 U1、U2 和 U3，则 U1、U2 和 U3 满足的关系是？

> 答案：**U1 ≤ U3 ≤ U2**（一般关系；具体选项以王道解析为准）。
> 窗口上限：停等 1、SR 2³⁻¹=4、GBN 2³-1=7；窗口越大理论上限越高，
> 但利用率封顶 1——SR 和 GBN 都能充满信道时 U3=U2=1，传播时延很小时三者可能相等。
> ⚠️ 不能无条件写严格小于（U1 < U3 < U2），要看信道是否已被窗口填满。

### 5.5 链路层 408 考情总结

```text
高频考点：停等/GBN/SR 计算（重传帧数、利用率、窗口大小、序号位数）
次高频：CRC 检错、以太网/交换机、CSMA/CD、HDLC 组帧

命题规律：
  1. 重传帧数题：GBN 看累计确认到哪个号，SR 看独立确认缺哪个号
  2. 利用率题：先算发送时间 vs 传播时延，再套窗口公式
  3. 窗口/序号位：GBN 窗口 ≤ 2ⁿ-1，SR 窗口 ≤ 2ⁿ⁻¹，停等 = 1
  4. 海明距离：d_min-1 检错，⌊(d_min-1)/2⌋ 纠错
```
