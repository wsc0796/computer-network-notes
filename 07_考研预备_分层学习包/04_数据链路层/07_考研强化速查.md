# 考研强化 · 数据链路层速查

> 408 重点章节：计算大题（停等/GBN/SR）+ 概念陷阱（以太网/交换机/CRC）。
> 目标：计算能秒、概念不混、陷阱能躲。

---

## 一、三大基本问题

| 问题 | 一句话 | 关键点 |
|------|--------|--------|
| **封装成帧** | 加首部尾部定边界 | 帧首尾包含地址、类型、FCS |
| **透明传输** | 数据中的控制字符不被误判 | PPP 异步链路字节填充（同步链路可用零比特填充）、HDLC 零比特填充 |
| **差错检测** | 检测比特错误 | CRC 只能检错不能纠错 |

> 陷阱：PPP 用**字节填充**，HDLC 用**比特填充**（连续 5 个 1 后插 0）。

## 二、差错控制

### 1. CRC（循环冗余校验）

```text
做题步骤：
1. 生成多项式转二进制（x⁴+x+1 → 10011）
2. 原数据后补 r 个 0（r = 生成多项式位数 - 1）
3. 模 2 除法（异或，不进位不借位）
4. 余数不足 r 位前面补 0
5. 原数据 + 余数 = 发送序列
接收方：收到的比特串 ÷ 生成多项式，余数为 0 → **未检出差错**（CRC 有漏检可能，不能说"无错误"）
```

### 2. 海明码 / 海明距离

```text
d_min ≥ 2 → 检错 1 位
d_min ≥ 3 → 检错 2 位 或 纠错 1 位
公式：可检错 d_min - 1 位，可纠错 ⌊(d_min-1)/2⌋ 位
```

### 3. 三种可靠传输协议对比（408 核心）

| 协议 | 发送窗口 | 接收窗口 | 确认方式 | 超时重传 |
|------|:------:|:------:|----------|----------|
| **停-等** | 1 | 1 | 每帧确认 | 重传当前帧 |
| **GBN**（后退 N） | ≤ 2ⁿ-1 | 1 | **累计确认** | 重传最早未确认帧及其后所有已发送但未确认的帧 |
| **SR**（选择重传） | ≤ 2ⁿ⁻¹ | ≤ 2ⁿ⁻¹ | **独立确认** | 只重传出错的帧 |

> 陷阱：GBN 收到 3 号确认 = 0~3 全部正确；SR 收到 1 号确认 ≠ 0 号正确。
> 记忆：**GBN 一次重传一堆（后退 N），SR 只重传出错的（精准打击）**。

### 4. 信道利用率计算（408 必考）

```text
发送时间 T = 帧长 / 传输速率
ACK 发送时间 T_A（题给则计入，忽略则不算）

停-等：U = min(1, T / (T + 2τ + T_A))
  一个周期 = 发送 + 传播 + ACK 发送 + ACK 传播

GBN/SR：U = min(1, W × T / (T + 2τ + T_A))
  窗口足够大时利用率最多 100%（取 min 封顶）

⚠️ 必须取 min(1, …)：窗口大时公式会超过 100%，实际最多 1。
⚠️ 题给确认帧长度时，周期里要加 ACK 发送时间（漏算会直接失分）。
```

## 三、介质访问控制体系（408 主干）

共享信道多站点如何协调发送，分三大类：

| 大类 | 是否冲突 | 协议/机制 | 特点 |
|------|:---:|------|------|
| **信道划分** | 无冲突 | FDM/TDM/WDM/CDMA | 预先分配资源，各占各的 |
| **随机访问** | 可能冲突 | ALOHA、CSMA 三坚持、CSMA/CD、CSMA/CA | 先听再发 + 退避重试 |
| **轮询/令牌** | 无冲突 | 轮询（主站问询）、令牌传递 | 有主控或令牌，同一时刻一个站点发 |

随机访问细节（高频）：

```text
ALOHA：纯（随时发，冲突概率高）/ 时隙（按时间片发，冲突减半）
CSMA：载波监听——1-坚持（忙等，空闲立即发）/ 非坚持（随机等再监听）/
      p-坚持（空闲以概率 p 发、1-p 等）
CSMA/CD：有线以太网——边发边听，冲突停止、随机退避
CSMA/CA：无线 802.11——不能边发边听，改用预约：
    DIFS 等待 → RTS → SIFS → CTS → SIFS → DATA → SIFS → ACK
    （RTS/CTS 解决隐藏终端问题；DIFS(长) > SIFS(短)，EIFS 仅错误接收后出现）
```

> 记忆：CDMA/TDMA/FDMA 无冲突；CSMA 类可能冲突（2013 真题）；CSMA/CA 靠预约避免冲突。

## 四、CSMA/CD（共享以太网）

```text
核心：先听再发，边发边听，冲突停止，随机退避（截断二进制指数退避）

争用期（碰撞窗口）= 2τ（τ = 单向端到端传播时延）
  → 在最坏情况下，发送站在 2τ 时间内可检测到冲突

最短帧长 = 2τ × 数据传输速率
  以太网：最短帧 64B（数据字段最小 46B），争用期 51.2μs
  （51.2μs 是 10Mb/s、512 bit 时间片的经典以太网；100Mb/s 对应 5.12μs）
  → 保证"发送完之前能发现冲突"

最大帧长：1500B 数据 + 18B 首尾部 = 1518B（不含前导码/SFD；带 802.1Q VLAN Tag 为 1522B）
```

> CSMA/CD 用于**有线共享以太网**；CSMA/CA 用于**无线**（无线不能边发边听，靠退避避免冲突）。

## 四、以太网与 MAC

```text
MAC 地址：48 位（6 字节）
  单播/组播看第一个字节的 I/G 位 = **第一个字节的最低位（LSB）**
    I/G = 0 → 单播；I/G = 1 → 组播
    例：01-00-5E-... 第一个字节 0x01 最低位=1 → 组播（首字节最高位其实为 0）
  广播地址：FF-FF-FF-FF-FF-FF（全 1）
  全球管理地址按设计唯一；但还有本地管理地址、虚拟地址、克隆/重复配置等例外

以太网帧格式：目的 MAC(6B) + 源 MAC(6B) + 类型(2B) + 数据(46~1500B) + FCS(4B)

以太网特点：无连接、不可靠（不确认）；差错帧通常丢弃，需要可靠性时由适当的上层机制处理（如 TCP）
```

## 五、交换机

```text
工作在数据链路层（第二层），基于 MAC 地址转发

自学习过程：
  1. 收到帧，记录「源 MAC → 入端口」到 MAC 表
  2. 查表：目的 MAC 在表中 → 从对应端口转发
  3. 目的 MAC 不在表中 → 泛洪（除入端口外所有端口转发）
  4. 目的端口 = 入端口 → 丢弃（过滤）

MAC 表条目有老化时间（TTL），一段时间没通信就删除

对比：
  集线器：物理层，共享带宽，一个冲突域，广播
  交换机：链路层，隔离冲突域（每端口一个冲突域），仍广播
  路由器：网络层，隔离广播域
```

> 陷阱：交换机隔离**冲突域**，不隔离**广播域**；路由器才隔离广播域。

## 六、VLAN

```text
VLAN 在交换机上划分逻辑网络（按端口/ MAC/协议/IP）

作用：
  1. 隔离广播域（每个 VLAN 一个广播域）
  2. 提高安全性（不同 VLAN 默认不能互访）
  3. 灵活管理（与物理位置无关）

VLAN 帧：以太网帧插入 4 字节 VLAN Tag（802.1Q）
```

## 七、PPP 与 HDLC

| 协议 | 特点 | 透明传输 |
|------|------|----------|
| **PPP** | 点对点，**不提供可靠传输**，无纠错/流量控制 | **异步链路字节填充**（0x7E 转义）；同步链路可用零比特填充 |
| **HDLC** | 面向比特，可靠传输 | 零比特填充（5 个 1 插 0） |

> 陷阱：PPP 不保证可靠传输（这是高频判断题）。

## 八、选择题高频陷阱

| 陷阱说法 | 纠正 |
|---------|------|
| CRC 能纠错 | CRC 只能**检错**，海明码才可纠错 1 位 |
| MAC 地址 32 位 | MAC 地址 **48 位** |
| 以太网最短帧 46B | 最短帧 **64B**（数据字段最小 46B） |
| 交换机隔离广播域 | 交换机隔离**冲突域**，VLAN 才隔离广播域 |
| GBN 收到 3 号确认只说明 3 号正确 | **累计确认**：0~3 全部正确 |
| SR 收到 1 号确认说明 0 号正确 | SR **独立确认**：0 号仍需重传 |
| PPP 提供可靠传输 | PPP **不提供**可靠传输 |
| 停-等协议信道利用率高 | 停-等利用率**低**（每帧都要等确认） |
