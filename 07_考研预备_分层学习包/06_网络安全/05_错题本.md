## 0. 做题前必看：网络安全高频陷阱（预填）

| # | 陷阱说法 | 正解 | 来源 |
|:--:|---------|------|------|
| S1 | 数字签名用公钥加密 | 发送方用**私钥对摘要执行签名算法**（教学简化说法"私钥加密摘要"），接收方用公钥验证 | 08 高频陷阱 |
| S2 | 非对称加密比对称快 | 对称加密**快得多**，非对称慢（数学运算量大） | 08 高频陷阱 |
| S3 | 报文鉴别能防抵赖 | 报文鉴别**不能**不可否认，数字签名可以 | 08 高频陷阱 |
| S4 | MD5 是加密算法可逆 | MD5 是**散列函数**（单向不可逆），不是加密；且 MD5/SHA-1 抗碰撞性已失效，现代用 SHA-256 等 | 08 高频陷阱 |
| S5 | HTTPS 全程非对称加密 | 数据用**对称加密**；非对称密码还用于证书签名和握手身份认证（现代 TLS 用 (EC)DHE 协商，不是 RSA 传密钥） | 08 高频陷阱 |
| S6 | 公钥加密用公钥解密 | **公钥加密 → 私钥解密**（加密用途）；私钥操作≠都是"加密"（签名是执行签名算法） | 08 高频陷阱 |
| S7 | 防火墙能完全防病毒/攻击 | 防火墙**不能完全防御**病毒、内部攻击、DoS——但可缓解部分 DoS（限流/ACL），下一代防火墙可识别部分恶意内容 | 08 高频陷阱 |
| S8 | 对称加密密钥分发简单 | 对称加密最大难题是**密钥分发** | 08 高频陷阱 |
| S9 | 摘要可逆（能还原原文） | 散列是**单向**的，不可逆 | 概念 |
| S10 | 证书直接证明公钥可信 | 证书由 **CA 私钥签名**，但要"可信"还需：CA 位于受信任链上 + 有效期 + 主机名匹配 + 用途正确（必要时候吊销状态） | 概念 |
