## 参考答案

### 1. 加密体系对比
对称：**DES/3DES/AES**，加解密用**1**个密钥，优点**快**、缺点**密钥分发难（N 人需 N(N-1)/2 个共享密钥）**
非对称：**RSA**，用**1**对密钥（**公钥**公开，**私钥**保密）；公钥加密→**私钥**解密（**机密性**）；**私钥**执行签名→公钥验证（**认证/签名**）；优点**分发简单**、缺点**慢**
混合体系：**非对称**传输或协商密钥材料，**对称**传数据

### 2. 摘要 / MAC / 签名三角
报文摘要：**散列**函数，解决**完整性（检出传输差错）**；MD5 **128** 位、SHA-1 **160** 位；特性**单向不可逆**（碰撞必然存在，安全散列使寻找碰撞计算不可行；MD5/SHA-1 已失效）
MAC：用**共享密钥**生成的鉴别码（散列实现即 **HMAC**），解决**完整性 + 认证发送方**
数字签名：发送方用**私钥**对**摘要**执行**签名**算法；验证用**公钥**；解决①**认证** ②**完整性** ③**不可否认**；比 MAC 多解决**不可否认性**
⚠️ 裸摘要不能防主动篡改（攻击者可同时改报文重算摘要）——报文鉴别必须由 MAC 或数字签名实现

### 3. HTTPS 握手（旧式 TLS_RSA 简化）
① **支持的加密套件 + 客户端随机数**
② **数字证书 + 选定加密套件 + 服务器随机数**
③ 验证**证书** → 生成**预主密钥** → 用**服务器公钥**加密 → 发送
④ 客户端随机数 + 服务器随机数 + **预主密钥** → **会话密钥**（**对称**密钥）
⑤ 用**会话密钥对称**加密
用到技术：非对称 = **密钥传输/证书签名/身份认证**；对称 = **会话密钥加密数据**；数字签名 = **CA 签名证书**；证书 = **服务器身份 + 服务器公钥 + CA 数字签名**
⚠️ TLS 1.3 已取消 RSA 密钥传输，改用 (EC)DHE

### 4. 攻击识别
窃听→**加密**；篡改→**报文鉴别/签名**；重放→**序号/时间戳**；中间人→**CA 证书验证**；DoS→**防火墙/限流（缓解）**

### 5. 防火墙
定义：**网络边界按规则过滤数据包的安全设备**
分类1（网络层）：**包过滤**，检查 **IP 首部+端口**
分类2（应用层）：**代理**，检查**应用层内容**
局限：**不能完全防**病毒 / 内部攻击 / DoS（应用层防火墙、内部隔离、限流/ACL 可缓解一部分）

### 6. 安全目标
机密性→**加密**；完整性→**报文鉴别（MAC/签名）**；认证→**数字签名/挑战-响应**；不可否认→**数字签名**；可用性→被 **DoS** 攻击破坏
