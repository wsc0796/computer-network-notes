# 强化验收 B 卷（解析版）

## 选择题答案

`1. B  2. B  3. C  4. B  5. B  6. B  7. C  8. B`

1. 奈奎斯特上限为 `2 x 2000 x log2(8)=12 kbps`；香农上限为 `2000 x log2(1+7)=6 kbps`，取 6 kbps。
2. 帧发送时延为 `1000 x 8 / 1 Mbps=8 ms`，一个周期为 `8+2x10=28 ms`，利用率为 `8/28=2/7`。
3. GBN 发送窗口最大为 `2^k-1=7`。
4. WDM 按光波长划分光纤传输资源。
5. 四个连续 `/24` 共 1024 个地址，对应 `/22`，起始地址为 8，满足 4 的边界。
6. 经 C 的候选代价为 `2+4=6`，大于当前的 5，保留经 A。
7. 本题使用考试简化模型：三重重复 ACK 后 `ssthresh=16/2=8 MSS`，`cwnd=ssthresh=8 MSS`。真实 TCP 具体实现可能有不同暂态处理，不用此题替代工程实现细节。
8. FTP 采用控制连接和独立的数据连接；控制连接通常使用 TCP 21 端口。

## 综合题参考答案

### 1. VLSM（5 分）

一个从低地址开始的可行方案如下：

| 部门需求 | 网络地址/前缀 | 可用主机范围 |
|---:|---|---|
| 500 | `172.20.0.0/23` | `172.20.0.1 - 172.20.1.254` |
| 250 | `172.20.2.0/24` | `172.20.2.1 - 172.20.2.254` |
| 120 | `172.20.3.0/25` | `172.20.3.1 - 172.20.3.126` |
| 60 | `172.20.3.128/26` | `172.20.3.129 - 172.20.3.190` |
| 60 | `172.20.3.192/26` | `172.20.3.193 - 172.20.3.254` |

### 2. TCP（2 分）

有效发送窗口为 `min(rwnd, cwnd)=2500 B`。已有 `2000 B` 未确认，因此在不收到确认时最多还能发送 `500 B`；TCP 段可以小于 MSS。

### 3. DHCP（2 分）

`DHCPDISCOVER -> DHCPOFFER -> DHCPREQUEST -> DHCPACK`
