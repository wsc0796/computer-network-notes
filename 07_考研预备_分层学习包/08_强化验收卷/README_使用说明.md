# 408 计算机网络强化验收卷

> 这是两套原创的 90 分钟、25 分制模拟卷。每套使用 `8 道选择题 x 2 分 + 1 道综合题 x 9 分`，仅用于检验强化学习证据，不代表当年 408 官方题量或分值分布。

## 文件顺序

```text
A卷_试题版.md -> A卷_答题纸.md -> A卷_解析版.md
B卷_试题版.md -> B卷_答题纸.md -> B卷_解析版.md
```

开始时只能打开同一套的“试题版”和“答题纸”。完成、记录用时并停止作答后，才能打开“解析版”。

## 验收规则

```text
1. A 卷闭卷、限时 90 分钟完成；保存原始答题纸和实际用时。
2. 订正 A 卷，但不要重做后覆盖原始答案。
3. 至少间隔 14 天，闭卷、限时完成 B 卷。
4. 两套总分均应 >= 20/25，且两次综合题均 >= 6/9。
5. 每道错题记录：错误类型、对应笔记路径、订正日期、复测结果。
```

任一条件不满足时，准确结论是“资料可进入强化，学习者尚未证明达到强化水平”。
