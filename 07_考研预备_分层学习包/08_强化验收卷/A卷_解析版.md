# 强化验收 A 卷（解析版）

> 完成试题并保存原始答题纸后再打开。

## 选择题答案

`1. C  2. B  3. B  4. C  5. A  6. C  7. C  8. C`

1. 奈奎斯特上限为 `2W log2 V = 2 x 3000 x 2 = 12 kbps`；香农上限为 `3000 log2(1+15) = 12 kbps`，取较小值。
2. `R·A/4=0`，`R·B/4=-1`。
3. 最小发送时间为 `2tau=40 us`，帧长为 `40 us x 10 Mbps=400 bit=50 B`。
4. `172.16.100.10` 匹配三个表项，`/19` 最长，选 R3。
5. 每个非末片最多装 `floor((620-20)/8)x8=600 B` 数据。最后片含 `280 B` 数据，总长 `300 B`，偏移 `1200/8=150`，MF 为 0。
6. `500 B` 数据消耗序号 `1000` 到 `1499`，FIN 的序号为 `1500`。
7. 根、顶级域、权威域各一次请求-应答，计 3 个往返。
8. 无线难以边发边可靠检测碰撞；ACK 在 SIFS 后发送，SIFS 短于 DIFS。

## 综合题参考答案

### 1. TCP（3 分）

```text
C -> S: SYN,             seq=1000
S -> C: SYN+ACK,         seq=5000, ack=1001
C -> S: ACK + 300 B,     seq=1001, ack=5001
S -> C: ACK + 1200 B,    seq=5001, ack=1301
C -> S: ACK,             seq=1301, ack=6201
```

### 2. IPv4 分片（3 分）

原 IP 数据报承载 `1200 B` 应用数据和 `20 B` TCP 首部，IP 负载为 `1220 B`。每个非末片最多承载 `600 B` IP 负载：

| 分片 | 数据部分 | 总长度 | 片偏移 | MF |
|---|---:|---:|---:|---:|
| 1 | 600 B | 620 B | 0 | 1 |
| 2 | 600 B | 620 B | 75 | 1 |
| 3 | 20 B | 40 B | 150 | 0 |

### 3. 路由（2 分）

`10.20.13.4` 同时匹配 `/16`、`10.20.8.0/21`（第三字节 8-15）和 `10.20.12.0/22`（第三字节 12-15）。最长前缀是 `/22`，下一跳为 R3。

### 4. 重组（1 分）

IPv4 分片只在最终目的主机重组，路由器不重组。
