## 学习范围

`07_考研预备_分层学习包/` 按下列主题组织：

```text
00_网络概述与体系结构
01_应用层
02_运输层
03_网络层
04_数据链路层
05_物理层
06_网络安全（扩展理解；不作为独立 408 分值模块）
08_强化验收卷（两套答案隔离的模拟验收）
```

每层优先使用零基础学习版、题型训练、错题本、空白默写和强化速查；网络层另有子网、RIP、路由表和移动 IP 专题。802.11 与 CSMA/CA 归入数据链路层。

## 证据边界

资料覆盖不等于学习者已经掌握，更不等于能在 408 考场稳定得分。强化水平只能由以下个人证据判定：闭卷复述、未见题限时作答、错题间隔复测和跨层综合解释。仓库中的 `8 道选择题 + 1 道综合题` 仅是 25 分制模拟验收格式，不是对当年官方题量或分值分布的承诺。

仓库中的 OCR 真题、课程试卷和配套解析用于训练与核对；除非明确标注可靠来源，不应把它们当作 408 统考官方答案。审阅结论应区分“资料覆盖”“题目解析可信度”和“学习者真实能力”。
